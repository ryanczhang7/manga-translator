# `fixtures/reading-order/` — hand-annotated reading order

Five pages of **geometry only**: a page size, a list of text-region bounding
boxes, and the order a human reads them in. No image, no detector, no GPU.
`tests/core/test_reading_order.py` builds `RawRegion`s from the boxes and runs
MT-009's AC-6 against `reading_order`.

**Provenance.** Annotated by hand by the Test Developer (`claude-opus-5`) for
MT-009 RED on 2026-09-16, from `spikes/MT-002/pages/{011,012,013,014,015}.jpg`.
Those scans are gitignored (`.gitignore:76`, `spikes/`) and **nothing here
depends on them being present**; MT-009 PO-2 explains why the fixture is
geometry rather than the scans.

**How the order was arrived at — MT-009 PO-3.** The order was read off the page
*art*: panel structure first, then bubble position and the sense of the
sentences within each panel. It was **not** computed by running a band sweep
over the boxes, and it could not have been: `src/mangatl/domain/reading_order.py`
did not exist while this directory was written, and the phase lock froze source
for the whole of RED. `## Handoff: RED -> GREEN` in `docs/backlog/stories/MT-009.md`
records, per page, how the call was made and what was non-obvious.

**How the boxes were obtained.** Each scan was rendered with a 100 px coordinate
grid overlaid and read by eye against the grid labels. They are faithful to
roughly ±10 px, which is far below the scale any banding decision on these pages
turns on. They are the **text block** extents — what MT-007 detects and MT-008
merges into a column — not the bubble outlines.

## Fields

| Key | Meaning |
|---|---|
| `source` | which scan it was traced from |
| `page_size` | `[width, height]` in page pixels; all five are `[1125, 1600]` |
| `layout` | `"conventional"` or `"unusual"` — see below |
| `layout_reason` | on `"unusual"` pages only: which pair of regions forces the exclusion, so the exclusion is auditable rather than a bare label |
| `boxes` | `[x0, y0, x1, y1]` per region, in page pixels |
| `labels` | the region's text, **for human review only** — see below |
| `reading_order` | indices into `boxes`, in the order a human reads them |

Bounding boxes rather than full polygons because the ordering function reads
only vertical extent and x-centre, and a fixture carrying more than the function
reads invites a later story to quietly start reading it (MT-009 `## Contract`).

`labels` exist for exactly one reason: **a hand annotation nobody can check is
not evidence.** PO-3's independence claim rests on a reviewer being able to open
a scan beside this file and disagree. MT-009 `## Out of scope` forbids using what
a region *says* to decide where it goes, so
`test_the_fixture_labels_are_review_material_and_never_reach_the_ordering` pins
that the loader builds regions from `boxes` alone.

## `conventional` versus `unusual`

`architecture.md` **D10**: v1 orders by geometry and does **not** segment panels,
accepting that some unusual layouts will be ordered wrongly. `layout` records
which side of that line a page falls on, and it is decided from the **panel
grid** — a property of the art — not by running any ordering:

> A page is `unusual` when reading it requires knowing where the panel borders
> are: when two or more panels sit side by side, both contain text, and their
> text is at different vertical offsets, so that the order a human reads is not
> the order the regions' own positions imply.

By that rule 011 and 013 are `unusual` and 012, 014 and 015 are `conventional`.
Note that 014 has a tier of **three** side-by-side panels and is still
conventional: all three panels' text sits in one horizontal band, so no panel
border is needed to read it.

Only `conventional` pages are scored by AC-6. The `unusual` pages are not
padding: they carry their true, art-derived order, and
`test_the_unusual_pages_are_ordered_differently_from_their_annotation` asserts
the produced order **differs** from it. A ground truth generated by running the
rule under test would agree on every page and turn that test red — which is the
control PO-3 asks for, made mechanical.
