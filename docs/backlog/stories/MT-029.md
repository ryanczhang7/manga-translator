## Context

**This story exists because of the user's 2026-09-12 decision that S1's
denominator is ground truth.** Before it, MT-022 and MT-023 both consumed a
`GroundTruth` that nothing in the backlog created, defined a format for, or
validated — the shape of gap that surfaces at story 22 as "where does this file
come from".

**The machine cannot supply this number.** S1b counts every text region that
genuinely exists on the benchmark chapter, *including the ones the detector
misses*. If the detector could enumerate them it would not miss them. So a human
marks every text region on the benchmark chapter once — on the order of 150–250
regions across 20 pages — and that annotation is an **input** to MT-022 and
MT-023, not something either produces.

**It serves S1b and S2 from one pass.** The same region list is the denominator
for acceptance (MT-022) and the truth set for detection recall (MT-023). That is
the argument for doing it properly once rather than twice, and it is why the
format carries more than polygons.

**O1 — which chapter — remains the user's and remains open.** This story defines
the format, the tooling and the validation. **The chapter itself and the labour
of annotating it are the user's**, and nothing here supplies either. A story
that shipped a ground-truth file would have destroyed the held-out property it
exists to protect.

**Which required gate would fail if this story's artifact broke:** `unit` and
`coverage-core` — the loader and validator are pure, and `bench` carries the
100% bar.

## Acceptance criteria

- **AC-1** — Given a chapter and a ground-truth document, when it is loaded,
  then each region carries its page ordinal, a polygon of **at least three
  integer vertices in page pixel coordinates** (closed implicitly — the last
  vertex joins the first; the first is **not** repeated, unlike
  `RawRegion.polygon`), a `kind` of `"bubble"` or `"box"`, and a `source` of
  `"seed"` or `"human"`.
- **AC-2** — Given a ground-truth document that omits a page present in the
  chapter, when it is validated, then it **fails**, naming the missing page.
  *(A silently absent page removes its regions from S1b's denominator and
  inflates the headline.)*
- **AC-3** — Given a ground-truth document naming a page **not** in the chapter,
  when it is validated, then it **fails**, naming the page.
- **AC-4** — Given two ground-truth regions on the same page whose
  **rasterised polygons** overlap at IoU ≥ `IOU_MATCH_THRESHOLD`, when it is
  validated, then it **fails**, naming both. *(At or above the matching threshold a single proposal could
  match either, so the match is ambiguous and every count downstream is
  undefined. The threshold is **imported** from `bench/matching.py` — see the
  Contract.)*
- **AC-5** — Given a region whose polygon has fewer than three vertices, or has
  a vertex outside `0 <= x <= width`, `0 <= y <= height` of its page, when it
  is validated, then it **fails**, naming the region.
- **AC-6** — Given a page whose recorded `sha256` does not match the scan on
  disk, when it is validated, then it **fails**, naming the page. *(The
  annotation is pinned to the exact bytes it was made against; a re-scanned or
  re-encoded page invalidates it, and MT-005 already treats the hash this way.)*
- **AC-7** — Given a chapter, when the seeding command is run, then it writes a
  **draft** ground-truth document from a detector pass with every region marked
  `source: "seed"`, and it **refuses to overwrite** an existing document.
- **AC-8** — Given a ground-truth document in which more than
  `SEED_REVIEW_WARN_FRACTION` of regions are still `source: "seed"`, when it is
  validated, then it emits a **loud warning** naming the fraction — the
  signature of a rubber-stamped annotation. *(Validation still passes: only a
  human can say whether a seed region was reviewed and found correct. See the
  bias note in the Contract — this is the story's most important criterion and
  the one most likely to be dropped as a nicety.)*
- **AC-9** — Given a valid document, when it is loaded twice, then the region
  ordering and indices are identical — the file is a stable input, so a
  measurement re-run on unchanged inputs reproduces exactly.
- **AC-10** — Given a document flagged as used during development, when it is
  loaded in benchmark mode, then it refuses — the same refusal MT-022 AC-8 and
  MT-023 AC-7 rely on, implemented **here**, once.

**Block 1 — `src/mangatl/bench/matching.py` (new; MT-022/MT-023 import it).**

```
IOU_MATCH_THRESHOLD: float = 0.5

Polygon = tuple[tuple[int, int], ...]        # >= 3 vertices, first NOT repeated

def polygon_mask(polygon: Polygon, width: int, height: int) -> NDArray[np.bool_]
    # shape (height, width); PIL ImageDraw.polygon(fill=1) on an "L" image, > 0
def decode_mask(png: bytes) -> NDArray[np.bool_]
    # a RawRegion.mask (1-bit PNG over the whole page) -> bool array, > 0
def iou(a: NDArray[np.bool_], b: NDArray[np.bool_]) -> float
    # |a & b| / |a | b|; 0.0 when the union is empty; shapes must match (ValueError)

@dataclass(frozen=True)
class Match:
    truth_index: int | None      # index into `truth`; None => the proposal is spurious
    region_id: int | None        # position in `proposals`; None => the truth region was missed
    iou: float                   # the IoU that paired them; 0.0 when either side is None

def match_regions(proposals: Sequence[RawRegion], truth: Sequence[TruthRegion],
                  *, width: int, height: int) -> list[Match]
```

- One-to-one, **greedy by descending IoU**: compute every (proposal, truth)
  IoU from `decode_mask(proposal.mask)` against
  `polygon_mask(truth.polygon, width, height)`; take pairs in descending IoU
  order, skipping any whose proposal or truth is already taken, stopping below
  `IOU_MATCH_THRESHOLD` (the comparison is `>=`). Ties broken by
  `(truth index, proposal position)` ascending, so the result is deterministic.
- Result order: one `Match` per truth region in truth order (matched or
  `region_id=None`), then one per unmatched proposal in proposal order
  (`truth_index=None`). So `len(result) == len(truth) + spurious`.
- `RawRegion.polygon` is a closed ring (first vertex repeated); truth polygons
  are not. `match_regions` reads proposal **masks**, never their polygons, so
  the two conventions never meet.

**Block 2 — `src/mangatl/bench/truth.py` (new; MT-022/MT-023 import it).**

```
SEED_REVIEW_WARN_FRACTION: float = 0.10
TRUTH_SCHEMA_VERSION: int = 1
TRUTH_SUFFIX: str = ".truth.json"
def truth_path_for(source_dir: Path) -> Path      # source_dir.with_name(source_dir.name + TRUTH_SUFFIX)

@dataclass(frozen=True) TruthRegion:
    page_ordinal: int
    index: int                                    # position within its page, 0-based, contiguous
    polygon: Polygon                              # from matching
    kind: Literal["bubble", "box"]
    source: Literal["seed", "human"]
    note: str                                     # free text; "" when absent

@dataclass(frozen=True) TruthPage:
    ordinal: int; filename: str; width: int; height: int; sha256: str
    regions: tuple[TruthRegion, ...]              # sorted by index

@dataclass(frozen=True) GroundTruth:
    schema_version: int; chapter_name: str; development_use: bool
    pages: tuple[TruthPage, ...]                  # sorted by ordinal
    @property regions -> tuple[TruthRegion, ...]  # every page's, page order then index

@dataclass(frozen=True) ValidationReport:
    errors: tuple[str, ...]
    warnings: tuple[str, ...]
    @property ok -> bool                          # not errors

class InvalidGroundTruth(Exception)               # malformed document: the loader's
class BenchmarkChapterUsedInDevelopment(Exception)

def load_ground_truth(path: Path, *, benchmark: bool = True) -> GroundTruth
def dump_ground_truth(truth: GroundTruth) -> str  # the JSON text seed writes; round-trips
def validate(truth: GroundTruth, chapter: Chapter) -> ValidationReport
def main(argv: Sequence[str] | None = None) -> int   # python -m mangatl.bench.truth FOLDER
```

- **The document** (`<chapter>.truth.json`, a sibling of the chapter folder,
  UTF-8, `json.dumps(..., indent=2, ensure_ascii=False)` with keys in the order
  below, pages by ordinal, regions by index):

  ```
  {"schema_version": 1, "chapter_name": "<folder name>", "development_use": false,
   "pages": [{"ordinal": 0, "filename": "001.png", "width": W, "height": H, "sha256": "<hex>",
              "regions": [{"index": 0, "polygon": [[x, y], ...], "kind": "bubble",
                           "source": "seed", "note": ""}, ...]}, ...]}
  ```

- **The loader raises `InvalidGroundTruth`** (message naming the path and what
  is wrong) for: unparseable JSON; `schema_version != TRUTH_SCHEMA_VERSION`; a
  missing or mistyped field; a `kind` or `source` outside its literal; a page
  whose region `index` values are not exactly `0..n-1` once sorted (naming the
  page); duplicate page ordinals. `note` may be absent in the file and loads as
  `""`. It does **not** check anything that needs the chapter — that is
  `validate`. Loading the same file twice gives `==` dataclasses (AC-9).
- **`benchmark=True`** (the default; what MT-022/MT-023 call) raises
  `BenchmarkChapterUsedInDevelopment` naming the path and `chapter_name` when
  `development_use` is true (AC-10). `benchmark=False` loads it anyway — for
  the validator CLI and the seed tool, which must be able to read a document
  that is still being annotated.
- **`validate` returns a report and never raises.** Each error names its
  subject so a human can act on it across 250 regions; RED pins the substrings,
  not the sentence:
  - AC-2: a chapter page absent from the document → an error carrying the
    page's `ordinal` and `filename`.
  - AC-3: a document page absent from the chapter → an error carrying its
    `ordinal` and `filename`.
  - AC-6: a page whose `sha256` (or `width`/`height`) differs from the
    chapter's → an error carrying `ordinal`, `filename` and both hashes.
    `Chapter.pages[*].sha256` **is** the hash of the scan on disk
    (`read_chapter` hashes the raw bytes), so `validate` stays pure over
    `(truth, chapter)` and reads no file.
  - AC-5: fewer than three vertices, or a vertex outside
    `0 <= x <= width`, `0 <= y <= height` → an error carrying page ordinal and
    region index.
  - AC-4: for each page, every pair of regions with
    `iou(polygon_mask(a), polygon_mask(b)) >= IOU_MATCH_THRESHOLD` → an error
    carrying page ordinal, **both** indices and the IoU to two decimals. Pages
    that failed AC-5 skip this check for the offending region (a polygon that
    cannot be rasterised is reported once, not twice).
  - AC-8: with `n_seed / n_total > SEED_REVIEW_WARN_FRACTION` (and
    `n_total > 0`) → **one** entry in `warnings`, beginning `WARNING:` and
    carrying the percentage to the nearest whole number and both counts, and
    the sentence that the human pass must look for **absent** regions as well
    as wrong ones. Never an error.
  - A chapter with zero regions in the document is `ok` with no AC-8 warning
    (0/0 is not a fraction) but **one** warning that the document holds no
    regions at all.
- **`main`** (`python -m mangatl.bench.truth FOLDER [--truth PATH]`): reads
  the chapter with `store.intake.read_chapter`, loads
  `truth_path_for(FOLDER)` (or `--truth`) with `benchmark=False`, runs
  `validate`, prints every error on its own line, every warning on its own
  line, then `ok: N pages, M regions` or `invalid: K error(s)`; returns `0`
  when ok, `1` otherwise, `2` when the folder or the document cannot be read
  (one sentence, no traceback — `cli.py`'s `_fail` shape).

**Block 3 — `src/mangatl/bench/seed.py` (new).**

```
class GroundTruthExists(Exception)
def seed_ground_truth(project: Project, out: Path) -> GroundTruth
def main(argv: Sequence[str] | None = None) -> int   # python -m mangatl.bench.seed FOLDER [--out PATH]
```

- Refuses to overwrite: if `out` exists, raise `GroundTruthExists` naming it,
  **before** reading anything (AC-7). Then for every page of
  `project.chapter`, in ordinal order, `project.read_regions(ordinal)` → one
  `TruthRegion` per `RawRegion` in stored order, `index` = position,
  `polygon` = the `RawRegion.polygon` **with its repeated closing vertex
  dropped**, `kind` copied, `source="seed"`, `note=""`. `chapter_name` =
  `project.chapter.source_dir.name`; `development_use=False`;
  `schema_version=TRUTH_SCHEMA_VERSION`. Writes `dump_ground_truth(...)` to
  `out` and returns the `GroundTruth` it wrote (which
  `load_ground_truth(out, benchmark=False)` reproduces `==`).
- `main`: `open_project(project_dir_for(FOLDER))`; `--out` defaults to
  `truth_path_for(FOLDER)`; prints one line per page `page {ordinal}
  ({filename}): {n} region(s)`, a `warning:` line for any page with zero
  stored regions ("has detection run?"), then the path written and **the
  reminder that every seed region is unreviewed and the human pass must look
  for regions the detector missed** (the one line of documentation the bias
  note demands at the point of use). Returns `0`; `1` with one sentence on
  `GroundTruthExists` or a missing project; no traceback.

**Format: one JSON document per chapter**, a sibling of the chapter folder,
`<chapter>.truth.json`. JSON rather than the project SQLite because it is a
human-editable artefact the user owns, must be diffable, and must outlive any
schema the app happens to be on. `schema_version` is present for the same reason
MT-005 carries one.

**`bench/matching.py` is created here, not in MT-022.** An earlier draft put it
in MT-022 and had this story import it — which is a dependency cycle, because
MT-022 needs `GroundTruth` from here. The matcher belongs to whichever story
runs first, and that is this one. AC-4's whole meaning is "ambiguous *to the
matcher*": a second threshold that could drift from the matcher's would make the
validator check a different question from the one it claims to, so there is
exactly one definition and MT-022 and MT-023 both import it.

**The seeding bias, stated plainly because it is a methodological trap.**
Seeding a ground truth from a detector pass biases it toward what the detector
already finds: a region the detector misses is absent from the seed, and a human
reviewing a seed is far likelier to correct a wrong region than to notice a
missing one — which is exactly the failure S1b exists to measure. Seeding is
nonetheless allowed, because 150–250 hand-drawn polygons is hours of work and a
tool nobody uses measures nothing. The mitigations are all in the format:
`source` is recorded per region, AC-8 warns when the document is mostly
unreviewed seed, and **the story's documentation must state that the human pass
is required to look for *absent* regions, not only to correct present ones** —
a thing no validator can check and every honest user needs told.

**`development_use` is set by whoever annotates**, and AC-10's refusal is the
mechanism MT-022 and MT-023 both lean on. Implementing it once here is the
repair for it having been specified twice.

**Oracle partition: entirely mechanical.** Every criterion is a document, a
chapter and an expected pass or named failure. `SEED_REVIEW_WARN_FRACTION` is
the only invented number and it is a *warning* threshold, not a gate — set it at
0.10 and say in `## Notes` what was seen on the fixture set.

**Fixtures** (`test` category, RED authors them): a small valid document over a
three-page fixture chapter; one missing a page; one naming a phantom page; one
with two regions overlapping above threshold; one with a two-point polygon; one
with a stale hash; one that is 100% seed.

### Benchmark contamination — vol. 17 pp. 011–015 were used to develop MT-002

**Recorded 2026-09-12 by lead-po during MT-002, on the user's confirmation that
**vol. 17 is the intended S1/S2 benchmark volume**. Read this before choosing
the benchmark chapter (O1), because it is cheap to avoid now and impossible to
undo later.

**What happened.** MT-002's spike needed real pages. The fixtures used were
`011.jpg`–`015.jpg` of Mato Seihei no Slave vol. 17. Those five pages were run
through the full local pipeline — detector, `manga-ocr`, LaMa — and the results
are recorded in `docs/wiki/audits/MT-002-model-runtime.md`, which is
**committed**. Specifically, that document now contains:

- transcriptions of several utterances from pp. 012 and 014, quoted verbatim;
- the detector's region counts and box coordinates on those pages;
- the observation that 9/9 transcriptions on p. 014 were correct.

**Why that matters.** MT-029 exists because S1b's denominator is ground truth,
and its value depends on the benchmark chapter being **held out** — annotated by
a human who has not been shown what the detector already found. Those five pages
fail that test twice: the detector's output on them is written down, and a later
annotator reading the audit would be anchored by it.

**The cheap fix, and the recommendation: choose a benchmark chapter from vol. 17
that does not include pages 011–015.** A volume holds several chapters and
MT-029 sizes the benchmark at ~20 pages, so this costs nothing. Pages 001–005
(front matter — covers, disclaimer, character list, story recap) were also
briefly used and are not chapter pages anyway.

**Do not** reach for `development_use: true` here. That flag is per *document*,
and AC-10 makes a flagged document refuse to load in benchmark mode — so using
it to quarantine five pages would disable the whole benchmark. It is the right
tool for a chapter that was used in development, not for five pages inside one.

**If pp. 011–015 must be in the benchmark chapter**, then the honest options are
to annotate them from the page images alone without reading MT-002's audit —
weak, because the anchoring is the thing being avoided — or to accept the
contamination and say so in the S1b write-up. Neither is as good as picking a
different chapter.
