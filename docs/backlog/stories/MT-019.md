## Context

Brief feature 5, and the second half of success metric S2: "no Japanese pixels
survive inside a cleaned region". A leftover glyph is visible at a glance and
makes the page look worse than an untouched one.

It is also where the brief's firmest non-goal is enforced in pixels rather than
in intent: **nothing outside a detected region is ever modified.** Not dimmed,
not blurred, not recompressed. AC-4 is the assertion, and it must be exact
equality over the complement of the mask, not a tolerance.

Read `docs/wiki/audits/MT-002-model-runtime.md`: the inpainting model and its
export are settled in `## Decided`; any measurement in `## Evidence` is to be
re-verified.

`required_gates: [integration]` is set for AC-6 and AC-7, which need the real
model. Everything else runs against a fake session.

## Acceptance criteria

- **AC-1** — Given a region mask, when the erase mask is prepared, then it is
  the region mask dilated by `MASK_DILATION_PX` and clipped to the page.
- **AC-2** — Given a page and a set of region masks, when the fake inpainter
  returns a known patch, then the result contains that patch exactly inside the
  dilated mask.
- **AC-3** — Given two overlapping region masks, when cleaning runs, then each
  pixel is inpainted once, not twice.
- **AC-4** — Given a cleaned page, when it is compared to the source page, then
  **every pixel outside the union of dilated region masks is byte-identical**.
- **AC-5** — Given a region whose dilated mask would extend past the page edge,
  when cleaning runs, then it is clipped and no index error occurs.
- **AC-6** — *(integration)* Given the real inpainting model and a fixture page,
  when cleaning runs, then the mean absolute residual between the cleaned region
  interior and the same region on a hand-cleaned reference is below
  `INPAINT_MAX_RESIDUAL`.
  *Control:* the **uncleaned** page scored against the same reference must
  exceed that threshold by a wide margin — record both numbers. If they are
  close, the metric cannot tell cleaning from not cleaning.
- **AC-7** — *(integration)* Given a fixture page with dense screentone behind a
  bubble, when cleaning runs, then the reconstructed interior's local variance is
  within `TONE_VARIANCE_TOLERANCE` of the surrounding tone's.
  *Control:* a flat-fill implementation (paint the region white) must fail this
  by a wide margin — that is the specific cheap wrong answer this AC exists to
  forbid, and a mean-residual metric alone does not catch it.

**Semantics behind each number:**

- **`MASK_DILATION_PX`** exists because a detection mask hugs the glyphs and
  leaves an anti-aliased halo of grey pixels behind. Too small and a ghost
  outline survives (visible at a glance, S2 fails); too large and the bubble's
  own outline gets eaten. GREEN measures it on the fixtures and records **both**
  failure directions with the values it tried.
- **`INPAINT_MAX_RESIDUAL`** is mean absolute difference in 8-bit levels against
  a hand-cleaned reference, over the region interior only. Set it below the
  measured value with stated headroom, and say how much; a threshold set to
  whatever the implementation scored is not a threshold.
- **`TONE_VARIANCE_TOLERANCE`** is the ratio of local variance inside the
  reconstructed area to local variance in an annulus around it. **AC-7 exists
  because AC-6 is blind to the flat-fill failure**: painting a screentoned
  bubble interior solid white can score a perfectly respectable mean residual
  while looking obviously wrong, and a one-point statistic cannot see it. This
  is the same shape of blindness `story-authoring` documents for variance versus
  gradient.

| AC | Kind | Instruction to RED |

## Deferred verifications

- *Falsifiable condition 1:* with `clean_page` replaced by a **flat white fill**
  inside the mask, AC-7 **must** fail and AC-4 must still pass. That combination
  is what proves AC-7 is measuring reconstruction quality rather than mask
  correctness.
- *Falsifiable condition 2:* with `MASK_DILATION_PX` set to `0` — a wrong value
  — AC-6 **must** fail (the glyph halo survives and raises the residual).
- *Falsifiable condition 3:* with the mask **inverted**, AC-4 **must** fail. A
  catastrophic and entirely plausible sign error that no type checker sees.
- *Why RED cannot run these:* no implementation, and in RED the integration
  suite does not load, so AC-6's and AC-7's controls are **claims until GREEN**.
  RED records the expected values; GREEN pastes the measured ones.
- **Owner: GATES.** Three mutations via `bash scripts/mutate.sh`.

## Model guidance

- **RED and GREEN models:** to be recorded at dispatch, by name. Defaults are
  `claude-opus-5` (Claude Opus 5).
- **Oracle partition mixed**; the table goes in the dispatch prompt verbatim.
  The instruction that matters is on AC-7: *invent a metric and demand a negative
  control that fires hard*, with the flat-fill control named explicitly. A
  criterion that is precise, measurable and blind is more dangerous than a vague
  one, and AC-6 alone is exactly that.
- **Success condition, falsifiable:** RED's AC-7 separates a flat-fill
  implementation from a real one by a stated ratio, and both numbers appear in
  the handoff table as expected-but-unverified. A separation narrow enough that
  sampling noise decides it sends the criterion back to the PO.
- **Verdict:** *to be recorded.*
