## Context

Brief feature 5, and the second half of success metric S2: "no Japanese pixels
survive inside a cleaned region". A leftover glyph is visible at a glance and
makes the page look worse than an untouched one.

It is also where the brief's firmest non-goal is enforced in pixels rather than
in intent: **nothing outside a detected region is ever modified.** Not dimmed,
not blurred, not recompressed. AC-4 is the assertion, and it must be exact
equality over the complement of the mask, not a tolerance.

Read `docs/wiki/audits/MT-002-model-runtime.md`: the inpainting model and its
export are settled in `## Decided`; any measurement in `## Evidence` is to be
re-verified. Two of its findings shape this story directly: `lama_fp32.onnx`
takes a **fixed 512×512 input** (E3), and the mask handed to the inpainter must
be the detector's `seg` mask **intersected with the accepted boxes** (E6) - which
is what MT-007 already stores as `RawRegion.mask`, so this story erases exactly
those pixels and never the raw `seg` map (art-integrated SFX stay untouched).

**This story is the cleaning logic and its model session, not the pipeline
stage.** Wiring a clean stage into the run is MT-065 (PO-2). Nothing in a run
calls `clean_page` when this story is done; MT-065 is what makes it happen.

**Which required gate fails if this story's artifact breaks:** `unit` and
`coverage`, for AC-1..AC-5 - both run `tests/core` and both carry
`covers | … | src/mangatl/**`, so `src/mangatl/clean/**` is read by a required
gate already and `project.conf` needs no new `covers` line (checked against
`bash scripts/gates.sh --list` on 2026-10-02). AC-6 and AC-7 need the real model
and live in `tests/integration`, read only by the optional `integration` gate -
hence `required_gates: [integration]`.

**The integration gate runs only from a checkout that has `spikes/`.**
`docs/wiki/environment.md` §5 says why: the scans and weights are gitignored and
a worktree does not carry them. In this worktree a directory junction
`spikes` → the main checkout's `spikes/` was created by the orchestrator on
2026-10-02, and `bash scripts/gates.sh --gate integration` passes here. CI has
no `spikes/` and no GPU and will report the gate `KNOWN` (no story active on the
runner, so nothing escalates it). See `## Notes`, "The integration gate at
GATES and REVIEW", for the plan.

## Acceptance criteria

- **AC-1** — Given a region mask, when the erase mask is prepared, then it is
  the region mask dilated by `MASK_DILATION_PX` and clipped to the page.
- **AC-2** — Given a page and a set of region masks, when the fake inpainter
  returns a known patch, then the result contains that patch exactly inside the
  dilated mask.
- **AC-3** — Given two overlapping region masks, when cleaning runs, then every
  pixel of the erase mask is a hole in exactly one inpainting call - none is
  inpainted twice - and all the pixels of one connected component of the erase
  mask are holes in the same call.
- **AC-4** — Given a cleaned page, when it is compared to the source page, then
  **every pixel outside the union of dilated region masks is byte-identical**.
- **AC-5** — Given a region whose dilated mask would extend past the page edge,
  or a page narrower or shorter than the model's 512 px input, when cleaning
  runs, then the mask is clipped to the page, no index error occurs, and AC-4
  still holds.
- **AC-6** — *(integration)* Given a synthetic composite - Japanese text
  rendered onto a text-free white area of a fixture scan, with the untouched
  scan as the exact reference - and the regions the real detector finds on it,
  when cleaning runs with the real inpainting model, then the mean absolute
  residual between the cleaned composite and the reference, over the pixels the
  rendered text changed, is below `INPAINT_MAX_RESIDUAL`.
  *Control:* the **uncleaned** composite scored against the same reference over
  the same pixels must be at least 4 × `INPAINT_MAX_RESIDUAL` - record both
  numbers. The control fires because the text is still there; if the two are
  close, the metric cannot tell cleaning from not cleaning.
- **AC-7** — *(integration)* Given a synthetic composite - Japanese text
  rendered onto a text-free area of dense screentone on a fixture scan - and the
  regions the real detector finds on it, when cleaning runs with the real
  inpainting model, then the ratio of local variance inside the reconstructed
  area to local variance in an annulus around it is within
  `TONE_VARIANCE_TOLERANCE` of 1.
  *Control:* a flat-fill implementation (paint the reconstructed area white)
  must miss 1 by at least 2 × `TONE_VARIANCE_TOLERANCE` - that is the specific
  cheap wrong answer this AC exists to forbid, and a mean-residual metric alone
  does not catch it.

### C-2 `src/mangatl/clean/session.py` - the session, and no arithmetic

```python
MODEL_INPUT_SIDE: int = 512          # lama_fp32.onnx: image [b,3,512,512], mask [b,1,512,512] (MT-002 E3)

class InpaintSession(Protocol):
    def run(self, image: NDArray[np.float32], mask: NDArray[np.float32]) -> NDArray[np.float32]: ...
    def get_providers(self) -> Sequence[str]: ...

def load_inpainter(model_path: Path, providers: Sequence[str]) -> InpaintSession
def selected_provider(session: InpaintSession) -> str      # get_providers()[0], never get_available_providers()
```

- Mirrors `detect/session.py` exactly in shape and in rules: `load_inpainter`
  calls `ort.preload_dlls(cuda=True, cudnn=True, msvc=True)` first (MT-002 E2);
  the module **owns no arithmetic** - it is read only by the optional gate, so
  every normalisation, transpose, resize and rounding lives in `inpaint.py`,
  which `unit` and `coverage` read.
- `run(image, mask)` feeds the graph's inputs named `image` and `mask` and
  returns output `output` unchanged.
  - `image`: `float32`, shape `(1, 3, 512, 512)`, **RGB** channel order, values
    in `[0.0, 1.0]` (8-bit level / 255).
  - `mask`: `float32`, shape `(1, 1, 512, 512)`, values exactly `0.0` or `1.0`,
    **`1.0` = hole (inpaint this pixel)**.
  - return: `float32`, shape `(1, 3, 512, 512)`, RGB, **in 8-bit scale
    `[0, 255]`, not `[0, 1]`**.
- **Settled, read out, do not re-derive:** the input convention is MT-002 E4's,
  validated against the publisher's own output (MAE 3.96/255). The **output
  scale is 255**, MEASURED by the Lead PO on 2026-10-02 on this machine
  (`CUDAExecutionProvider`) running Carve's `image.jpg` + `mask.png`: output
  range `[1.0, 223.0]`, and outside the hole `|output - 255·image|` has maximum
  `0.0` while `|output - image|` has maximum `222.1`. The export composites
  internally (`out = 255·(image·(1-mask) + pred·mask)`), which is also why E4
  calls outside-mask fidelity of the raw graph a tautology - AC-4 is meaningful
  only because the fake session in C-6 changes non-hole pixels.

### C-3 `src/mangatl/clean/mask.py` - the erase mask

```python
MASK_DILATION_PX: int = <measured in GREEN, C-7>

def erase_mask(regions: Sequence[RawRegion], page_size: tuple[int, int]) -> NDArray[np.bool_]
```

- **`RawRegion`, not `OrderedRegion`** (PO-4). The original contract named
  `OrderedRegion`, which is `mangatl.ui.link.OrderedRegion` - a `region_id` and
  a polygon, **no mask** - and which `clean` may not import (architecture.md §3
  contracts 1 and 3). The type that carries a mask is
  `mangatl.domain.region.RawRegion`, and it is exactly what
  `Project.read_regions(ordinal)` returns (in reading order), so MT-065 can hand
  the store's regions straight in.
- `page_size` is **`(width, height)`**, the project-wide convention
  (`detect.page`, `regions_from_detection`); the result's shape is
  **`(height, width)`**, dtype `bool`. The reversal is deliberate.
- Each `region.mask` is the 1-bit, page-sized PNG MT-007 writes; decode it with
  PIL (`Image.open(BytesIO(region.mask))`, nonzero = in the mask). If a decoded
  mask's size is not `page_size`, raise `ValueError` naming the region's index -
  never resize, transpose or crop a mask silently.
- Result = union of all decoded masks, then dilated once with
  `cv2.getStructuringElement(cv2.MORPH_ELLIPSE, (2r+1, 2r+1))`, `r =
  MASK_DILATION_PX`; `r = 0` is the identity. (Union-then-dilate equals
  dilate-then-union; either is fine.) With `cv2.dilate`'s default border no
  pixel outside the page exists to be set - that **is** "clipped to the page"
  (AC-1, AC-5): the array is page-sized from the start.
- Mechanical oracle for AC-1, so RED does not re-implement the kernel: a single
  set pixel at `(y, x)` well inside the page dilates to the ellipse kernel
  centred there; for `r ≥ 1` the pixel at distance `r` along an axis is set and
  the one at `r + 1` is not; for `r ≥ 2` the pixel at `(y + r, x + r)` is not
  set (it is a disk, not a square). Tests read `MASK_DILATION_PX` from the
  module, never a literal. If GREEN sets `r = 0` (see C-7), the axis assertions
  degrade to identity and RED must parametrise the dilation helper so the disk
  shape is pinned for `r ∈ {1, 2, 3}` independently of the shipped value -
  RED, say how in the handoff.
- `regions == []` returns an all-`False` `(height, width)` array.

### C-4 `src/mangatl/clean/inpaint.py` - cleaning one page

```python
INPAINT_MAX_RESIDUAL: float = <set in GREEN, C-7>
TONE_VARIANCE_TOLERANCE: float = <set in GREEN, C-7>
MIN_CONTEXT_PX: int = 32

def clean_page(page: NDArray[np.uint8], mask: NDArray[np.bool_],
               session: InpaintSession) -> NDArray[np.uint8]
```

- `page`: `uint8`, shape `(H, W, 3)`, **RGB** - exactly what
  `detect.page._decoded_page` produces from a scan (`.convert("RGB")`).
  `mask`: `bool`, shape `(H, W)` - `erase_mask`'s output. Returns a **new**
  `(H, W, 3)` `uint8` array; neither input is mutated. `ValueError` if
  `page` is not 3-D `uint8` with 3 channels, if `mask` is not 2-D `bool`, or if
  `mask.shape != page.shape[:2]`. An all-`False` mask returns a copy equal to
  `page` with **zero** calls to `session.run`.
- **The 512×512 constraint - one call per connected component, never tiles**
  (PO-5):
  1. Label the mask's **8-connected components**
     (`cv2.connectedComponentsWithStats(..., connectivity=8)`). Two overlapping
     regions are one component, which is what makes AC-3 hold by construction.
  2. Process components in **ascending label order** (raster order of each
     component's first pixel). Each window is cut from the **working result**,
     so a component cleaned earlier is clean context for a later one.
  3. **Native path** - when the component's bounding box satisfies
     `w + 2·MIN_CONTEXT_PX ≤ 512` and `h + 2·MIN_CONTEXT_PX ≤ 512`: the window
     is `512 × 512` at native resolution, centred on the bbox centre and
     clamped into the page: `x0 = clamp(cx − 256, 0, W − 512)` (likewise `y0`).
     On an axis where the page is shorter than 512 the window is the whole
     axis and the window is **padded to 512 at the bottom/right with
     `np.pad(mode="edge")`**; the mask is padded with `False`, and the padding
     is cropped off the output. Clamping never loses a component pixel: a
     centred 512 window contains any bbox of side ≤ 448 (proved in PO-5).
  4. **Downscale path** - otherwise: crop = bbox expanded by `MIN_CONTEXT_PX`
     on every side, clamped to the page; `s = 512 / max(crop_w, crop_h)`;
     resize the crop to `(round(crop_w·s), round(crop_h·s))` with
     `cv2.INTER_AREA`; the model's mask is the hole resized the same way as a
     float with `INTER_AREA`, **thresholded `> 0`** (conservative: a hole pixel
     must never become visible context and be copied back as text); pad to
     512 as in step 3; after the call crop the padding off and resize the patch
     back to `(crop_w, crop_h)` with `cv2.INTER_LINEAR`.
  5. **Model input** (`hole` = this component's pixels in window coordinates,
     `bool`): image = `window.astype(np.float32) / 255.0` transposed to
     `(1, 3, 512, 512)`; mask = the padded boolean hole as
     `(1, 1, 512, 512)` `float32`. The line that converts the boolean hole to
     the model's `float32` mask is **exactly one line, ending with
     `.astype(np.float32)  # model-mask`**, its receiver a numpy `bool` array
     (C-8 mutates it).
  6. **Model output**: `patch = np.clip(np.rint(out[0].transpose(1, 2, 0)), 0,
     255).astype(np.uint8)` - scale 255 (C-2), no division.
  7. **Write-back - only this component's pixels**, never the whole window:
     exactly one line in the module, of the form
     `<target>[hole] = patch[hole]  # write-back`, where `<target>` is the
     window's (or crop's) view of the result, `hole` the component in that
     window's coordinates at full resolution, and `patch` the `uint8` RGB output
     at that resolution. Both paths go through this one line (C-8 mutates it).
     GATES checks `grep -c '# write-back$'` and `grep -c '# model-mask$'` on
     the module are each `1`.
- **Why components and not tiles.** A component inpainted in one call has no
  tile boundary inside its hole, so the seam failure MT-002 DV-1 names cannot
  occur (PO-5). The measured fixture regions all take the native path - the
  largest connected component on `spikes/MT-002/pages/011-015.jpg` is 182×420
  (`015.jpg`), and the native limit at `MIN_CONTEXT_PX = 32` is 448 - so the
  downscale path is a correctness fallback, not the common case.
- **Why `MIN_CONTEXT_PX = 32`** (PO decision, not tuned): the native window
  centres the component, so any component that fits gets far more context than
  32 px on every side except at a page edge; 32 is the guaranteed floor, and at
  64 the 420-px component on `015.jpg` would already fall to the lossy path.

### C-5 Semantics behind each number

- **`MASK_DILATION_PX`** exists because a detection mask that hugs the glyphs
  leaves an anti-aliased halo behind; too large and the bubble's own outline is
  eaten. **The PO pre-measurement says the "too small" direction may not be
  observable on MT-007's masks**: `regions_from_detection` already dilates the
  thresholded map 2 × 7×7 inside its fence, and on the AC-6 composite the
  detector's regions cover **99.8 %** of the rendered text's pixels. AC-6's
  residual measured **1.17 / 1.00 / 0.96 / 1.03** at `r = 0 / 2 / 4 / 8`
  (throwaway probe, 2026-10-02, see `## Notes`). GREEN re-measures and records
  **both directions** with the values tried (C-7). If "too small" is not
  observable, the honest value is the smallest one that is not shown to harm,
  and the docstring says the constant is a guard against a detector or fence
  change rather than a measured necessity.
- **`INPAINT_MAX_RESIDUAL`** is mean absolute difference in 8-bit levels,
  over the pixels the rendered text changed (C-9), against the untouched scan.
  It is set **above** the cleaned residual GREEN measures, with stated headroom
  - and **at most a quarter** of the uncleaned control, which is what AC-6's
  "at least 4 ×" says from the other side. *Corrected at PLANNED (PO-8): this
  paragraph said "set it below the measured value", which would make the
  criterion fail by construction.* A threshold set to whatever the
  implementation scored is not a threshold.
- **`TONE_VARIANCE_TOLERANCE`** bounds `|ratio − 1|`, where `ratio` is local
  variance inside the reconstructed area over local variance in an annulus
  around it (C-9). **AC-7 exists because AC-6 is blind to the flat-fill
  failure**: on AC-6's white fixture, painting white is the correct answer, so
  a flat fill scores a perfect residual there. On tone it scores ratio 0. It
  must be below 0.5 for the control's "2 ×" to be satisfiable at all.
- **`MIN_CONTEXT_PX`** - C-4.

### C-6 The fake session (AC-1..AC-5), in `tests/core`

RED writes it; this pins what it must do so that it is a discriminating fake
rather than a mirror:

- Implements `InpaintSession`: `run(image, mask)` and
  `get_providers() -> ["FakeExecutionProvider"]`. It records every call (copies
  of `image` and `mask`) in order.
- **It checks the calling convention on every call** and fails the test if
  violated: `image` is `float32` `(1, 3, 512, 512)` within `[0, 1]`; `mask` is
  `float32` `(1, 1, 512, 512)` with values in `{0.0, 1.0}`. A unit test with a
  page whose R, G and B differ checks `image[0, c]` equals the window's channel
  `c` / 255 - that pins RGB order and normalisation without the model.
- Output modes, chosen per test:
  - **constant** - every pixel `(17, 34, 51)` in model scale (`float32`, so
    the 8-bit result is exactly `(17, 34, 51)`): AC-2, both paths.
  - **inverted** - `255 − 255·image`, which differs from the source at
    **every** pixel, including non-hole pixels inside the window: AC-4. A fake
    that preserved non-hole pixels would let a whole-window paste pass AC-4.
- AC-3 is observed through the recording: `Σ over calls of (mask == 1).sum()`
  equals `erase_mask.sum()` for native-path components (no padding pixel is
  ever a hole), there is exactly one call per component, and for one component
  the count of holes in its call equals that component's pixel count. A
  per-region loop over two overlapping regions makes two calls whose hole
  counts sum to more than the union - the defect AC-3 forbids.
- AC-5 cases: a region touching each page corner; a component within 256 px of
  each edge (window clamps); a page `300 × 200` (both axes padded); a page
  `1000 × 400` (one axis padded); each must also satisfy AC-4.
- AC-2 also covers the **downscale path**: a component taller than 448 px on a
  page big enough to hold it.

**Pipeline under test:** encode the composite as PNG,
`detect_page_regions(load_detector(...), png)` → `erase_mask(all regions,
(W, H))` → `clean_page(composite, mask, load_inpainter(...))`. **All** regions
on the page are cleaned, as production will; only the metric is local.
Precondition, asserted (a failure, not a skip): the detector's union mask
covers at least 95 % of the changed pixels `F`. If it does not, AC-6 is not
measuring cleaning and the test says so.

**AC-6 metric:** `F = (composite != reference).any(axis=2)`;
`residual(X) = mean(|X[F] − reference[F]|)` over all three channels, as
float. Assert `residual(cleaned) < INPAINT_MAX_RESIDUAL` and
`residual(composite) ≥ 4 · INPAINT_MAX_RESIDUAL`. Pre-measured: cleaned
**1.00-1.17**, uncleaned **145.37** (ratio > 120).

**AC-7 metric:** `g` = `cv2.cvtColor(X, cv2.COLOR_RGB2GRAY)` as `float64`;
local variance `V = blur(g², k) − blur(g, k)²` with `cv2.blur`, `k = 5`
(`LOCAL_VARIANCE_WINDOW`); `S` = the erase-mask components (8-connected) that
intersect `F`; inside `I = erode(S, 5×5 square)` (every window wholly in the
hole); annulus `A = dilate(S, square of side 2·(2 + ANNULUS_PX) + 1) &
~dilate(S, 5×5 square) & R`, `ANNULUS_PX = 12`, `R` = the source rect eroded by
2 px (every annulus window wholly in tone, wholly outside the hole);
`ratio(X) = mean(V_X[I]) / mean(V_X[A])`. Assert `S ⊆ rect` (else the fixture
is invalid - fail), `|ratio(cleaned) − 1| ≤ TONE_VARIANCE_TOLERANCE`, and for
`flat` = composite with `S` set to 255, `|ratio(flat) − 1| ≥ 2 ·
TONE_VARIANCE_TOLERANCE`. Pre-measured: cleaned **0.82-0.86** (deviation
0.14-0.18), flat **0.000** (deviation 1.0), uncleaned 2.2-3.0. `k`, `ANNULUS_PX`
and `0.95` are test constants in the test module, not production constants.

**Session smoke and convention check** (supports AC-6; C-2 is settled, this
