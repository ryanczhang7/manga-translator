## Context

Brief feature 8 and section 3 step 3: "it works through the pages, showing each
page as it goes with the bubbles it found marked on the art, and reports progress
and running cost". The $2 ceiling is meant to be **observable rather than
assumed**, and MT-012 and MT-013 made it a number; this story is where the user
sees it.

Design is settled in `docs/wiki/design/components.md` §8. Two of its decisions
are sharper than they look:

- **`$—`, never `$0.00`, when nothing has been priced yet.** `$0.00` is a claim
  that the run is free; `$—` is a statement that nothing is known. On a product
  whose defining constraint is a budget, that distinction is the difference
  between a readout and a lie.
- **A budget abort is an `ErrorBanner`, not a modal**, and it names what
  survived and offers "Review pages 1–13" and "Change budget…".

This story consumes MT-006's event stream and nothing else from the pipeline —
which is what makes it testable without a GPU or an API key, and is the payoff
for `architecture.md` §6's insistence on typed events rather than callbacks.

**Which required gate would fail if this story's artifact broke:** `unit`
(`tests/ui/`, offscreen, driven by a synthetic event stream).

## Acceptance criteria

- **AC-1** — Given a run of 20 pages and a `PageStarted(6)` event, when the
  panel updates, then the overall bar is determinate and reads "Page 7 of 20".
- **AC-2** — Given a page in progress, when stage events arrive, then the
  four-step stepper advances Detecting → Reading → Translating → Done, rather
  than showing a single indeterminate spinner.
- **AC-3** — *Moved to [[MT-062]] (user, 2026-10-01; `## Amendments` A-1).* No
  event carries detected regions or a page image, so this criterion needs a new
  domain event and the pipeline emitting it.
- **AC-4** — Given fewer than three completed pages, when the panel updates,
  then **no estimated remaining time is shown**; from the third completed page
  onward it is.
- **AC-5** — Given zero priced calls, when the cost readout renders, then it
  shows `$—` and **not** `$0.00`.
- **AC-6** — Given spend crossing 75% of the budget, when the readout updates,
  then it enters the `approaching` state (warning meter and glyph) and emits
  **exactly one** live-region announcement; when further pages keep it above
  75%, it emits **no further announcements**.
- **AC-7** — Given two or more priced calls, when the readout renders, then it
  shows a projection, and the projection states its basis — "estimated" versus
  "from N pages" (MT-013's `Projection.basis`).
- **AC-8** — Given `RunAborted(reason="budget")`, when it arrives, then an
  `ErrorBanner` appears — not a modal — naming the pages that completed, with a
  "Review pages 1–N" action. It has **no** "Change budget…" action until a
  budget setting exists (A-2).
- **AC-9** — Given a chapter opened in the review `Workspace`, when it loads,
  then the workspace header shows the cost readout in its post-run state with
  the chapter total, or `$—` when no call has been priced (A-3). Moving the
  readout from a run header is [[MT-059]]'s, which builds the run screen.

**RED-A1 (Test Developer, 2026-10-01).** The block named no constructor for
`CostReadout`, and the tests must build one; they call `CostReadout()` with no
arguments and assert that a freshly built readout - and the readout of a freshly
built `RunProgressPanel` - is already `unknown` with figure `"$—"`, because
"before the first priced call" (§8 `unknown`) includes before any `set_state`,
and PO-2 means nothing calls `set_state` during a run yet.

`APPROACHING_FRACTION` is a `Decimal`, not the `float` the first draft said:
`Usd.amount` is a `Decimal`, and a float threshold would be the only float in
the money path (`cost_estimate.py`: "exact `Decimal` throughout - no float").

**Semantics, every number pinned:**

- **Overall bar (AC-1).** `RunStarted(page_count=P)` sets range `0..P`.
  `PageStarted(k)` sets value `k` and the label `f"Page {k + 1} of {P}"`
  (ordinals are 0-based, `domain/page.py`). `RunFinished` sets value `P`.
- **Stepper (AC-2).** `PageStarted` → `("active", "pending", "pending",
  "pending")`. `StageFinished` with `stage` `"detect"` → Detecting done, Reading
  active; `"ocr"` → Reading done, Translating active; `"translate"` →
  Translating done, Done `"done"`. Those are the real stage names
  (`detect_stage.py`, `ocr_stage.py`, `translate_stage.py`). A `StageFinished`
  for any other name changes nothing. There is no `failed` step state in this
  story (no AC asks for it; MT-059 owns the failed run state).
- **A completed page (AC-4).** A page is *completed* when, after its
  `PageStarted`, the next `PageStarted`, `PageSkipped` or `RunFinished`
  arrives. `PageSkipped` pages are not completed pages - nothing ran, so they
  are not a rate sample.
- **Elapsed and remaining (AC-4).** Driven by events alone, no clock: elapsed
  is the sum of every `StageFinished.elapsed_ms`, shown `f"Elapsed
  {format_duration(ms)}"`. With fewer than `MIN_PAGES_FOR_ETA` completed pages
  the remaining label is exactly `"Remaining estimating…"` (U+2026) and
  contains no digit; from the third on it is `f"Remaining about
  {format_duration(r)}"` where `r = (sum of completed pages' elapsed_ms //
  completed) × (P − completed − skipped)`. `format_duration` truncates to whole
  seconds.
- **Cost states (AC-5..AC-7).** `set_state(spent, ceiling, projection)`:
  `spent is None` → `unknown`, figure `"$—"` (U+2014), meter value 0,
  projection label empty. Otherwise the figure is `format_usd(spent)`
  (`ui/cost_estimate.py`, reused, not re-spelled) and the budget label `f"of
  {format_usd(ceiling)}"`; the state is `exceeded` when `spent ≥ ceiling`,
  else `approaching` when `spent ≥ APPROACHING_FRACTION × ceiling` **or** the
  projected total `≥ ceiling`, else `normal`. The *projected total* is
  `spent + projection.remaining_chapter`.
- **Projection (AC-7).** Shown only when `projection is not None and
  projection.sample_count >= 2` (`components.md` §8, "shown only once
  pages_priced ≥ 2"; `MIN_SAMPLES_FOR_PROJECTION`). Its basis is **read from
  `projection.basis`, never inferred from the count** (`budget.py`: "reported,
  not inferred"): `"estimate"` → `"estimated"`, `"observed"` → `f"from
  {sample_count} pages"`. Text: `f"~{format_usd(total)} projected ({basis})"`,
  or when the projected total `≥ ceiling`, `f"projected {format_usd(total)} —
  over budget ({basis})"` (§8 approaching copy).
- **Announcement (AC-6), edge-triggered.** `live_region.announce` is called
  exactly once on each transition from `unknown`/`normal` into
  `approaching`/`exceeded`, with `f"Cost {figure} of {budget}: approaching the
  budget."` Staying at or above the threshold announces nothing; neither does
  `mark_aborted` nor `show_final`.
- **Glyph.** `"⚠"` (U+26A0) in `approaching` and `exceeded`, empty otherwise
  (A-10: colour is not the only carrier).
- **Budget abort (AC-8).** `RunAborted(reason=BUDGET, ordinal=k)`
  (`pipeline.runner.BUDGET` == `"budget"` - import it, do not re-spell it):
  `banner` is an `ErrorBanner` child of the panel (not a `QDialog`, not a
  top-level window), headline `f"Run stopped at page {k + 1} of {P} — the
  {format_usd(ceiling)} budget was reached."`, body `f"Pages 1–{k} are
  translated and can be reviewed and rendered."` and one action `f"Review pages
  1–{k}"` (en dash U+2013) whose click emits `review_requested(k)`. With `k ==
  0`: body `"No pages were translated."` and no actions. Exactly one action
  otherwise - no "Change budget…" (A-2). The banner's accessible role is
  `Alert`. The readout goes to `aborted` (`mark_aborted`: figure kept, meter
  full). Any other `RunAborted` reason leaves `banner` `None` (MT-059).
- **Workspace header (AC-9).** `Workspace` gains `cost_readout: CostReadout`
  inside `self.header`. `load_chapter(project)` calls
  `cost_readout.show_final(spent, ceiling)` with `spent =
  ledger.chapter_total(project)` if `ledger.chapter_call_costs(project)` is
  non-empty, else `None`; `ceiling = project.budget_ceiling() or
  DEFAULT_CEILING`. `show_final(None, c)` → state `unknown`, `"$—"`;
  `show_final(s, c)` → state `final`, figure `format_usd(s)`, caption ends
  `"final"` (budget label `f"of {format_usd(c)} · final"`).
- **The boundary.** `progress.py` and `cost_readout.py` import nothing from
  `mangatl.pipeline` except the reason constant `BUDGET`, and nothing from
  `mangatl.translate` or `mangatl.store`. *(RED: if import-linter's layer
  contract refuses `ui → pipeline` for the constant, amend this to spell the
  string with a test that pins it equal to `runner.BUDGET`.)* `workspace.py`
  already imports `mangatl.store.project`; it may import `mangatl.store.ledger`.
- **Styling.** Colours come from `theme.qss` by object name and dynamic
  property (MT-061's rule, as `cost_estimate.py` does): the readout sets the
  dynamic property `costState` to its state and re-polishes. No colour literal
  in either module (`tests/ui/test_workspace_colour_literals.py` is the

**Rules that are settled and must be read out:**

- **The five cost states** are `unknown`, `normal`, `approaching`, `exceeded`,
  `aborted` (`components.md` §8). `unknown` renders `$—`.
- **`approaching` is entered when spend ≥ 75% of budget *or* the projection ≥
  budget.** Either condition; the projection one is what gives the user warning
  before the guard fires.
- **The announcement is edge-triggered, not level-triggered** (AC-6). A live
  region that re-announces on every page turns a screen reader into a metronome
  and the user turns it off, which removes the warning entirely.
- **`MIN_PAGES_FOR_ETA = 3`** because two pages is not a rate — the first page
  carries cache-write cost and model warm-up, so an ETA from one or two samples
  is confidently wrong in the direction that matters.
- **The panel is driven entirely by `RunEvent`s** (`architecture.md` §6). It
  must not call into `pipeline`, `translate` or the store. If a criterion here
  seems to need one of those, the event stream is missing an event and MT-006's
  contract should be amended rather than the boundary crossed.

## Design notes

*Lifted from `docs/wiki/design/README.md`:*

> `RunProgressPanel` shows a determinate overall bar ("Page 7 of 20"), the
> current page thumbnail with markers appearing as they are found, and a
> four-step `PageStageStepper` (Detecting → Reading → Translating → Done) rather
> than a single spinner. Estimated remaining time appears only after three pages
> complete. `CostReadout` is in the header during the run and in the workspace
> header afterwards: `$0.83` in `type.numeric-lead`, "of $2.00" in
> `type.caption`, a 4px meter, and a projection once two pages are priced. Five
> states — `unknown` (shows `$—`, **never `$0.00`**), `normal`, `approaching`
> (≥ 75% spend or projection ≥ budget: `color.status.warning` meter plus a
> warning glyph), `exceeded`, `aborted`. A budget abort is an `ErrorBanner`, not
> a modal, and it names what survived and offers "Review pages 1–13" and "Change
> budget…"; the budget is a setting with a $2.00 default, not a constant. See
> components.md §8 and voice.md.
>
> **Assertable:** with zero priced calls the readout renders `$—` and not
> `$0.00`; crossing 75% of the budget moves it to `approaching` and emits exactly
> one live-region announcement, and staying above 75% for further pages emits no
> further announcements.

Error-message shape and tone: `docs/wiki/design/voice.md`. Announcement and
live-region obligations: `docs/wiki/design/accessibility.md` A-10.
