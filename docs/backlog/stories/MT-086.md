## Context

Filed 2026-10-14 when MT-048 was narrowed (MT-048 PO-1, the user's decision).
`components.md` §`PageStrip` says each strip item "carries its index and a
status glyph" from a seven-row table (pending, running, translated-none-reviewed,
partly reviewed, fully reviewed, has a failed line, skipped) with an accessible
name `"Page 7 of 20, filename, 12 of 18 lines reviewed"`. `layout.md`'s 1440 px
breakpoint says the 28 px rail "still carries every status glyph, which is what
A-10 requires of it". None of this exists: after MT-048 the strip shows the index
(rail) or the filename (full) and `AccessibleTextRole` is `Page N of M, filename`.

The store knows `page.status` (`PAGE_PENDING`, `PAGE_STALE`, `PAGE_DONE`,
`store/project.py:665`) and each line's `status` (`workspace.py` `STATUS_GLYPHS`
keys). The seven page statuses are a **derivation** over those, and that
derivation is this story's domain rule.

## Acceptance criteria

*Draft; to be pinned at PLANNED → RED against `components.md` §`PageStrip`.*

- **AC-1** — Given a page in each of the seven states the table names, when the
  strip is laid out at 1900 px and at 1100 px, then the item shows that row's
  glyph, and the seven glyphs are pairwise distinct as silhouettes (A-15.7).
- **AC-2** — Given a page with 18 lines of which 12 are accepted or edited, when
  its item is read, then its accessible name is exactly
  `Page N of M, <filename>, 12 of 18 lines reviewed`.
- **AC-3** — Given the glyph colours, when the widget sources are scanned, then
  every colour resolves through a token (`color.text.muted`, `color.accent.base`,
  `color.text.secondary`, `color.status.success`, `color.status.danger`,
  `color.text.disabled`) and no literal appears (MT-015 AC-7's scanner covers
  `workspace.py`).
- **AC-4** — Given a line's status changes in the column (accept, edit, revert),
  when the change commits, then the current page's glyph and accessible name
  update without reloading the chapter.

## Contract

To be pinned. Expected shape: a pure function `page_status(statuses:
Sequence[LineStatus], page: str, running: bool) -> PageStatus` in `domain`,
tested exhaustively; the strip reads it. The rail and the full strip share the
glyph; the rail shows glyph + index, the full strip glyph + filename (until
MT-087 adds thumbnails).

## Out of scope

Thumbnails (MT-087). The "running" state's live update during a run — the
workspace is not open during a run today; pin "running" from stored state only
unless the PO decides otherwise.
