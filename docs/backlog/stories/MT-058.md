## Context

**Filed 2026-09-30 by the Lead PO**, the second of three stories that let the
window start a run ([[MT-057]] `## Context` has the split). `components.md` §2
`CostEstimate`: spend should be "observable before it happens as well as
during" - brief feature 8, and the product's defining $2/chapter constraint.
[[MT-018]]'s `CostReadout` is the *during*; this is the *before*.

The arithmetic already exists and is the oracle for any number shown:
`mangatl.domain.budget` - `DEFAULT_CEILING` ($2.00),
`BOOTSTRAP_PAGE_ESTIMATE` ($0.06 a page, from `docs/wiki/cost-model.awk`
design A), and `Budget.project`, whose `basis` is `"estimate"` before any call
is priced. **Read those constants; do not re-derive or tune them.**

**Q1 and Q2 were answered by the user on 2026-09-30** (PO-1, PO-2): the
estimate is the single figure the budget guard itself uses before any call is
priced - `BOOTSTRAP_PAGE_ESTIMATE` × pages, labelled as an estimate - and the
budget is $2.00, read-only. The design's range ("$1.10 – $1.90") and its
`unknown` state are not built here; the Lead Designer is asked to amend §2
(PO-1).

Required gates: `unit`, `coverage`, and `coverage-core` if any arithmetic lands
in `domain`. `required_gates: []`.

## Acceptance criteria

- **AC-1** — Given a chapter summary, when it is shown, then it carries a
  `CostEstimate` that states the budget the run will be held to, "Budget
  $2.00": `DEFAULT_CEILING`, read-only, shown to the cent as the design shows
  it (not `str(Usd)`, which prints four places).
- **AC-2** — Given a summary of N pages, when it is shown, then the estimate
  reads "Estimated for N pages: *$x*." where *$x* is `BOOTSTRAP_PAGE_ESTIMATE`
  × N shown to the cent (`Budget.project` with no priced calls, its
  `remaining_chapter`), and it is labelled as an estimate - never presented as
  a measured cost. (20 pages → $1.20.)
- **AC-3** — Given a summary whose estimate exceeds the budget, when it is
  shown, then the whole estimate block takes its **over-budget** state
  (`color.status.warning`, plus a glyph or wording change - `accessibility.md`
  A-10). ([[MT-059]] owns the Start button and its "Start run anyway" label.)
  *(Control: 33 pages - $1.98, within the inclusive ceiling - shows the normal
  state; 34 pages - $2.04 - shows over-budget. RED reads the boundary from the
  two constants rather than hard-coding it, and asserts both sides.)*
- **AC-4** — Given a folder of more than 200 page images, when its summary is
  shown, then it carries the warning "That is more pages than a chapter.
  Estimated cost is *$x*." with AC-2's figure, and nothing is blocked; given
  exactly 200, no warning.
- **AC-5** — Given any estimate shown, when it renders, then it never reads
  `$0.00` for a chapter of one or more pages (`components.md` §8's rule for
  `CostReadout`, applied here: an unmeasured cost displayed as zero is a lie).

**C-1 — `format_usd`** (new module `src/mangatl/ui/cost_estimate.py`,
`__all__ = ["CostEstimate", "format_usd"]`).

```python
def format_usd(amount: Usd) -> str: ...
```

`$`, the dollars with `,` every three digits, `.`, exactly two decimals; a value
that is not a whole number of cents rounds **up** (toward +infinity) to the next
cent. `Usd.from_micro(60_000)` → `$0.06`; `Usd(Decimal("12.06"))` → `$12.06`;
`Usd(Decimal("1200"))` → `$1,200.00`; `Usd.from_micro(0)` → `$0.00` (the
formatter is honest; AC-5 is the widget's rule); `Usd.from_micro(1)` → `$0.01`;
`Usd(Decimal("1.141"))` → `$1.15`; `Usd(Decimal("2.0001"))` → `$2.01`;
`Usd(Decimal("1.15"))` → `$1.15` (a whole cent is not bumped). Never `str(Usd)`.
No float anywhere.

## Design notes

*Lead Designer, 2026-10-01.* Full spec: `docs/wiki/design/components.md` §2
`CostEstimate` (amended for PO-1/PO-2), `ChapterSummary` (parts renumbered),
§10.9 (High Contrast); `voice.md` Numbers; `accessibility.md` A-10.

**Placement.** `CostEstimate` is `ChapterSummary` **part 5**: inside the scroll
area, after the page facts (parts 2-4) and **before** the order notice (now part
6; the button is part 7). A 200-name notice must not push the cost out of sight.
`space.4` above and below it.

**Copy (character-exact).** `{n}` = page count in digits; `{x}` =
`Budget().project((), n).remaining_chapter`; `{b}` = `DEFAULT_CEILING`.

| Line | Shown | Copy | Token |
|---|---|---|---|
| 1 estimate | always | `Estimated for {n} pages: {x}.` / one page: `Estimated for 1 page: {x}.` | `type.body-strong` |
| 2 budget | normal | `Budget {b}.` | `type.body`, `color.text.secondary` |
| 2 budget | over-budget | `Budget {b}. The estimate is over budget.` | `type.body`, `color.text.secondary` |
| 3 page-count warning | `n > 200` only | `That is more pages than a chapter. Estimated cost is {x}.` | `type.body` |

AC-2 adopts line 1 exactly as the PO drafted it, with the one-page form `1 page`
(as part 2 says it). AC-1's budget is its **own line** (line 2), not a tail on
line 1's sentence, because the over-budget wording attaches to it.

**Money format.** `$` + dollars (`,` every three digits) + `.` + exactly two
decimals: `$0.06`, `$1.20`, `$12.06`, `$1,200.00`. Never `str(Usd)`. A
fraction of a cent rounds **up** - confirmed: it is `budget.py`'s direction, and
it makes the shown figure exceed `$2.00` exactly when the estimate does, so the
figure and the state cannot disagree; AC-5 (never `$0.00` for ≥ 1 page) then holds
by construction. Today's figures are whole cents, so rounding is testable only on
the formatter itself ($0.001 → `$0.01`, $1.141 → `$1.15`, $2.0001 → `$2.01`).

**States.** **normal** when `{x} <= {b}` (unrounded `Usd`, inclusive, as
`Budget.check`): 1px `color.border.subtle` border. **over-budget** when
`{x} > {b}`: 1px `color.status.warning` border **and** line 2's extra sentence
`The estimate is over budget.` - the sentence is the A-10 carrier; **no glyph**
(as the order notice). Same border width and padding in both, so nothing moves.
The state is a **queryable boolean on the widget** (MT-059 reads it). Line 3 is
text only and does not set the state; with today's constants every chapter over
200 pages is also over budget, so 201 pages shows all three lines.

| Pages | State | Lines (`\n`-joined) |
|---|---|---|
| 1 | normal | `Estimated for 1 page: $0.06.` `Budget $2.00.` |
| 20 | normal | `Estimated for 20 pages: $1.20.` `Budget $2.00.` |
| 33 | normal | `Estimated for 33 pages: $1.98.` `Budget $2.00.` |
| 34 | over | `Estimated for 34 pages: $2.04.` `Budget $2.00. The estimate is over budget.` |
| 200 | over, no line 3 | `Estimated for 200 pages: $12.00.` `Budget $2.00. The estimate is over budget.` |
| 201 | over + line 3 | … `$12.06.` … `That is more pages than a chapter. Estimated cost is $12.06.` |

**Box.** A `QFrame`, ground as the order notice, `radius.sm`, padding `space.3`,
lines `space.1` apart; labels word-wrap; no horizontal scroll. Suggested object
names, following MT-057's (the contract may rename): frame
`summary-cost-estimate`, labels `cost-estimate`, `cost-budget`,
`cost-page-warning`.
