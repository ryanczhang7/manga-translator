## Context

Filed by the follow-up mutation audit
`docs/wiki/audits/audit-followups-EPIC-04-EPIC-07-2026-10-26.md`, survivor
**S91-1** (`## Decided` 3, `## Evidence` E-3). **LOW-MEDIUM priority.**

MT-091 closed the EPIC-07 audit's RS17: `RESIDUAL_INK_MAX`
(`src/mangatl/bench/residual.py:85`, `0.01`) can no longer be doubled or cut
tenfold without a test failing. Its over-side test, however, sits at
**0.0125** (20 dots in a 1,600 px region), so the bar can still move anywhere
in **[0.01, 0.0125)** with every test green. Measured at this audit's base
(`c32c689`):

- `0.012` and `0.0124` survive `tests/core/test_bench_residual.py
  tests/core/test_bench_s2.py` (65 passed each);
- `0.0124` survives all of `tests/core` (2348 passed, exit 0);
- `0.0099` is killed by the at-threshold test.

So a re-tuning that loosens S2's "no Japanese pixels survive" bar by up to 24%
still reports `S2 PASS` for a clean that leaves that much more ink, and no test
notices. The fixture's resolution is one pixel in 1,600, i.e. 0.000625, so the
bar can be pinned to within one pixel above it at no extra cost.

**Settled (audit `## Decided` 3, do not re-litigate):** the code is correct and
0.01 is the bar (MT-023's measured decision, consumed again by MT-091). This
story pins it tighter; it does not change it.

**Evidence to verify, not assume:** the survival of `0.0124` and `0.012`, and
that `17 / 1600 == 0.010625` is `True` in Python floats (checked at audit time,
`uv run python -I -c "print(17/1600 == 0.010625)"` -> `True`). RED re-runs the
`0.0124` mutant once against the two bench files before writing the test.

Required gate that fails if this breaks: `unit` and `coverage-core` (both
required, both run `tests/core`, `coverage-core` covers
`src/mangatl/bench/**`). No optional gate involved.

## Acceptance criteria

- **AC-1** - Given page 0's region 0 cleaned white except for **17** isolated
  ink dots (a measured residual fraction of exactly `0.010625`, one pixel above
  the bar), when S2 is judged, then that region's fraction is `0.010625`,
  `residual_ok` is `False`, and the verdict is `(recall ok, residual not ok,
  not passed)`. The fraction is written as a literal, never derived from
  `RESIDUAL_INK_MAX`.
  *Control:* with `RESIDUAL_INK_MAX` set to `0.0124` or `0.012` (both survive
  today) this test fails, because `0.010625 <= 0.0124` turns `residual_ok`
  `True`; with the shipped `0.01` it passes. *Known resolution limit, not a
  defect:* a bar strictly inside `[0.01, 0.010625)` - for example `0.0106` -
  still leaves `0.010625` over the bar, so the test keeps passing and that
  mutant survives. One pixel in 1,600 is the fixture's resolution and the
  story's title; nothing finer is claimed.
