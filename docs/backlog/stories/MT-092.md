## Context

Filed by the EPIC-07 mutation audit, `docs/wiki/audits/EPIC-07-2026-10-22.md`:
survivors TR1, TR4 and MA9 (`## Decided` item 3, `## Evidence` E-2 items 3-5).
**Low priority.** None of the three can corrupt a measurement on a well-formed
document. Each is a stated contract of `bench/truth.py` or `bench/matching.py`
that no test holds. All three survived the full bench set (291 tests).

- **TR1.** `_typed` (`src/mangatl/bench/truth.py:157`) uses `type(value) is`,
  and `_get`'s docstring says why: "`True` is an `int` and `0` must not pass
  for a `bool`". Only the second half is tested (`development-use-as-int`).
  Swap in `isinstance` and `"width": true` or a `[true, 10]` vertex loads as
  `1`.
- **TR4.** `_parse` refuses any `schema_version` other than 1
  (`truth.py:226`). Only `2` is tested, so `>` in place of `!=` survives, and
  version `0` (or `-1`) loads.
- **MA9.** `iou` refuses masks of different shapes (`matching.py:74`). Its
  test uses (4, 6) against (6, 4), which numpy refuses on its own with a
  `ValueError`, so the guard can be deleted and the test stays green. A
  broadcastable pair, such as (1, 6) against (4, 6), would silently compute
  a wrong IoU.

**Settled:** all three are unprotected, and the code is correct. **Evidence,
to verify:** that numpy 2.5.3 refuses (4, 6) against (6, 4). That is why MA9
survives, and it was measured on one numpy version.

Required gate that fails if this breaks: `unit`.

## Acceptance criteria

- **AC-1 (TR1).** **Given** a document in which an integer field holds a JSON
  `true` (a page `width`, a region `index`, or one vertex coordinate), **when**
  it is loaded, **then** `InvalidGroundTruth` is raised naming the path.
  Fails under TR1.
- **AC-2 (TR4).** **Given** a document with `"schema_version": 0`, **when** it
  is loaded, **then** `InvalidGroundTruth` is raised naming the path. Fails
  under TR4.
- **AC-3 (MA9).** **Given** two masks of different but broadcastable shapes,
  for example `(1, 6)` and `(4, 6)`, **when** `iou` is called, **then** it
  raises `ValueError` whose message names both shapes. The existing test also
  gains a `match=` on the guard's message, so numpy's own broadcast error no
  longer satisfies it. Fails under MA9.
