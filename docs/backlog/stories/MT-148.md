## Context

EPIC-13 priority 2, PO-3 (the Lead PO's decision, open to the user). S2
fails a spurious proposal because "a phantom bubble gets inpainted, which
damages the art" (`bench/s2.py`). A region the pipeline excluded as `art`
(MT-147) is left as drawn: bake restores its source pixels. So it is not that
phantom, and counting it as spurious would leave S2 unable to move however
well MT-147 works.

The rule is symmetric, so it cannot hide a wrong exclusion. An `art`
region is **not a proposal** at all: it neither matches a truth region nor
counts as spurious. A real balloon the model wrongly marks `art` therefore
leaves its truth region **missed**, and recall and S1b fall.
A `user` exclusion is still counted as a proposal: it is a human's
correction of the pipeline's output, and the benchmark measures the pipeline.
`watermark` is treated like `art`, as the pipeline's own call, though nothing
writes it today (MT-121).

Required gates: `unit`, `coverage`.

## Acceptance criteria

- **AC-1** - Given a page with one truth balloon, and two stored regions -
  one matching the balloon and one elsewhere excluded `art` - when
  `measure_recall` runs, then matched is 1, spurious is 0 and missed is 0.
- **AC-2** - *(control: a wrong exclusion costs recall)* Given the same page
  with the **matching** region excluded `art`, then matched is 0, missed is
  1 and spurious is 0. S1b for the page is 0 %.
- **AC-3** - *(control: a human's act is not the pipeline's)* Given the
  region elsewhere excluded `user` instead, then spurious is 1, exactly as
  today.
- **AC-4** - `measure` (S1a/S1b) uses the same rule: an `art` region is
  neither proposed nor accepted, and `proposed` falls by the number of `art`
  regions.
- **AC-5** - The report's `spurious` line is unchanged in form. A new line
  directly below it reads `left as art               N`, counting the regions
  the rule set aside.
