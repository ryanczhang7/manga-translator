## Context

EPIC-13 priority 2, PO-3 (the Lead PO's decision, open to the user). S2
fails a spurious proposal because "a phantom bubble gets inpainted, which
damages the art" (`src/mangatl/bench/s2.py`). A region the pipeline excluded
as `art` (MT-147, `pipeline/translate_stage.py` `apply_answer`) is left as
drawn: bake restores its source pixels. So it is not that phantom, and
counting it as spurious would leave S2 unable to move however well MT-147
works.

The rule is symmetric, so it cannot hide a wrong exclusion. An `art`
region is **not a proposal** at all: it neither matches a truth region nor
counts as spurious. A real balloon the model wrongly marks `art` therefore
leaves its truth region **missed**, and recall and S1b fall.
A `user` exclusion is still counted as a proposal: it is a human's
correction of the pipeline's output, and the benchmark measures the pipeline.
`watermark` is treated like `art`, as the pipeline's own call, though nothing
writes it today (MT-121).

MT-147's DV-2 measured, on the development set, 17/17 art regions marked and
4/250 truth balloons marked art (accepted by the user, 2026-11-23, "MT-148's
bench tracks it from here"). Under this rule those four become `missed`
truth regions, named by page and index on the S2 `missed` line.

Required gates: `unit`, `coverage`, `coverage-core` (all `required` in
`project.conf`; `coverage-core` holds `src/mangatl/bench/**` at 100 %).
`required_gates` stays `[]`: no optional gate carries a criterion.

### C-1 The one rule (`src/mangatl/bench/recall.py`)

```python
from mangatl.domain.region import ExclusionReason, RawRegion

__all__ = ["PIPELINE_EXCLUSIONS", "PageRecall", "RecallReport", "measure_recall", "proposal_indices"]

PIPELINE_EXCLUSIONS: frozenset[ExclusionReason] = frozenset({"art", "watermark"})

def proposal_indices(regions: Sequence[RawRegion]) -> tuple[int, ...]:
    """The positions in `regions` of the regions the bench scores, ascending:
    every region whose `excluded` is not in PIPELINE_EXCLUSIONS. `None` and
    `user` are scored."""
```

- *Changed at PLANNED from the first draft's `proposals(regions) ->
  list[RawRegion]`.* `bench.matching.match_regions` returns
  `Match.region_id` as the **position in the sequence it was handed**
  (`matching.py`, `Match(truth_index=None, region_id=p, ...)`), and
  `acceptance.measure` reads `lines[match.region_id]` from
  `read_review_lines`, which has one entry per **stored** region. A filtered
  list would shift every id after an `art` region and read a neighbour's
  line. So the rule returns positions, and both callers map back (AC-6 pins
  it).
- `RawRegion.excluded` is `ExclusionReason | None`, with `ExclusionReason =
  Literal["watermark", "user", "art"]` (`domain/region.py`). `None` is
  included. `art` is written by `apply_answer` (MT-147), `user` by the
  workspace (MT-120); nothing writes `watermark` today (MT-121).
- The rule lives in `recall` and `acceptance` imports it. `recall` still
  imports nothing from `acceptance`. The existing source checks stand:
  `test_ac1_recall_imports_the_threshold_and_the_matcher_and_defines_neither`
  forbids a module-level name containing `THRESHOLD` or starting `IOU`, and
  `PIPELINE_EXCLUSIONS` is neither.

### C-2 `measure_recall` and its reports

```python
@dataclass(frozen=True)
class PageRecall:
    ordinal: int
    matched: int
    missed: tuple[int, ...]
    spurious: int
    left_as_art: int = 0      # new, last, defaulted

@dataclass(frozen=True)
class RecallReport:
    matched: int
    missed: tuple[tuple[int, int], ...]
    spurious: int
    ground_truth: int
    recall: float
    pages: tuple[PageRecall, ...]
    left_as_art: int = 0      # new, last, defaulted; sum of the pages'
```

`measure_recall`'s signature does not change. Per truth page:
`regions = project.read_regions(page.ordinal)`, `kept =
proposal_indices(regions)`, and `match_regions` is handed
`[regions[i] for i in kept]`.

What each number counts, after this story:

- **matched** - truth regions paired, at `IOU_MATCH_THRESHOLD`, with a
  scored region. Unchanged in form; an `art` or `watermark` region can no
  longer be the partner.
- **missed** - truth regions with no scored partner. A truth balloon whose
  only overlapping region is `art` is missed.
- **spurious** - scored regions paired with no truth region. `user`
  exclusions and included regions count; `art` and `watermark` never do.
- **left_as_art** - `len(regions) - len(kept)`: every stored region on a
  truth page whose `excluded` is in `PIPELINE_EXCLUSIONS`, wherever it
  lies and whether or not it overlaps a truth region. It counts `art`
  **and** `watermark` (PO-2): both are the pipeline's own call and bake
  leaves both as drawn, and counting only `art` would let a region leave
  the report uncounted. The invariant a test may read:
  `matched + spurious + left_as_art == stored regions on the truth pages`.
- **recall**, **ground_truth** - unchanged.

The defaults are there so that the existing construction sites (C-6) keep
meaning "none set aside". The two production construction sites pass the
field explicitly.

### C-3 `measure` (`src/mangatl/bench/acceptance.py`)

```python
@dataclass(frozen=True)
class AcceptanceReport:
    s1b: float
    s1a: float
    recall: float
    accepted: int
    proposed: int
    matched: int
    spurious: int
    ground_truth: int
    left_as_art: int = 0      # new, last, defaulted
```

`measure`'s signature does not change. Per truth page it reads `regions`
and `kept` as C-2 does, and:

- **proposed** += `len(kept)` (was `len(regions)`).
- **left_as_art** += `len(regions) - len(kept)`.
- the line of a matched region is `lines[kept[match.region_id]]`, never
  `lines[match.region_id]`.
- **accepted**, **matched**, **spurious**, the three ratios and the
  identity line's condition (`spurious == 0`) are otherwise as they are.
  With no spurious region `S1b == S1a x recall` still holds exactly, since
  `proposed == matched` then.
