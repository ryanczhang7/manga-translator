## Context

Brief feature 3, and the story the product's headline metric is about. The whole
reason the brief chose a cloud LLM over a local translation model is that it can
see the page: pronouns, speaker attribution, honorifics and continuity are
decided with the art in view.

`docs/wiki/stack.md` §5/O4 and `architecture.md` D5 fix the call shape, and both
constraints are budget constraints rather than preferences:

- **one call per page** — two passes per page costs $2.29 against a $2.00
  ceiling;
- **the page image capped at 1,568 px on the long edge** — an uncapped 2400×3400
  scan costs $1.95 against $1.14 capped.

Neither is a tuning knob. Changing either is a change to a stated constraint and
goes back to the user.

`required_gates: [integration]` is set for AC-8, the one criterion that needs a
real API call. Everything else runs against a recorded response fixture.

## Acceptance criteria

- **AC-1** — Given a page with N ordered regions carrying Japanese text, when a
  translation request is assembled, then it contains exactly one image block,
  one system block, and one user block listing all N regions by reading index
  and source text.
- **AC-2** — Given a page image of any size, when it is prepared for the
  request, then its long edge is at most 1568 px, its aspect ratio is preserved,
  and its estimated token count (width × height ÷ 750) is recorded on the
  request.
- **AC-3** — Given a page image already smaller than 1568 px on its long edge,
  when it is prepared, then it is **not** upscaled.
- **AC-4** — Given a well-formed response naming every region index, when it is
  parsed, then each region receives its proposed English on the matching region
  id, and no region id is assigned a line belonging to another.
- **AC-5** — Given a response that omits region 3, when it is parsed, then
  region 3 is flagged `untranslated` and the other regions are still assigned —
  the page is not discarded.
- **AC-6** — Given a response naming a region index that does not exist on the
  page, when it is parsed, then a named error is raised identifying the bad
  index, and nothing is written.
- **AC-7** — Given a page whose regions are all `ocr_empty`, when the stage
  runs, then **no API call is made** and the page completes with no proposed
  lines. *(A page of wordless art must not cost money.)*
- **AC-8** — *(integration)* Given a real API call for one fixture page, when it
  completes, then `response.usage` is recorded, and the story's `## Notes`
  carries the **measured** input, output and thinking token counts, alongside
  the estimates in `docs/wiki/stack.md` §5/O4.

## Contract

```

    MAX_IMAGE_LONG_EDGE_PX: int = 1568
    def prepare_page_image(page: NDArray[np.uint8]) -> tuple[bytes, int]   # (jpeg, est_tokens)
    def build_request(page_image: bytes, regions: Sequence[OrderedRegion],
                      context: PageContext) -> MessageParams

src/mangatl/translate/parse.py
    def parse_lines(response: Message, region_ids: Sequence[int]) -> dict[int, str]
    class UnknownRegionIndex(Exception)

src/mangatl/translate/client.py
    MODEL_ID: str = "claude-opus-5"
    def translate_page(client: Anthropic, ...) -> TranslationResult

src/mangatl/translate/stage.py
    class TranslateStage:  # implements pipeline.Stage
        name = "translate"
```

**Call shape, settled — read these out, do not re-derive:**

- **Model `claude-opus-5`**, adaptive thinking (`thinking: {"type": "adaptive"}`
  — `budget_tokens` is rejected with a 400 on this model),
  `output_config: {"effort": "medium"}`.
- **Structured output** via `output_config.format`, not prefill — assistant
  prefill returns a 400 on this model. The response is a JSON object mapping
  reading index to English line.
- **Prompt caching**: the system prompt and the lettering style guide are the
  stable prefix and carry the `cache_control` breakpoint; the page image, the
  region list and the rolling context come **after** it. Anything volatile
  before the breakpoint invalidates the cache for every page, and the cost model
  assumes 19 cache reads per 20-page chapter.
- **`response.usage` is read on every response** and handed to MT-012. This
  story records it; MT-012 prices it.

**Semantics behind each number:**

- **1568 px** is Claude's documented image long-edge cap; beyond it the image is
  downscaled server-side anyway, so sending more is paying for bytes that are
  discarded. **`est_tokens = width × height ÷ 750`** is the documented image
  token rule and is what the budget guard projects with before a call is made.
- **`effort: "medium"`** rather than `high` because the cost model's sensitivity
  analysis (`docs/wiki/cost-model.awk`) shows the chapter crossing $2.00 at
  3,200 thinking tokens per page. AC-8 measures whether that is near.

**Oracle partition:**

| AC | Kind | Instruction to RED |
|---|---|---|
| AC-1, AC-4, AC-5, AC-6, AC-7 | **Mechanical** | Recorded response fixtures and a fake client. Pin the request shape and the parse behaviour exactly; assert AC-7 by asserting the fake client was **not called**, which is the only form that catches it. |
| AC-2, AC-3 | **Mechanical** | Arithmetic on dimensions. Enumerate at exactly 1568, one pixel either side, both orientations, and a square. |
| AC-8 | **Oracle-free** | A measurement, not a threshold. Record it; do not invent a pass/fail bar for it here — MT-013 is the story that enforces a bar. |

**Do not assert on translation quality in this story.** Quality is S1 and is
measured by MT-022 against a held-out chapter. A test here that asserts a
particular English string against a live model is a test that fails on a model
update for no reason.

## Deferred verifications

- *Falsifiable condition 1:* with `prepare_page_image` made to skip the resize,
  AC-2 **must** fail and the estimated token count must rise by the ratio the
  cost model predicts.
- *Falsifiable condition 2:* with `parse_lines` made to assign lines **by
  position in the response** rather than by region index — a plausible and
  entirely silent corruption — AC-4 **must** fail. Build the fixture so the
  response's key order differs from the region order, or this mutation passes.
- *Falsifiable condition 3:* with the `cache_control` breakpoint moved **after**
  the page image, `usage.cache_read_input_tokens` on the second page of a live
  run **must** drop to zero. This one cannot be checked without a live call; it
  is the check that proves the cost model's caching assumption.
- **Owner: GATES** for conditions 1 and 2, via `bash scripts/mutate.sh`.
  **Owner: GATES** for condition 3 as well, run once against the integration
  gate — or **WAIVED** with the reason recorded, if a live call is not
  affordable at that moment.

## Model guidance

This is the story where the *product's* model choice and the *harness's* model
choice are easy to confuse. They are unrelated.

- **The product's translation model is `claude-opus-5`**, settled above, and is
  not the agent's to change.
- **RED and GREEN agent models:** to be recorded at dispatch, by name. Defaults
  are `claude-opus-5` (Claude Opus 5).
- **Oracle partition mixed**; the table goes into the dispatch prompt verbatim,
  with the explicit instruction that the call shape (model id, thinking config,
  effort, structured output, cache placement) is **settled** and is to be read
  out of this contract. An agent that "improves" the call shape has changed the
  cost model.
- **Success condition, falsifiable:** RED's AC-4 fixture has a response key
  order that differs from the region order — so a position-based parser fails it
  — and AC-7 is asserted as "the client was not called", not as "no lines were
  produced". A suite where either is weaker has failed RED.
- **Verdict:** *to be recorded.*
