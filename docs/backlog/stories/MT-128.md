## Context

Filed by the EPIC-11 mutation audit, `docs/wiki/audits/EPIC-11-2026-11-01.md`:
survivors W01, W03, W02 and W26 (`## Decided` 4, `## Evidence` E-3). **The
audit's first priority for EPIC-11.**

**What is settled** (the audit's `## Decided`, not to be reopened):
- The four guards below are correct in production today and no test pins any
  of them.
- The fix is tests only. No production file changes.

**What is evidence, to verify rather than trust:** that each of the four
mutants below still survives at this story's base (re-run each command first),
and W01's reachability claim - that "Run again" stays enabled while a render
step is loading - which the audit read from the code (`_set_render_loading`,
`src/mangatl/ui/workspace.py:1356-1365`, changes only `render_button`) and did
not observe in the running app.

**The gap, one line each** (line numbers at `12108c9`):

- **W01** - `workspace.py:1422`, `_rerun`'s `or self.render_button.property("loading")`.
  Replaced with `or False`, all 1,926 tests in `tests/ui` pass. During a
  render's bake Run again is enabled, so this guard alone stops a run starting
  on the project the bake is reading.
- **W03** - `workspace.py:1344`, `_render_pages`'s `or self.run is not None`.
  Removed, all of `tests/ui` passes. `Workspace.render()` is the contract's
  public command (MT-066 C-4) and reaches `_render_pages` whatever the button
  says.
- **W02** - `workspace.py:1421`, `_rerun`'s `or self.run is not None`. Removed,
  all of `tests/ui` passes. Run again is disabled during a run, so tests only
  ever reach it through a disabled button; a `clicked` emission reaches it
  regardless.
- **W26** - `workspace.py:1420`, `_rerun`'s `or self._project is None`. Removed,
  all of `tests/ui` passes. No test presses Run again before `load_chapter`.

No required gate fails if this story's tests are absent: these are assertion
gaps under full line coverage. **Not in this story:** disabling Run again
during a render (that is a behaviour change and a design question, not a test
gap); any change to `workspace.py`.

## Acceptance criteria

- **AC-1** - Given a `Workspace` built with a logging `RunSetup`, a chapter
  loaded, and a render step in flight (the "Render pages" button in its
  loading state, as `_on_bake_dialog_finished` leaves it while a bake runs),
  when "Run again" is clicked, then no `RunSetup` callable is called, no
  `RerunDialog` opens, `window.run` stays `None` and no `run` row is written.
  This test **fails** under W01: `bash scripts/mutate.sh src/mangatl/ui/workspace.py '1422s/^            or self.render_button.property("loading")$/            or False/' -- uv run pytest -q tests/ui/test_rerun_guards.py`.
  *Control:* the same window with the render step finished (loading state
  cleared) - the click calls `resolve_models` and opens the dialog.
- **AC-2** - Given a run in progress started through Run again (the stage held
  on a gate so the run stays on), when `Workspace.render()` is called with no
  arguments, then no render starts: no bake preview is requested, the Render
  pages button does not enter its loading state, and no `BakeConfirmDialog`
  opens. This test **fails** under W03: `bash scripts/mutate.sh src/mangatl/ui/workspace.py '1344s/ or self.run is not None or / or /' -- uv run pytest -q tests/ui/test_rerun_guards.py`.
- **AC-3** - Given the same run in progress, when the Run again button's
  `clicked` signal is emitted directly (the disabled state bypassed), then no
  `RunSetup` callable is called beyond the first run's, no second dialog
  opens, and `window.run` is still the first `RunController`. This test
  **fails** under W02: `bash scripts/mutate.sh src/mangatl/ui/workspace.py '1421s/^            or self.run is not None$/            or False/' -- uv run pytest -q tests/ui/test_rerun_guards.py`.
- **AC-4** - Given a `Workspace` built with a logging `RunSetup` and **no**
  chapter loaded, when "Run again" is clicked, then nothing is raised, no
  `RunSetup` callable is called and no dialog opens. This test **fails** under
  W26: `bash scripts/mutate.sh src/mangatl/ui/workspace.py '1420s/^            or self._project is None$/            or False/' -- uv run pytest -q tests/ui/test_rerun_guards.py`.
