## Context

EPIC-13, after its closing audit. `docs/wiki/audits/MT-159-epic-13-done-when.md` (`## Decided`, line 2;
`## Evidence` E-2) found that on the paid run of the development set the
model marked three balloons on p075 as drawn art text: reading indices r0,
r2 and r3, which are truth balloons t0, t2 and t3 at IoU 1.0. Each is a
small closed balloon holding hand-lettered katakana that read as ガチャ. The
truth document has all three as `kind: bubble`, confirmed by the user on
2026-11-10. MT-147's own run marked the same three. So this is two runs of
one model version, not one.

**What it costs.** The app excludes an art-marked region with no proposal,
and baking leaves its Japanese as drawn (EPIC-13 U-4). The bench counts an
art-excluded truth balloon as missed (EPIC-13 PO-3). So `matched` fell from
238 to 235 on the paid run, and three balloons the user confirmed would
ship untranslated without anything in review saying a translation is
missing.

**The mechanism.** `pipeline/translate_stage.py`, `apply_answer`, is the one
place the answer's `art_text` list is applied, shared by the translate stage
and `pipeline/batch.py`. It marks every listed region `excluded = "art"`
unless the region is already excluded. Nothing checks the mark against the
page. The system prompt already says "Dialogue, narration and captions are
never art text, however they are lettered" (`translate/page_prompt.py`), and
the model marked these three anyway.

**The Lead PO's cut, open to the user.** The app does not apply an art mark
to a region whose text lies inside a closed balloon. The region stays
included with no proposal, which review already shows as a line that could
not be translated. A balloon is something the app can find on the page
without the model. A change to the prompt was not chosen: its effect can
only be seen with a paid run, and the prompt already says it.

**Q-1, to put to the user before this story leaves PLANNED.** With this
rule the balloon is kept but the model gave no English for it. Review then
shows it as not translated, and a bake made without review leaves the
balloon empty, where today its Japanese stays as drawn. The choices:

1. Kept and shown as not translated, as the criteria below say
   (recommended: the epic's goal is that review says so instead of shipping
   silently).
2. Kept, and the app asks the model again for that region alone. This is a
   second priced call on such a page and is not in this story as written.
3. Not wanted: the three balloons are a drawn sound, the truth document
   changes instead, and this story closes.

**To measure before the Contract is written (no paid call).** The rule is
only worth building if "inside a closed balloon" separates the three
balloons from real art text. The paid copy
`D:\bench\blackjack-v1-ep02-03-mt159-paid.mtproj` (read-only) stores the 12
art marks of that run: the three above, and nine art-text regions (p061 r3,
r4, r5; p066 r1; p070 r0; p071 r1; p072 r0; p089 r3; p097 r2). The proposed
test of "inside a closed balloon" is MT-154's: `typeset.interior` finds the
balloon whole around the region. It must hold for 3 of the 3 and for 0 of
the 9. If it does not, the planner reports the figures to the user and does
not tune the test until it does.

**What is settled.** The three regions, their truth indices and that the
user confirmed them as balloons. That `apply_answer` is the one place the
mark is applied.

**What is evidence, to verify.** "Closed balloons" is what three crops look
like to one reader (audit E-2). Whether the app's balloon search finds them
whole has not been measured. The nine art-text regions were classed by a
raster rule, not by eye.

**Required gate that would fail if this broke:** `unit`.

## Acceptance criteria

On synthetic pages (white paper, a drawn closed outline, text blobs), with a
page answer built by hand. "Inside a closed balloon" is the test the
Contract pins (`## Context`, "To measure"). No criterion needs a paid call.

- **AC-1** - Given a page whose region R holds text inside a closed balloon,
  and a page answer that lists R under `art_text` and gives proposals for
  the page's other regions, when the answer is applied, then R is not
  excluded, R holds no proposal and is not `misaligned`, and every other
  region holds the proposal the answer gave it.
- **AC-2** - *(control: real art text)* Given the same answer listing a
  region S whose text lies inside no closed balloon, when the answer is
  applied, then S is `excluded = "art"` and holds no proposal, exactly as
  today.
  *Control:* AC-1's page and AC-2's page differ only in the balloon's
  outline. The same answer excludes the region on one and keeps it on the
  other, so the outline is what decides.
- **AC-3** - Given AC-1's region R after the answer is applied and the
  page's run has finished, when its line's status is derived, then it is the
  status of a region the model gave no entry for (`failed`), so review shows
  it as not translated and the bake dialog counts it among the regions that
  will be left empty.
- **AC-4** - Given an answer that lists under `art_text` both a region
  inside a closed balloon and a region inside none, when the answer is
  applied, then the first is kept and the second is excluded: the rule is
  judged per region, not per page.
- **AC-5** - Given a region already excluded for another reason, when an
  answer lists it under `art_text`, then its exclusion reason is unchanged,
  whether or not it lies inside a closed balloon.
- **AC-6** - Given the same page and answer collected through the batch
  path, when the answer is applied, then the result in the store equals the
  translate stage's: one rule, in one place.
- **AC-7** - Given the 12 regions the model marked as art on the development
  set, read from the paid copy's store without any paid call, when the rule
  is applied to each on its own page, then it keeps p075 r0, r2 and r3 and
  excludes the other nine.
  *Control:* with the three kept, the bench on a scratch copy of the paid
  project prints `matched 238` and `spurious 23` under the development
  label: the no-spend run's `matched` and the paid run's `spurious`. If
  `spurious` rises, the rule kept an art-text region.
