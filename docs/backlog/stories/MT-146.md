## Context

EPIC-13 priority 2, the groundwork for U-4 and PO-2. MT-147 lets the page
answer mark a region as drawn art text. The region is then excluded:
no proposal, no typesetting, and the art put back at bake (MT-119). Today
`region.excluded` may be only `watermark` (the detector's rule, MT-121, never
switched on) or `user` (the workspace's Remove). The model's judgement is
neither. Folding it into `user` would make the bench (MT-148) and the user
unable to tell the pipeline's call from their own. Folding it into
`watermark` would be false.

SQLite cannot change a column's CHECK in place. Version 13 therefore rebuilds
`region`, with the recipe `_MIGRATE_TO_V10` uses for `llm_call` (renamed
aside, recreated, copied, dropped). The fresh schema and the migrated one
must declare byte-identical tables, which `test_schema_v8.py`'s pattern
holds.

Required gates: `unit`, `coverage`, `coverage-core` (`domain/**` at 100 %),
and `ui` for the row.

## Acceptance criteria

- **AC-1** - `RawRegion(..., excluded="art")` constructs.
  `EXCLUSION_REASONS == ("watermark", "user", "art")`, and any other string
  still raises naming the allowed values.
- **AC-2** - Given a fresh project, when `Project.set_excluded(ordinal, i,
  "art")` runs and the regions are read back, then that region reads
  `excluded == "art"`. Writing `"artwork"` raises before touching the file.
- **AC-3** - Given a version 12 project file holding regions with `NULL`,
  `watermark` and `user` exclusions, lines, a cleaned page and a glossary,
  when it is opened, then it is version 13. Every region, line and cleaned
  page is unchanged: same ids, same order, same blobs. `art` can now be
  written. And `sqlite_master.sql` for `region` is identical to a fresh
  version 13 file's.
- **AC-4** - *(control: the rebuild keeps its foreign keys)* After the
  migration, deleting a page still cascades to its regions and their lines,
  and `PRAGMA foreign_key_check` reports nothing.
- **AC-5** - Given an `art`-excluded region in the review workspace, then
  its row shows the excluded state MT-120 designed. Its caption reads
  exactly `Left as drawn: read as art text`, and its accessible name ends
  `removed from translation, read as art text.` Restore clears it to
  included, exactly as it does for `user`.
- **AC-6** - Pressing Remove on an `art` row's restored region writes
  `user`, never `art`: only the pipeline writes `art`.
