## Context

Filed by the EPIC-11 mutation audit, `docs/wiki/audits/EPIC-11-2026-11-01.md`:
survivors W19, W15 and W20 (`## Decided` 5, `## Evidence` E-3). Lower
priority than MT-128: none of these loses data or money; they are an
accessibility promise, a sentence's grammar, and a leak.

**What is settled** (the audit's `## Decided`, not to be reopened):
- These three behaviours of MT-125's run hand-over in
  `src/mangatl/ui/workspace.py` are correct today and no test pins them.
- The fix is tests only. No production file changes.

**What is evidence, to verify rather than trust:** that each mutant below still
survives at this story's base (re-run each command first). W20 was run against
`tests/ui/test_rerun_workspace.py` only, not all of `tests/ui`.

**The gap, one line each** (line numbers at `12108c9`):

- **W19** - `workspace.py:1467`, `_start_run`'s
  `self.setFocus(Qt.FocusReason.OtherFocusReason)`, which parks focus on the
  window before the body is hidden and both actions are disabled (MT-125 D-2).
  Replaced with `pass`, all 1,926 tests in `tests/ui` pass. Without it, focus
  is left on a hidden or disabled control.
- **W15** - `workspace.py:984`, `_return_sentence`'s
  `"page" if len(pages) == 1 else "pages"`. Changed to `== 0`, all of
  `tests/ui` passes: every fixture has four pages, so a one-page chapter's
  `Run finished. 1 of 1 page done.` is never read.
- **W20** - `workspace.py:1440`, `_rerun`'s `self.rerun_dialog.deleteLater()`
  for the previous dialog. Replaced with `pass`, `test_rerun_workspace.py`
  passes: no test presses Run again twice and counts what is left.

## Acceptance criteria

- **AC-1** - Given a `Workspace` with a chapter loaded and a `RunSetup` whose
  stage is held on a gate, with the Run again dialog open and focus on its
  primary, when the dialog is confirmed, then while the run is on the
  application's focus widget is neither hidden nor disabled (it is the
  `Workspace` itself or a visible, enabled descendant of it). This test
  **fails** under W19: `bash scripts/mutate.sh src/mangatl/ui/workspace.py '1467s/^        self.setFocus(Qt.FocusReason.OtherFocusReason)$/        pass/' -- uv run pytest -q tests/ui/test_rerun_handover.py`.
  If RED finds this mutant equivalent under the offscreen platform (Qt moving
  focus off a hidden widget by itself), RED stops and says so with the
  measured focus widget, rather than weakening the assertion.
- **AC-2** - Given a **one-page** chapter whose page is not done and a fake
  stage list that finishes it, when "Run again" is confirmed and the run
  finishes, then the live region announces exactly
  `Run finished. 1 of 1 page done.` This test **fails** under W15:
  `bash scripts/mutate.sh src/mangatl/ui/workspace.py 's/    noun = "page" if len(pages) == 1 else "pages"/    noun = "page" if len(pages) == 0 else "pages"/' -- uv run pytest -q tests/ui/test_rerun_handover.py`.
- **AC-3** - Given a `Workspace` with a chapter loaded, when "Run again" is
  activated, the dialog cancelled, and "Run again" activated a second time,
  then after deferred deletes are processed the window has exactly one
  `RerunDialog` child, and it is `window.rerun_dialog`. This test **fails**
  under W20: `bash scripts/mutate.sh src/mangatl/ui/workspace.py '1440s/^            self.rerun_dialog.deleteLater()$/            pass/' -- uv run pytest -q tests/ui/test_rerun_handover.py`.
