## Context

Filed by the EPIC-07 mutation audit, `docs/wiki/audits/EPIC-07-2026-10-22.md`:
survivors RS17 and RS13 (`## Decided` item 2, `## Evidence` E-2 items 1-2).
**This is the audit's highest priority.** It is the only survivor that moves a
verdict the user reads.

- **RS17.** `RESIDUAL_INK_MAX` (`src/mangatl/bench/residual.py:85`, `0.01`) is
  the bar S2's residual-ink half passes against. It can be changed to `0.02`,
  `0.001` or `0.0205` and all 291 bench tests stay green.
  - **Why.** Every assertion compares against the constant itself
    (`>= 10 * RESIDUAL_INK_MAX`, `< RESIDUAL_INK_MAX`,
    `math.nextafter(RESIDUAL_INK_MAX, ...)`). The only absolute check is
    `0 < x < 1` (`test_bench_residual.py:105-107`).
  - **The effect.** A doubled bar lets a clean that leaves twice the ink print
    `S2 PASS`.
- **RS13.** `measure_residual` skips a page with no matched truth region
  (`residual.py:161`, `if not matched: continue`). The module docstring says
  such a page "is not read at all, so it is never listed as measured on its
  source scan". With the skip removed, every bench test stays green.
  `test_ac4_with_no_matched_region_nothing_is_measured_and_the_worst_is_zero`
  runs exactly that scenario and never asserts `uncleaned_pages`.

**Settled** (the audit's `## Decided`): both are unprotected, and the code is
correct. Do not re-open whether 0.01 is the right bar: that is MT-023's
measured decision, to be revisited only on the real benchmark chapter.

**Evidence, verified at this story's base (`ecdef78`, 2026-10-23, PO, before
RED)** - the audit's `## Evidence` numbers this story relies on:

- RS17 at `0.02` and at `0.001`, against
  `tests/core/test_bench_residual.py tests/core/test_bench_s2.py`: `61 passed`
  both times (`mutate.sh`, restored and `cmp`-verified). Survives.
- RS13 (`if not matched:` -> `if False:`) against
  `tests/core/test_bench_residual.py`: `31 passed`. Survives.
- The cleaning-skipped figure: re-measured through `ink_fraction` on the
  fixture's page 0, region 0 - `0.205625` = `329 / 1600`, exactly the
  docstring's number. So AC-5's `skipped >= 10 * v` bounds the survivor range
  at `v <= 0.0205625`; the range between the three points is still inferred,
  not swept, which is why AC-1's over-side literal (`0.0125`) sits well inside
  it rather than near the edge.
- `16 / 1600 == 0.01` and `20 / 1600 == 0.0125` are exact in Python floats,
  and `0.01 <= 0.001` is `False`, `0.0125 <= 0.02` is `True` - the two
  controls in AC-1 do flip the verdict.

Required gate that fails if this breaks: `unit` (required; `covers
src/mangatl/**`) and `coverage-core` (required; `covers src/mangatl/bench/**`),
both over `tests/core`. No optional gate is involved, so `required_gates` stays

## Acceptance criteria

- **AC-1 (RS17).** The residual-ink bar is the measured 0.01, on both sides.
  - **Given** a matched truth region whose residual ink, as computed by
    `ink_fraction` on a luma array, is exactly `0.01`: when S2 is judged,
    `residual_ok` is `True`.
  - **Given** a region whose fraction is a literal value strictly between
    `0.01` and `0.0205` (for example `0.0125`): when S2 is judged,
    `residual_ok` is `False`.
  - Both fractions are written as literals in the test, never derived from
    `RESIDUAL_INK_MAX`.
  - *Control:* the test fails with `RESIDUAL_INK_MAX` set to `0.02` (the
    over-threshold case passes) and with it set to `0.001` (the at-threshold
    case fails).
- **AC-2 (RS13).** **Given** a chapter where no truth region on some page is
  matched, and no cleaned image is stored for that page, **when**
  `measure_residual` runs, **then** that page is absent from
  `uncleaned_pages`. With no matched region anywhere,
  `uncleaned_pages == ()`. Fails under RS13.

### Block 1 - the surfaces under test (existing, unchanged)

All in `src/mangatl/bench/residual.py` and `src/mangatl/bench/s2.py`. No
signature changes. No new export.

- `RESIDUAL_INK_MAX: float = 0.01` (`residual.py:85`). A region passes when its
  fraction is `<=` this. The comparison is `s2.py:72`,
  `all(region.fraction <= RESIDUAL_INK_MAX for region in residual.regions)`.
- `ink_fraction(cleaned: NDArray[np.uint8], mask: NDArray[np.bool_]) -> float`:
  fraction of `mask`'s pixels where `cleaned < INK_LUMA_MAX` (160) **and**
  `local_contrast(cleaned, within=mask) >= INK_CONTRAST_MIN` (64) over the 5x5
  window. `0.0` for an empty mask.
- `measure_residual(project: Project, truth: GroundTruth) -> ResidualReport`,
  with `ResidualReport(regions: tuple[RegionResidual, ...], worst: float,
  uncleaned_pages: tuple[int, ...])`. `uncleaned_pages` is, in page order,
  every page that was **read** for a measurement and had no cleaned image
  stored. A page with no matched truth region is skipped before any read
  (`residual.py:161-162`), so it is never in `uncleaned_pages`.
- `measure_s2(project: Project, truth: GroundTruth) -> S2Report`, with
  `S2Report(recall: RecallReport, residual: ResidualReport, recall_ok: bool,
  residual_ok: bool, passed: bool)`. `measure_s2` calls `measure_recall` and
  `measure_residual` as bare names from `s2.py`'s own globals (MT-023 A-2), so
  `monkeypatch.setattr(s2_module, "measure_residual", ...)` is the sanctioned
  seam - `tests/core/test_bench_s2.py::_with_reports` already uses it.

**Callers of changed signatures:** none - no signature changes. For the
record, the callers of the exports named above, checked against the tree
(`rg`, 2026-10-23): `measure_s2` is called from `src/mangatl/bench/s2.py:129`,
`src/mangatl/bench/__main__.py:71`, `tests/core/test_bench_main.py`,
`tests/core/test_bench_s2.py`; `measure_residual` from `s2.py:70` and
`tests/core/test_bench_residual.py`; `ink_fraction` from `residual.py:172` and
`tests/core/test_bench_residual.py`. Nothing this story writes changes what
any of them sees.

### Block 3 - AC-1's construction, verified by the PO at the base

- An isolated black pixel (luma 0) on white (luma 255) is ink by
  `ink_fraction`'s definition - its own luma is below 160 and its 5x5 contrast
  is 255 - while its white neighbours fail the luma test. So `k` isolated
  black dots inside a white 40 x 40 (1,600 px) mask score exactly `k / 1600`.
  Measured at the base: 16 dots -> `0.01` (`== 0.01` is `True`); 20 dots ->
  `0.0125` (`== 0.0125` is `True`). Dots at least one pixel apart; the
  fixture's `w.cleaned_page(ordinal, w.WHITE, extra_ink=[(x, y, x, y), ...])`
  draws a 1 x 1 inclusive box per dot inside the region, or RED builds the
  luma array directly with numpy.
- **Assert the fraction before the verdict**, both as literals: the
  `RegionResidual.fraction` (or `ink_fraction` result) `== 0.01` / `== 0.0125`,
  then `residual_ok is True` / `is False`. The string `RESIDUAL_INK_MAX` does
  not appear in the new assertions.
- **Where the verdict lives is RED's choice**, and both readings lead to the
  same code (none): either `measure_s2` on a `_s2_world` project whose cleaned
  pages carry the dots (every region found, so `recall_ok` is `True` and
  `passed` tracks `residual_ok`), or `ink_fraction` on a real luma array for the
  fraction and the A-2 seam to feed that measured fraction into `measure_s2`.
  The first is preferred because it reads the verdict the user reads.
