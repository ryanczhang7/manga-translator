## Context

Brief feature 2, and the story the brief's S2 metric attaches to. It also sets
the boundary that enforces the brief's firmest non-goal: **art-integrated sound
effects are never touched**, and that is a property of what this detector is
allowed to emit, not a filter applied downstream.

Read `docs/wiki/audits/MT-002-model-runtime.md` before starting. Its
`## Decided` section is **settled** — the runtime and the model file identity
are not to be re-litigated. Its `## Evidence` section is **not**: any latency,

`required_gates: [integration]` is set because one criterion (AC-7) genuinely

## Acceptance criteria

- **AC-1** — Given a fake session returning a known probability map, when
  detection post-processing runs, then it produces one region per connected
  component above the threshold, each with a polygon and a 1-bit mask of the
  same dimensions as the page.
- **AC-2** — Given a probability map with a component of area below
  `MIN_REGION_AREA_PX`, when post-processing runs, then that component produces
  no region.
- **AC-3** — Given a probability map with two components whose masks overlap,
  when post-processing runs, then two regions are produced and each region's
  mask contains only its own pixels.
- **AC-4** — Given a page, when detection runs, then every returned region's
  polygon lies entirely within the page bounds and every mask pixel outside the
  polygon's bounding box is zero.
- **AC-5** — Given a region, when its mask is stored and read back through
  MT-005's store, then it is bit-identical.
- **AC-6** — Given a fixture page carrying art-integrated sound effects outside
  any bubble, when detection runs with the shipped configuration, then **no
  region overlaps any pixel of the annotated SFX area**.
  *Control:* the same page with the SFX region annotated as a bubble must
  produce a region there — otherwise the assertion is passing because the
  detector finds nothing at all.
- **AC-7** — *(integration)* Given the real detector model and a real page
  fixture, when the session loads and runs, then it returns a probability map of
  the expected shape and dtype, and post-processing yields at least one region.

```
    MIN_REGION_AREA_PX: int
    def regions_from_probability(prob: NDArray[np.float32],
                                 page_size: tuple[int, int]) -> list[RawRegion]

src/mangatl/domain/region.py
    @dataclass(frozen=True) RawRegion:
        polygon: tuple[tuple[int, int], ...]   # page pixel coords, closed
        mask: bytes                            # PNG-encoded 1-bit, page-sized
        confidence: float                      # mean probability inside the mask
        kind: Literal["bubble", "box"]
```

**Semantics behind each number:**

- **`MASK_THRESHOLD`** is the probability above which a pixel is text. Raising
  it loses faint text; lowering it bleeds into screentone. It is **not settled
  here** — GREEN measures it on the fixture set and records the measurement and
  the two failure directions in `## Notes`. It is a number a later story may
  read out; it is a number this story must derive.
- **`MIN_REGION_AREA_PX`** exists to discard speckle, not to discard small
  bubbles. A single-kana bubble is legitimate and must survive; the floor is
  sized below the smallest annotated region in the fixture set, and the fixture
  that pins it is named in `## Notes`.
- **`confidence` is the mean probability inside the mask**, not the max. The max
  is 1.0 for almost every region and therefore carries no information.
- **`polygon` is in page pixel coordinates**, not model-input coordinates. The
  rescale from the model's input size back to the page is where an off-by-a-
  ratio bug lives, and AC-4 is what catches it.

**Oracle partition:**

| AC | Kind | Instruction to RED |
|---|---|---|
| AC-1..AC-5 | **Mechanical** | Fake session, synthetic probability maps you construct by hand. Pin exactly; these are arithmetic. |
| AC-6 | **Oracle-free** | The SFX exclusion has no settled metric. Invent one (pixel overlap against an annotated mask is the obvious candidate) and **demand the control named in the criterion fires hard**. | AC-7 | **Mechanical** | Shape, dtype, non-empty. A smoke test, nothing more. |

**Fixtures.** This story introduces `fixtures/pages/` with, at minimum: a page
with clean bubbles, a page with SFX outside bubbles, a page with overlapping
bubbles, a page with one single-kana bubble. Each needs a hand-made annotation
file. **These fixtures are development material and must never be the benchmark
chapter** (EPIC-07, O1).

## Deferred verifications

**Is AC-6's metric capable of failing?**

- *Falsifiable condition:* with post-processing forced to return an empty region
  list, AC-6 **must** fail (its control clause), and AC-1 **must** fail. With
  `MASK_THRESHOLD` set to 0.0 — every pixel is text — AC-6 **must** fail,
  because the single page-sized region overlaps the SFX area.
- *Why RED cannot run it:* there is no post-processing to mutate.
- **Owner: GATES.** Three mutations via `bash scripts/mutate.sh`, one of them a
  wrong *value* (`MASK_THRESHOLD`) rather than a removed behaviour.

## Model guidance

- **RED and GREEN models:** to be recorded at dispatch, by name. Defaults are
  `claude-opus-5` (Claude Opus 5).
- **Oracle partition is mixed and that is the important part of the brief**
  (table above): AC-1..AC-5 and AC-7 are to be pinned exactly; **AC-6 is the one
  place RED must invent a metric, and it is the one place a negative control is
  mandatory.** Put the partition in the dispatch prompt verbatim.
- **Success condition, falsifiable:** RED's AC-6 test fails by a wide margin
  against a deliberately over-eager detector (threshold 0.0) and passes against
  the fixture, with both numbers recorded in the handoff. If the separation is
  narrow enough that sampling noise decides it, the metric is wrong and the
  criterion goes back to the PO.
- **Verdict:** *to be recorded.*
