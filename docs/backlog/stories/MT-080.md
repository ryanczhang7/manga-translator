## Context

The user's request of 2026-10-09 (`EPIC-08`, MT-078 `## Context` PO-1 to
PO-3): translation must work with a Google Gemini key. MT-078 selects the
provider and leaves a `ProviderUnavailable` arm for `gemini`; MT-079 makes
the prompt and the parse provider-neutral. This story fills the arm: one
module that turns a page into one `google-genai` request and the response
into the same `TranslationResult` Claude's adapter produces, a rate-table row
so the ledger prices it, and a live measurement so the cost is a number.

**Default model: `gemini-3.1-pro`** (PO-2, the user, 2026-10-09).

**What is unverified, and must be confirmed from the official docs before it
is pinned - say in the handoff which page and which date:**

- Pricing (web search 2026-10-09, not the official page): Gemini 3.1 Pro
  **$2 in / $12 out per MTok** (≤200K prompt), **≈90% cached-input
  discount**. Context-cache *storage* has a separate hourly price this story
  does not use (implicit caching only).
- Every SDK call shape in `## Contract` C-2 and every usage field in C-3.
  **Do not invent SDK shapes.** The checkable mechanism is C-5: the live
  test, which is where a wrong kwarg becomes a `TypeError` or a 400.

**`MT-038` dependency lifted by the user, 2026-10-09 (PO-6).** The user has a
Google key and no Anthropic key, so Gemini goes first and MT-038 waits. This
story therefore carries the three gating edits MT-038 "What PLANNED must
settle" items 1-3 describe, written provider-neutrally so MT-038, MT-045 and
MT-081 inherit them from here: the `covers | integration |
src/mangatl/translate/**` line in `project.conf`; a credential case in the
`integration` gate's `blocked-when` covering a missing or rejected key for
**any** of the three providers, probed in `## Gate probes`; and an
`environment.md` section on the three key env vars, `MANGATL_PROVIDER`, and
what was measured on which machine.

**The cost model is Claude's.** `docs/wiki/cost-model.awk` and `stack.md`
§5/O4 are not re-derived for Gemini. This story records the *measured*
per-page cost and multiplies by 20 (PO-3). `BOOTSTRAP_PAGE_ESTIMATE` ($0.06,
Claude's figure) is what the guard projects from before three priced calls
exist; for a cheaper provider that is conservative, and after three pages it
is the observed mean. No guard change (MT-078 `## Context`).

**Which required gate would fail if this story's artifact broke:** `unit`
and `coverage` over `src/mangatl/translate/**`, `compose.py` and
`domain/rates.py` (and `coverage-core` over `domain`). The live test is under
the optional `integration` gate on purpose and is **not** in
`required_gates` (PO-3): it is discharged on the development machine and its
evidence is pasted into `## Notes`.

## Acceptance criteria

*Oracle partition: AC-1 to AC-6 are **mechanical** (fixtures, a fake client,
exact values). AC-7 is **settled** by the rate figures once confirmed from
the official page - read them out, do not derive. AC-8 is a **live
measurement** with no oracle: record, do not assert a cost.*

- **AC-1** — Given a page image, N OCR results and a `PromptContext`, when the
  Gemini request is built, then it carries exactly one image part (the
  1,568-px-capped JPEG from `page_prompt.prepare_page_image`), the system
  text `page_prompt.SYSTEM_PROMPT` in the SDK's system-instruction slot, the
  context text when the context is non-empty and **no empty part** when it is
  empty, and the listing `page_prompt.user_text(ocr_results)` as the last
  text part - the same five pieces Claude's request carries (MT-079 AC-1).
- **AC-2** — Given the request, then it asks for JSON output against
  `page_prompt.response_schema(N)` (or the closest schema the SDK accepts;
  C-2 says what may differ and why), names `MODEL_ID == "gemini-3.1-pro-preview"` (V-1),
  and caps output at `MAX_OUTPUT_TOKENS` (4096, Claude's figure, same reason).
- **AC-3** — Given a recorded well-formed response fixture keyed out of
  order (`2, 0, 3, 1`, as MT-011's is), when it is parsed, then each region
  gets the line keyed by its own index; a response omitting region 3 leaves 3
  absent; an unknown index raises `UnknownRegionIndex` - all via
  `parse_lines_text`, no new parser.
- **AC-4** — Given a response whose usage reports P prompt tokens of which C
  are cached, K candidate tokens and T thinking tokens, when it is converted,
  then `TokenUsage(input=P-C, output=K+T, cache_read=C, cache_write=0)`;
  given the cached and thinking fields are absent/`None`, they count as 0.
  *Control:* a conversion that forgets T under-reports output by the
  thinking volume (the one unmeasured input of the whole cost model); a
  conversion that does not subtract C bills cached tokens twice. The fixture
  has T > 0 and C > 0 so both mistakes change the numbers.
- **AC-5** — Given every region `ocr_empty`, when `translate_page` runs, then
  **no call is made** and the result is `TranslationResult({}, TokenUsage(0,0,0,0), call=None, ())`
  (MT-011 AC-7, same guard, same place).
- **AC-6** — Given a selection of `gemini`, when `build_pipeline(translate=True)`
  runs, then the bound translator is this module's `translate_page` with a
  `google.genai.Client` constructed **with `api_key=selection.api_key`
  explicitly** (never the SDK's own `GOOGLE_API_KEY`/`GEMINI_API_KEY` lookup:
  PO-1 names one variable, and the SDK reads two), and no `Anthropic` client
  is constructed.
- **AC-7** — Given `domain.rates.RATES`, then it lists `gemini-3.1-pro-preview` with
  the four confirmed figures, `RATE_TABLE_VERSION` is bumped in the same
  commit, and `price("gemini-3.1-pro-preview", usage)` reproduces one hand-computed (A-1)
  micro-dollar figure written in the test.
- **AC-8** — *(live, `network`; skips with no `GEMINI_API_KEY`)* Given the
  fixture page `spikes/MT-002/pages/011.jpg` with real OCR (MT-038's
  fixture), when one real call completes, then (a) the four usage counts, the
  priced cost, and **the model string the response reports** are printed and
  pasted into `## Notes`; (b) `price(call.model_id, usage)` does **not**
  raise `UnknownModel` - if the reported model string is not `MODEL_ID`, the
  reported one is added to the rate table (same figures) and that is a
  finding recorded in `## Notes`; (c) the parsed lines cover at least one
  region; (d) a second call within the cache window records
  `cache_read_tokens` - **recorded, not asserted > 0** (the user's MT-038
  answer; the ≈200-token stable prefix is likely below Gemini's implicit-cache
  minimum, which is a finding, not a defect); (e) measured cost × 20 is
  written beside the $2.00 ceiling in `## Notes` and in `stack.md` §5/O4's
  provider note.

### Export shape the tests already pin (fact, not suggestion)

`mangatl.translate.gemini` (new module; the tests reach it as
`from mangatl.translate import gemini`):

- `MODEL_ID: str == "gemini-3.1-pro-preview"`; `MAX_OUTPUT_TOKENS: int == 4096`.
- `build_request(page_image: bytes, ocr_results: Sequence[OcrResult], context: PromptContext) -> dict[str, Any]` - the shape is RA-1 above, exactly.
- `translate_page(client, page_image, ocr_results, context) -> TranslationResult`,
  positional in that order. Calls `client.models.generate_content(**build_request(...))`
  **once** and only when `not all(r.ocr_empty for r in ocr_results)`; otherwise
  returns `TranslationResult(lines={}, usage=TokenUsage(0,0,0,0), call=None, proposed_terms=())`
  without touching the client (an empty `ocr_results` is the same case).
  On a call: `lines=parse_lines_text(response.text, range(len(ocr_results)))`
  (`UnknownRegionIndex` propagates), `usage=_usage_of(response.usage_metadata)`,
  `call=CallInfo(request_id=response.response_id or "", model_id=response.model_version)`,
  `proposed_terms=parse_terms_text(response.text)`.
- `_usage_of(usage_metadata) -> TokenUsage` reading `prompt_token_count` (P),
  `cached_content_token_count` (C), `candidates_token_count` (K),
  `thoughts_token_count` (T): `TokenUsage(input_tokens=P-C, output_tokens=K+T,
  cache_read_tokens=C, cache_write_tokens=0)`, C/T `None` -> 0. Return type must
  be exactly `TokenUsage`.
- The fake response exposes `.text`, `.usage_metadata`, `.model_version`,
  `.response_id`, `.candidates[0].finish_reason`; the adapter may read no other
  attribute of it (a `SimpleNamespace` raises `AttributeError` on anything else).

import Client as GeminiClient`), and the `gemini` arm of `_translator` returns
