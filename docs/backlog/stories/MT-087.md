`layout.md` §"Review workspace" sizes the strip as "96px fixed (72px thumbnail +
`space.3` either side)" and the ≥1440 breakpoint row says "full 96px with

the filename per row. `RunThumbnail` (`ui/run_thumbnail.py`, MT-062) decodes a
page for the run screen at 120 × 160 with a plain `QImage(path)` and draws into
a rect derived from the `Page`'s stored dimensions, not the decoded image's —
that precedent (the geometry comes from the store) is reused here; the widget

**Pinned at PLANNED → RED on 2026-10-21** against `components.md` §`PageStrip`

## Acceptance criteria

- **AC-1** — Given a chapter of decodable pages, when the strip is at 96 px and
  the event loop has run until nothing is pending, then each row shows a
  thumbnail exactly `thumbnail_size(page.width, page.height)` (72 px wide,
  aspect from the page's stored dimensions) whose pixels are the page's, each
  page was decoded **once** (a decode counter equals the page count), and
  selecting rows, re-polishing or resizing within the wide regime decodes
  nothing more.
- **AC-2** — Given a page whose bytes do not decode, when the strip has run its
  queue, then that row's thumbnail area is the placeholder (no pixmap,
  `thumbnail_state == "failed"`), it was tried once and not retried, and the
  strip remains usable: selecting it shows the page-failed state naming the
  file and selecting a decodable page shows it (MT-015 AC-6's behaviour holds).
- **AC-3** — Given the window is below 1440, when the chapter is loaded and the
  event loop has run, then no thumbnail is shown and **none is decoded**
  (counter 0, every page pending); crossing to ≥ 1440 decodes them (counter =
  pages); crossing back hides them without discarding them; crossing up again
  shows them with the counter unchanged.
- **AC-4** — Given a chapter, when `load_chapter` returns, then no thumbnail
  has been decoded (counter 0, `pending_thumbnails() == pages`); decoding then
  proceeds in batches of at most `THUMBNAIL_BATCH` per event-loop tick, so the
  counter rises monotonically by at most `THUMBNAIL_BATCH` per `processEvents`
  pass until it reaches the page count. (PO-2: replaces the draft's wall-clock
  bound.)

**Block 1 — the decode helper** (`src/mangatl/ui/thumbnail.py`, new; `__all__`
lists all three):

```python
THUMBNAIL_WIDTH: int = 72          # layout.md: 72 px thumbnail, space.3 either side

def thumbnail_size(width: int, height: int) -> QSize
    # (THUMBNAIL_WIDTH, max(1, round(THUMBNAIL_WIDTH * height / width)));
    # from the Page's STORED dimensions (MT-062's precedent), never the decoded image's

def decode_thumbnail(path: Path, size: QSize) -> QImage | None
    # QImageReader(str(path)); setAutoTransform(True); if not canRead(): None;
    # setScaledSize(size); image = read(); None if image.isNull() else image —
    # the returned image's size() == size exactly. Never raises.
```

**Block 2 — `PageStrip`** (`workspace.py`). `set_pages(filenames, progress)` is
**unchanged**; thumbnails arrive through a second call:

```python
THUMBNAIL_BATCH: int = 4           # pages decoded per event-loop tick (PO-2)
                                   # A-1 (RED): a MODULE-level constant of
                                   # mangatl.ui.workspace (the test imports it
                                   # by name from there), not a class attribute

def set_thumbnails(self, source_dir: Path, sizes: Sequence[tuple[int, int]]) -> None
    # one (width, height) per page, parallel to set_pages' filenames; sizes each
    # row's thumbnail area to thumbnail_size(w, h) now (so rows do not reflow
    # when the image lands), resets the cache, queues every index in ordinal
    # order and starts the queue iff not is_rail.
def thumbnail(self, index: int) -> QPixmap | None        # the decoded pixmap, else None
def thumbnail_state(self, index: int) -> Literal["pending", "shown", "failed"]
def pending_thumbnails(self) -> int                       # the queue's length
```

The queue is a `QTimer(self)` with interval 0 (single-shot off): each timeout
pops up to `THUMBNAIL_BATCH` indices, calls **`decode_thumbnail` looked up on
the `mangatl.ui.workspace` module** (so a test may monkeypatch
`mangatl.ui.workspace.decode_thumbnail` to count or stub decodes), stores
`QPixmap.fromImage(image)` or records `"failed"`, shows it, and stops the timer
when the queue is empty. `set_rail(True)` **stops** the timer; `set_rail(False)`
restarts it iff the queue is non-empty. `set_pages` clears the cache and the
queue and stops the timer. A decoded or failed page is never decoded again for
the life of the chapter (until the next `set_pages`).

**Block 3 — the row** (`_PageRow`, `workspace.py`). Gains `thumb = QLabel()`,

Written by the Test Developer in RED, 2026-10-21. Every value is settled
(72, 12 + 72 + 12, `THUMBNAIL_BATCH == 4`, the two placeholder tokens and the
hairline, 1900 / 1500 / 1100 px) or mechanical (`thumbnail_size`'s formula,

`qtbot.waitUntil(lambda: strip.pending_thumbnails() == 0, timeout=10_000)`
(an upper bound on a state) or a fixed number of `processEvents()` passes
(`_IDLE_PASSES = 40`, ten times the 4 passes a 10-page queue needs) where the

widget integration on a **standalone `PageStrip`** with the packaged sheet

the **real `Workspace.load_chapter`** over real `create_project` projects. The
decode counter `_Decodes` monkeypatches `mangatl.ui.workspace.decode_thumbnail`
(block 2: the strip looks the helper up on that module) with a wrapper around
the real `mangatl.ui.thumbnail.decode_thumbnail` that records each path.

Fixtures: `three` = `001.png` tall 120 x 180, `002.png` broad 180 x 120, `003.png`
junk bytes (stored as 120 x 180); `ten` = ten decodable pages alternating tall
