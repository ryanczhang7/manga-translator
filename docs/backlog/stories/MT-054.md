## Context

**Filed 2026-09-30 by the Lead PO** as [[MT-017]] PO-1. EPIC-05's done-when says
the user can "open a chapter that has been translated … edit a line, revert it,
close the app, reopen it and find their edits". Every piece of that exists by
the end of MT-017 *except the first verb*: `mangatl.app.main` still opens the
empty `MainWindow`, because MT-015 PO-4 deferred wiring `Workspace` into the app
"until a story gives the window a chapter to open", and no story took it. This
is that story. It is small on purpose: it wires what exists, it does not design
a chapter picker.

The PLANNED → RED pass (contract, callers, deferred verifications) was done by
the Lead PO on 2026-09-30; the criteria below are frozen from here.

## Acceptance criteria

- **AC-1** — Given a folder whose sibling `.mtproj` project exists, when the app
  is launched with that folder as its one argument, then the review `Workspace`
  opens with the chapter's pages listed and the first page shown.
- **AC-2** — Given the app launched with such a folder, when a line is edited and
  the window is closed, and the app is launched again with the same folder, then
  the edit and its status are there (EPIC-05's done-when, end to end, through
  `mangatl.app.main`).
- **AC-3** — Given a folder with no project, when the app is launched with it,
  then the window says no project exists for that folder and names the command
  that creates one (`mangatl-run <folder>`, MT-006) - it does not create one
  silently.
- **AC-4** — Given no argument, when the app is launched, then it behaves as it
  does today (MT-001's smoke path is unchanged).

### C-1 — `src/mangatl/app.py`: `build_window` is the seam, `main` is a shell

```python
__all__ = ["build_window", "main"]

def build_window(arguments: Sequence[str]) -> QMainWindow: ...
def main(argv: list[str] | None = None) -> int: ...
```

`arguments` is the command line **without** the program name. `build_window`
constructs the window and returns it **not shown**; it never calls
`QApplication`, `show()` or `exec()`, so a test drives it under `qtbot` with no
event loop of its own.

`main(argv)` is, in this order and nothing more:

```python
argv = argv if argv is not None else sys.argv
app = QApplication(argv)
window = build_window(argv[1:])
window.show()
return app.exec()
```

Arguments are the Python list, not `app.arguments()` (the existing
`_FakeQApplication` has no `arguments()`; see C-6). `main` keeps its signature.

*RED amendment:* the tests reach the project and the window through
`mangatl.app`'s own namespace, so two import shapes are pinned: `mangatl.app`
imports `open_project` **by name** (`from mangatl.store.project import
open_project, ...`) and `build_window` calls it by that bare name (not
`project_module.open_project`), and `main` calls `build_window` by its bare
module-global name. `monkeypatch.setattr(app_module, "open_project", ...)` /
`(app_module, "build_window", ...)` is how C-4's "the connection is closed" and
AC-2's "the window `main` built" are observed without adding production API; a
call through another path makes those tests see nothing (`IndexError` /
`len(opened) == 1` fails).

### C-2 — What `build_window` returns, by case

`folder = Path(arguments[0]).resolve()` wherever a folder is named below.

| # | `arguments` | Returns |
|---|---|---|
| 1 | `[]` | `MainWindow()` — exactly today's window (AC-4) |
| 2 | one, `folder` is not a directory | `MainWindow(notice=NO_FOLDER_NOTICE.format(folder=folder))` |
| 3 | one, directory, `project_dir_for(folder) / "project.db"` absent | `MainWindow(notice=NO_PROJECT_NOTICE.format(folder=folder))` (AC-3) |
| 4 | one, project opens | a `Workspace`, chapter loaded, **page 0 current and shown** (AC-1) |
| 5 | one, `open_project` raises `SchemaTooNew` | `MainWindow(notice=str(error))` |
| 6 | two or more | `MainWindow(notice=USAGE_NOTICE)` |

Case 3 is decided by `open_project` raising `FileNotFoundError` (it checks the
path before sqlite can create anything) or by an equivalent `is_file()` check;
either way **nothing is written**: after case 3 neither `<folder>.mtproj` nor
anything inside `folder` exists that did not before (AC-3's "not silently").
`create_project` is not imported by `mangatl.app`.

Case 4, precisely: `project = open_project(project_dir_for(folder))`;
`window = Workspace()`; `window.load_chapter(project)`;
`window.page_strip.setCurrentRow(0)` (which reaches `show_page(0)` through the
existing `currentRowChanged` connection); the project's lifetime is then tied to
the window per C-4. Observable: `page_strip.count() == len(chapter.pages)`, the
strip's item texts are the page filenames in ordinal order,
`page_strip.currentRow() == 0`, `page_canvas.state() == LOADED`, and the
translation column holds page 0's rows. A chapter always has ≥ 1 page
(`read_chapter` raises `NoPagesFound` otherwise), so no zero-page branch is
built.

### C-3 — The notice texts (`src/mangatl/app.py`, exported constants)

Exact strings; RED asserts them character for character after `.format`:

```python
NO_PROJECT_NOTICE = (
    "No project exists for {folder}.\n"
    'Create one by running:  mangatl-run "{folder}"'
)
NO_FOLDER_NOTICE = "No such folder: {folder}"
USAGE_NOTICE = "mangatl opens one chapter folder:  mangatl <folder>"
```

The folder is always the **resolved absolute** path, so the command in the
notice works pasted into any shell from any directory; double quotes because
Windows paths carry spaces. `mangatl-run` is MT-006's console script
(`pyproject.toml` `[project.scripts]`), the only thing that creates a project.

### C-4 — Closing the window closes the project, after the pending save

`src/mangatl/ui/workspace.py`: `Workspace` gains `closed = Signal()`, emitted as
the **last** statement of `closeEvent`, after `translation_column.flush()` and
`super().closeEvent(event)`. `build_window` case 4 connects it to close the
`Project` (`project.__exit__(None, None, None)`, or a `close()` method GREEN adds
to `Project` if it prefers — its choice, not a test's).

Observable: after `window.close()`, `project.select("SELECT 1")` raises
`sqlite3.ProgrammingError` (closed connection); and an edit committed with
`Enter` and followed **immediately** by `close()` — inside the 500 ms debounce,
no wait — is on disk (the flush ran before the close). Emitting `closed` before
the flush loses that edit; that is the C-4 ordering control (D-3).

`Workspace` constructed without `build_window` (every existing test) has
nothing connected to `closed`, so it changes nothing for them.

### C-5 — `src/mangatl/ui/main_window.py`: `MainWindow(notice=None)`

```python
NOTICE_OBJECT_NAME = "notice"
class MainWindow(QMainWindow):
    def __init__(self, notice: str | None = None) -> None: ...
```

- `notice is None`: byte-for-byte today's behaviour — central widget a plain
  `QWidget` whose accessible name is `CANVAS_ACCESSIBLE_NAME` (AC-4).
- `notice` given: title still `WINDOW_TITLE`; central widget is a `QLabel` with
  `objectName() == NOTICE_OBJECT_NAME`, `text() == notice`,
  `accessibleName() == notice` (the accessibility floor: the whole content of
  the window is readable by a screen reader), word-wrapped, and
  `textInteractionFlags()` including `TextSelectableByMouse` and
  `TextSelectableByKeyboard` so the user can copy the command. Plain text
  (`Qt.TextFormat.PlainText`): a folder name containing `<` must not be parsed
  as markup.
