## Context

EPIC-13 enabler. Every fix in the epic has to be measured before and after
on pages that are **not** the held-out benchmark (`product-brief.md` O1;
EPIC-13 "Evidence"). The bench refuses any truth document flagged
`development_use: true`, both in `load_ground_truth`'s default mode and inside
`measure` (MT-022 AC-8). That refusal is right for the headline and stays
the default. This story adds a deliberate, visibly labelled way to measure a
development document, so that a development figure can never be mistaken
for a benchmark result.

Required gates: `unit`, `coverage`. No optional gate is involved.

## Acceptance criteria

- **AC-1** - Given a truth document flagged `development_use: true` and its
  project, when `python -m mangatl.bench FOLDER --development` runs, then it
  exits `0` and prints the same report as a benchmark run would. The first
  line printed is exactly `DEVELOPMENT SET - not a benchmark result`, and
  every S-line (`S1b`, `S1a`, `S2`, `S5`) carries the suffix
  `  [development]`.
- **AC-2** - Given the same document, when the bench runs **without**
  `--development`, then it still refuses with
  `BenchmarkChapterUsedInDevelopment` and exits `2` (MT-022 AC-8 unchanged).
- **AC-3** - *(control: the flag cannot relabel the benchmark)* Given a
  document flagged `development_use: false`, when the bench runs with
  `--development`, then it exits `2` and prints nothing on stdout. Its
  stderr names the chapter and says it is the held-out benchmark.
- **AC-4** - Given a flagged document handed directly to `measure`,
  `measure_recall` or `measure_s2`, when the call passes
  `development=True`, then it measures. When it does not, it raises as
  today. And `development=True` with an unflagged document raises
  `NotADevelopmentSet`.

### C-1 Signatures

```python
# bench/truth.py is NOT changed; the refusal stays its own.
class NotADevelopmentSet(Exception): ...          # bench/acceptance.py, re-exported by s2/recall

def measure(project, truth, *, development: bool = False) -> AcceptanceReport
def measure_recall(project, truth, *, development: bool = False) -> RecallReport
def measure_s2(project, truth, *, development: bool = False) -> S2Report
```

`__main__` loads with `load_ground_truth(path, benchmark=not development)`
and threads the flag through. `render_*` functions are unchanged. The label
and the suffix are added in `__main__` alone, so the standalone
`bench.acceptance` and `bench.s2` commands keep refusing (no flag for them in
this story).

### C-2 Callers of the changed signatures

The new parameters are keyword-only with a default, so no existing caller
changes. RED lists `rg -n "measure\(|measure_recall\(|measure_s2\("
src tests` in its handoff to confirm.

### C-3 Oracle partition

All four criteria are **mechanical**: pin the strings exactly.
