## Context

EPIC-10 PO-4. The only evidence that `kind == "box"` (the detector's box-head
class 0) means "scanlation watermark" is MT-007 amendment A-4: across
`011-015.jpg`, 4 class-0 boxes of 38, every one cropped and looked at, every
one `DL-Raw.Se` / `RawLazy.Com`. Four boxes on five pages of one chapter say
nothing about a narration box, a caption strip, a signboard or a thought
rendered outside a bubble - all of which are text to translate and all of
which are "text not in a bubble", which is the obvious reading of a two-class
head. If class 0 is "any text outside a bubble", an automatic exclusion on it
silently drops real dialogue, and nothing downstream would notice: the region
simply has no line.

This spike answers that before MT-121 is allowed to implement the rule. It is
local - the detector runs on the development machine, no API is called - and
its output is a document: `docs/wiki/audits/MT-117-class-zero-regions.md`,
with the sections `## Scope`, `## Decision rule`, `## Measurement`,
`## Decided`, `## What was not checked`, following `docs/wiki/audits/TEMPLATE.md`
where the two agree. MT-121 reads its predicate out of `## Decided`.

**The decision rule is written before the measurement** (`story-authoring`,
"When the story depends on an audit or a spike"), in `## Decision rule`, and
is the one proposed here unless the user sets another (EPIC-10 Q-2):

- **R-1** - The predicate `kind == "box"` is adopted as the automatic rule if
  at least **10** class-0 regions were examined across at least **2**
  chapters, and **none** of them is translatable text (dialogue, narration, a
  caption, a sign, a thought) - every one is a watermark, a URL, a credit, or
  not text at all.
- **R-2** - If one or more class-0 regions is translatable text, the audit
  states a narrower predicate only if it can be stated mechanically over
  fields the store holds (`kind`, `polygon`, `confidence`, `source_ja`) and
  separates every watermark seen from every translatable region seen with a
  margin the audit records; otherwise `## Decided` says **no automatic rule**
  and MT-121 closes as a no-op with the audit cited.
- **R-3** - If fewer than 10 class-0 regions exist on every page available,
  the audit says so, records what was seen, and `## Decided` still answers
  R-1 or R-2 on what there is, marked **under-powered**, so that MT-121's
  story records the thinness rather than inheriting a confidence the data
  does not carry.

**Pages** (EPIC-10 Q-3): the five spike pages at `spikes/MT-002/pages`
(gitignored, on this machine); the user's sample chapter, whose folder the
user names; the benchmark chapter if the user allows it (its truth file
carries human `kind` labels, `bench/truth.py`). The user supplies the paths;
the orchestrator runs the measurement, as MT-101's probe was run.

**Does every bubble come out class 1?** The spike also records the converse
on the same pages - how many class-1 regions are *not* dialogue - because a
rule that excludes class 0 is only as good as class 1 is complete. A-4's
cross-check on `014.jpg` (nine OCR-confirmed bubbles, all class 1) is the
baseline; the spike extends the count.

No gate judges a document; `required_gates` stays empty (MT-068 PO-4).

## Acceptance criteria

A spike's criteria are about what is *known* at the end.

- **AC-1** - `## Decision rule` reproduces R-1 to R-3 above, or the rule the
  user set in their place, dated, **before** `## Measurement` in the document
  and in the commit history: the rule's commit precedes the measurement's.
- **AC-2** - `## Measurement` lists every class-0 region found on every page
  measured - page, reading index, bounding box, `confidence`, what OCR read
  (`transcribe_page_regions` on the crop), and a one-word human reading from
  {watermark, url, credit, narration, caption, sign, dialogue, sfx, not-text}
  made by looking at the crop - and states the totals: pages, regions, class-0
  regions, class-1 regions, per chapter.
- **AC-3** - `## Measurement` lists every class-1 region whose human reading is
  **not** dialogue or narration, the same way, so the converse is on record.
- **AC-4** - `## Decided` states, as `D-1`, exactly one of: the predicate
  `kind == "box"` is the automatic rule (R-1 met); a narrower predicate, stated
  as a boolean over named store fields with the separating margin measured
  (R-2); or no automatic rule (R-2 failed, or R-3 under-powered and the PO
  declines). It names the pages the decision rests on and the count behind it.
- **AC-5** - The measurement script is written **inside the document** as a
  fenced block, runnable from the repository root with the page folders as
  arguments; the document records the command run and the detector weights'
  hash (`models/` manifest) it ran against. No code is committed.

## Contract

**Writes:** `docs/wiki/audits/MT-117-class-zero-regions.md`

- The document has the five sections named in `## Context`, in that order.
  `## Decided` is a list `D-1 ... D-n`, one sentence each plus the evidence
  line it rests on, so MT-121 cites `MT-117 D-1`.
- The script uses only what the tree already has: `mangatl.detect.page
  .detect_page_regions` bound to the real session (`compose`), and
  `mangatl.ocr.page.transcribe_page_regions`. It prints one row per region.
  The crops it saves for the human reading go under `spikes/MT-117/` -
  gitignored, never committed (the pages are non-redistributable scans,
  `fixtures/detect/README.md`).
- Oracle partition: AC-1, AC-4 and AC-5 are **mechanical** (a section exists,
  a sentence has a given shape, a commit order holds). AC-2 and AC-3 are
  **oracle-free** on the human reading column - it is a person looking at a
  crop - and **settled** on every other column, which is read out of the
  detector and the store, never re-derived. No control beyond R-1's own: a
  decision rule that could come out either way.
- No test-only dependency; no code.
