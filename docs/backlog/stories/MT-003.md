## Context

`docs/wiki/architecture.md` §3 states five import contracts. Without a tool
refusing them, a Qt project accrues `from ...ui import` in its core within a
month, and the two that matter most — "only `translate` imports `anthropic`"
and "nothing imports `ui`" — are the ones that make two load-bearing claims
checkable rather than aspirational: that there is exactly one place API spend
can originate, and that the whole pipeline can be driven in a test with no
display.

MT-001 wires `lint-imports` into the `lint` gate command. This story writes the
contracts and probes each one.

**Which required gate would fail if this story's artifact broke:** `lint`. The
contracts live in `pyproject.toml`, which is `config`, so this is a GREEN-phase
write; the probes are what make it a gate rather than a file.

## Acceptance criteria

- **AC-1** — Given the five contracts configured, when `uv run lint-imports`
  runs on a clean tree, then it reports `Contracts: 5 kept, 0 broken`.
- **AC-2** — Given a module in `pipeline` that imports `mangatl.ui`, when the
  `lint` gate runs, then it fails and names the contract and the offending
  module.
- **AC-3** — Given the same violation written as a **relative** import
  (`from ...ui import X`), when the `lint` gate runs, then it fails too.
- **AC-4** — Given a module in `domain` that imports `numpy`, when the `lint`
  gate runs, then it fails.
- **AC-5** — Given a module outside `translate` that imports `anthropic`, when
  the `lint` gate runs, then it fails.
- **AC-6** — Given a module outside `detect`, `ocr` and `clean` that imports
  `onnxruntime`, when the `lint` gate runs, then it fails.
- **AC-7** — Given `.claude/harness/project.conf`, when it is read, then
  `floor | lint | 5` is present, so a contract silently disappearing is caught.

## Contract

**Where the contracts live:** `pyproject.toml`, `[tool.importlinter]` and
`[[tool.importlinter.contracts]]`. One file; do not add a `.importlinter`
dotfile.

**The five contracts, exactly as `architecture.md` §3 states them:**

1. `layers` — `mangatl.ui` above `mangatl.pipeline` above the stage packages
   (`detect`, `ocr`, `translate`, `clean`, `typeset`, `bench`) above
   `mangatl.store` above `mangatl.domain`.
2. `forbidden` — `mangatl.domain` may not import `numpy`, `PIL`, `PySide6`,
   `onnxruntime`, `anthropic`, or any other `mangatl.*` package.
3. `forbidden` — nothing imports `mangatl.ui` (including `mangatl.bench`).
4. `forbidden` — only `mangatl.translate` imports `anthropic`.
5. `forbidden` — only `mangatl.detect`, `mangatl.ocr` and `mangatl.clean`
   import `onnxruntime`.

**AC-3 is not a duplicate of AC-2 and must not be collapsed into it.** This is
the specific failure this story exists to prevent: a boundary rule probed only
in absolute-import form was found to catch the aliased crossing and miss the
relative one — which is the form somebody actually crosses a boundary with by
accident. Two probes, two pasted outputs.

**Oracle partition: mechanical.** Every criterion is "this configuration
produces this tool output". Pin it exactly. There is nothing to calibrate and
nothing to invent.

### Pinned by the orchestrator at dispatch, 2026-09-12

**RED may amend any block below in place, with a reason. GREEN builds what the
amended block says.**

**P1 — `include_external_packages = True` is mandatory, and its absence is a
hard error, not a silent pass.** Contracts 2, 4 and 5 forbid *external* modules
(`numpy`, `PIL`, `PySide6`, `anthropic`, `onnxruntime`). `[tool.importlinter]`
currently declares only `root_packages = ["mangatl"]`.

Measured by the orchestrator out-of-tree, on a throwaway package, so this is not
a claim:

```
=== WITHOUT include_external_packages:
The top level configuration must have include_external_packages=True when there
are external forbidden modules.

=== WITH include_external_packages:
core may not import PySide6
---------------------------
foo.core is not allowed to import PySide6:
-   foo.core -> PySide6 (l.1)
```

So the `lint` gate **fails loudly** without it rather than reporting a vacuous
`kept` — which is the good outcome, and worth stating because the opposite was
assumed. Add the line; do not spend a cycle discovering it.

**P2 — `mangatl.app` must be excluded from contract 3's `source_modules`, and
that is correct rather than a loophole.** `src/mangatl/app.py` line 9 is
`from mangatl.ui.main_window import MainWindow` — the entry point's whole job is
to open the window. MT-001 already excludes it. A contract phrased as "nothing
at all imports `mangatl.ui`" breaks `bash scripts/task.sh dev`. Contract 3's
source list is the nine non-`app` packages, and `architecture.md` §3's "nothing
imports `ui`" means "nothing *below the entry point*".

**P3 — three of the five contracts will pass vacuously, and that is the whole
reason this story is gate probes rather than a config edit.** Measured on the
current tree: every package under `src/mangatl/` except `app`, `domain/money.py`
and `ui/main_window.py` is an empty `__init__.py`; `domain/money.py` imports only
`dataclasses` and `decimal`; and **`anthropic` and `onnxruntime` appear nowhere
in `src/`**. So contracts 1, 4 and 5 have nothing to check and will report
`kept` having done nothing. `Contracts: 5 kept` is therefore **not** evidence
that the contracts work. Only `## Gate probes` is.

**P8 — the stage layer is INDEPENDENT: `|`, not `:`. Confirmed by the user
2026-09-13.** This is the one thing the first RED attempt escalated rather than
guessed, and it was right to. `architecture.md` §3 clause 1 groups the six stage
packages in parentheses and says only "imports go down only" — silent on whether
they may import *each other*. `import-linter`'s `LayerField` needs it stated:
`|` makes siblings independent, `:` lets them import each other.

Contract 1's stage line is therefore:

```
"mangatl.detect | mangatl.ocr | mangatl.translate | mangatl.clean | mangatl.typeset | mangatl.bench"
```

Three reasons, now also recorded in `architecture.md` §3 so this is not
re-litigated:

1. `pipeline` is the orchestrator. If stages import each other directly, the
   orchestration is a fiction and the layer above it is decorative.
2. Contract 5 confines `onnxruntime` to `detect`/`ocr`/`clean`. That confinement
   **leaks transitively** the moment `typeset` or `bench` may import `detect`.
3. `coverage-core` demands **100%** coverage of `domain`, `typeset` and `bench`.
   Unreachable if `bench` can pull in a stage that loads ONNX.

If a later story genuinely needs a stage-to-stage import, amending this contract
deliberately is the system working. That is what a gate is for.

**P9 — contract 2's forbidden list uses the expression `mangatl.*`**, not ten
explicit module names. It is what §3 literally says ("nothing else of ours"), and
it covers a package a future story adds. Verified with `--verbose` against the
real graph: it expands to `app, bench, clean, detect, ocr, pipeline, store,
translate, typeset, ui`, with `Skipping overlapping modules mangatl.domain and
mangatl.domain`.

**Contracts 3, 4 and 5 stay explicit.** Each needs an exclusion a wildcard
cannot express, and explicitness is what makes P4's "`bench` quietly dropped
from contract 3" regression catchable by the shape test.

**P10 — P1 is confirmed in source, not only out-of-tree.** `forbidden.py`'s

## Out of scope

Any change to the package layout. Any new production module. Any relaxation of

## Deferred verifications

**AC-2 through AC-6 cannot be verified in RED, and RED must decline them rather
than claim them.** Each asserts that the `lint` gate *fails* on a specific
boundary crossing. In RED the contracts do not exist, so breaking a boundary
demonstrates nothing — the gate would pass, or fail for the wrong reason.

**Owner for all five: GATES.** Source and config are writable there, which is
what a probe needs. They are discharged as `## Gate probes` entries, and
`check-boundaries.sh` refuses a PR whose probe section describes a failure
without showing one.

Each entry is discharged by: making the change, running `uv run lint-imports`
(or the whole `lint` gate), pasting the output showing the contract broken **and
named**, reverting, and confirming the revert. Use `bash scripts/mutate.sh`,
which restores the file and verifies the restore with `cmp` — `sed -i` on
production source is working around the lock.

**"Config half" means exactly that, and it is the honest limit of this file.**
These tests prove the contract is *written*; they do not prove it *rejects*
anything. That is DV-1..DV-5, owned by GATES. See the decline in the handoff.

Tests 7 and 8 overlap deliberately: 7 pins the whole list (so it also catches

**Edges covered.** Zero (`[tool.importlinter]` or a contract absent → a named
