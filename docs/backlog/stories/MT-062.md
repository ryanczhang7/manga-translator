## Context

**Filed 2026-10-01 by the Lead PO**, on the user's decision to split
[[MT-018]] AC-3 out (MT-018 `## Amendments` A-1).

`components.md` §8 `RunProgressPanel`: "the page thumbnail with markers
appearing as they are detected, beside a `PageStageStepper`". MT-018 built the
panel and the stepper. This story adds the thumbnail, which needs two things
the event stream does not carry today:

- the detected regions of the current page - no `RegionsDetected` event exists
  in `mangatl.domain.events`;
- the page image - no event carries a path, and the panel may not read the
  store (MT-018 `## Contract`, "The boundary": "the event stream is missing an
  event and MT-006's contract should be amended rather than the boundary
  crossed").

So it amends the event contract (a new frozen dataclass in `domain.events`,
inside `coverage-core`'s 100% set) and has the pipeline emit it after
detection, then renders it.

## Acceptance criteria

- **AC-1** — Given `RegionsDetected` events for the current page, when they
  arrive, then markers appear on the current-page thumbnail as they are found.
  *(Carried verbatim from MT-018's original AC-3.)*

*Refined by the Lead PO at PLANNED → RED (2026-10-01), as this story's own
text asked; AC-1 is unchanged and AC-2..AC-4 say what it rests on (PO-1..PO-3).*

- **AC-2** — Given a page the detect stage runs on, when its regions have been
  written, then the stage emits exactly one `RegionsDetected` for that page,
  carrying every region's polygon in the reading order they were stored in (an
  empty tuple when the page has none); a page whose detection is skipped as
  already done emits none.
- **AC-3** — Given `PageStarted` for a page, when it arrives, then the
  thumbnail shows that page's image, read from the chapter's own folder, with
  no markers; a `RegionsDetected` for any page other than the current one
  changes nothing.
- **AC-4** — Given a run started from the window ([[MT-059]]), when the run
  screen appears, then its panel shows the thumbnail for the chapter being run;
  the panel reads nothing from the project store.

**C-1 — the event (`mangatl.domain.events`, `coverage-core`'s 100 % set).**

```python
@dataclass(frozen=True)
class RegionsDetected:
    """The page with this ordinal has been detected and its regions stored."""
    ordinal: int
    polygons: tuple[tuple[tuple[int, int], ...], ...]   # page pixels, closed rings, reading order
```

Data only, as every event (MT-006 PO-4): no method, no validation. Added to
`__all__` and to the `RunEvent` union. **Polygons, not `RawRegion`s:** a
region's mask is a page-sized PNG, and the event crosses a thread (MT-059) to a
widget that draws outlines.

**C-2 — the emitter: `DetectStage.run`** (`mangatl.pipeline.detect_stage`).
After `ctx.project.write_regions(ordinal, ordered)` returns:
`ctx.emit(RegionsDetected(ordinal=ctx.page.ordinal, polygons=tuple(r.polygon for r in ordered)))`.
After the write, so a consumer that reads the store on receipt sees the same
regions (MT-063's "after the write" rule for `CallPriced`); from `ordered`, so
the order is the stored reading order. A stage whose `is_done` skips it emits
nothing (the runner never calls `run`). In the stream it falls between the
page's `PageStarted` and the runner's `StageFinished(stage="detect")`.

**C-3 — the thumbnail (`mangatl.ui.run_thumbnail`, new).**

```python
class RunThumbnail(QWidget):
    def show_page(self, ordinal: int, image_path: Path, width: int, height: int) -> None  # new image, no markers
    def set_regions(self, polygons: Sequence[Sequence[tuple[int, int]]]) -> None
    def markers(self) -> tuple[QPolygonF, ...]   # in widget coordinates, as painted
    def image_rect(self) -> QRectF               # where the page is drawn, aspect kept
```

`markers()` is each polygon mapped from page pixels (`width` x `height`, the
`Page`'s own dimensions, not the decoded image's) onto `image_rect()`:
`x' = rect.x + x * rect.width / width`, `y' = rect.y + y * rect.height / height`.
An image that does not decode follows `## Design notes`; it never raises.

## Design notes

Normative source: `components.md` §8 `RunThumbnail` (amended for this story).
Restated here so RED can pin it.

**Layout.** A row `QHBoxLayout`, object name `run-current-page`, takes the
stepper's place in the panel column (after `run-overall`, before the times
row): `run-thumbnail` left, `stage-stepper` right and top-aligned, spacing
`space.4` (16). The stepper is otherwise unchanged. With no chapter
(C-4, `thumbnail is None`) the row holds the stepper alone.

**Widget.** `RunThumbnail`, object name `run-thumbnail`, fixed size
**120 × 160 px** (`setFixedSize`). Ground `color.surface.sunken`,
`border.width.hairline` `color.border.subtle`, radius 0, from the stylesheet
rule `#run-thumbnail`. Not a focus stop (`Qt.NoFocus`); accessible role
`QAccessible.Graphic`. Why 120 × 160: the run column is ≤ 720 px wide and the
window ≥ 720 px tall; 160 px is ~2.2× the `PageStrip`'s 72 px thumbnail, enough
to see where regions are, and 3:4 fits a single manga page with little slack.

**Geometry (`image_rect()`).** Content box = the widget rect inset by 1 px:
`(1, 1, 118, 158)`. `image_rect()` is the page's `width × height` scaled by
`s = min(118 / width, 158 / height)` and centred in the content box; C-3's
mapping then reduces to `p' = image_rect().topLeft() + p·s`. The image is drawn
into `image_rect()` (smooth scaling); painting is clipped to the content box.
Worked case (C-7's 1000 × 1500 page): `s = 158/1500 = 0.10533…`,
`image_rect() = (7.3333…, 1, 105.3333…, 158)`; page point `(300, 600)` →
`(38.9333…, 64.2)`.

**Markers.** Outline only: no fill, no ordinal badge, no dimming, one state
(idle). For every polygon, in event order, first **all** halo strokes, then
**all** core strokes (a later halo never cuts an earlier core):
- halo: `overlay.halo`, width `overlay.stroke.core-idle + 2·overlay.stroke.halo`
  = 6 px, cosmetic, round join (`overlay_pen`);
- core: `overlay.bubble.idle`, width `overlay.stroke.core-idle` = 2 px, same pen.
This is A-06 unchanged: same tokens, two strokes. Markers appear at once, no
animation.

**States and events.** `n` = current ordinal + 1, `k` = len(polygons).

The thumbnail is visible from construction (an empty frame keeps the layout
still when the first page arrives). The accessible name carries the page
number; `show_page` receives the ordinal (PO-4, amended by the Lead PO from
"the panel sets it"), so **the thumbnail sets its own name** in every state,
and the description.

| Event | Image | Markers | Accessible name |
|---|---|---|---|
| thumbnail constructed | none (empty frame) | none | `No page started` |
| `PageStarted(o)` | page `o`, loaded from `source_dir / filename` | cleared | `Page {n}: detecting text regions…` |
| `RegionsDetected(o)`, `o` = last `PageStarted` ordinal | unchanged | **replaced** by the event's polygons | `Page {n}: {k} text regions found` |
| same, `k` = 1 | | | `Page {n}: 1 text region found` |
| same, `k` = 0 | | none | `Page {n}: no text regions found` |
| `RegionsDetected`, any other ordinal, or before any `PageStarted` | unchanged | unchanged | unchanged |
| `RunStarted`, `PageSkipped`, `StageFinished`, `RunFinished`, `RunAborted` | unchanged | unchanged | unchanged |

So a finished or aborted run leaves the last page and its markers in view; a
skipped page never replaces it. The ellipsis is U+2026; `{k}` is a plain
decimal. The name changes silently (no per-page live announcement).

**Undecodable image** (`show_page` on a file that will not load): no exception,
the frame and ground drawn with no image, `image_rect()` still computed from
`width × height`, later markers still drawn there; `accessibleDescription()` =
`The page image could not be opened.` - empty after any `show_page` that
decodes. Never an `ErrorBanner`: the run has not failed.

**Tests should assert:** object names `run-thumbnail` and `run-current-page`;
`size() == 120 × 160`; the worked-case `image_rect()` and vertex; markers
replaced, not appended; other-ordinal events change nothing; on captured paint
calls every halo stroke precedes every core stroke, halo `#0B0B0B` width 6,
core `#D6DCE2` width 2, both cosmetic; the five strings exactly; `NoFocus`;
role `Graphic`; the undecodable case does not raise and sets the description.

## Notes

### PO decisions at PLANNED → RED (2026-10-01, lead-po)

- **PO-1 — the event carries polygons, and `DetectStage` emits it.** The stage
  owns the regions and already holds them in reading order; `TranslateStage`
  emitting `CallPriced` (MT-063) is the precedent for a stage emitting through
  `ctx.emit`. Masks stay out (C-1).
- **PO-2 — "as they are found" is per page.** Detection yields a page's
  regions in one call, so markers appear when the page's event arrives; there
  is no finer granularity to show without changing the detector.
- **PO-3 — the panel gets the page image from the `Chapter`, not the store.**
  MT-018's boundary forbids the panel reading the store, and an event carrying
  image bytes would ship a page image across a thread per page. The window
  already holds the `Chapter` it ran (MT-059), whose `source_dir`, `filename`,
  `width` and `height` are domain data; reading the user's scan folder is what
  the `Workspace` canvas already does (`workspace.py`). AC-2..AC-4 were added
  at PLANNED, where the story's own text left them to be refined; AC-1 is
  verbatim.
- **Required gates.** `unit`/`coverage` (`tests/ui`, `tests/core`) and
  `coverage-core` (the event in `domain`) are required and read every path this
  story changes; `required_gates: []`.
- **Epic done-when.** No gap: the done-when's "during a run they can see which
  page is being worked on" is already met (MT-018, MT-059); this adds the
  designed thumbnail.

painted under a painter scale transform, where a non-cosmetic pen is scaled

paints with an identity transform, where a cosmetic and a non-cosmetic pen of
the same width are the same pen. So "pens not cosmetic" is not a reachable
defect in this implementation and the test cannot (and need not) see it; it
still pins the outcome the design asks for (2 px core / 6 px halo in screen
pixels at s = 0.5), and would catch the defect if a later change painted under
a transform. Recorded, not a test problem.
