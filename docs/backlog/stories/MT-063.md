## Context

**Filed 2026-10-01 by the Lead PO** (MT-018 PO-2). EPIC-05's done-when says
"during a run they can see … what has been spent so far". [[MT-018]] built
`CostReadout.set_state(spent, ceiling, projection)` and tested it given values,
but no `RunEvent` carries spend or a projection, so nothing in a run can call
it. The translate stage computes both (`translate_stage.py`: `chapter_total`,
`budget.project`) and keeps them to itself.

This story adds an event that carries them (a frozen dataclass in
`domain.events`), emits it after each priced call, and has
`RunProgressPanel.on_event` feed it to its `CostReadout`. [[MT-059]] AC-3
("drives MT-018's progress panel and cost readout") depends on it for the
cost half.

## Acceptance criteria

- **AC-1** — Given a run in which a call is priced, when the call is recorded,
  then an event carrying the chapter's spend so far and the current projection
  is emitted, and the progress panel's cost readout shows that spend.

**Semantics:**

- **When.** `TranslateStage.run` emits exactly one `CallPriced` per page whose
  translator returned `result.call is not None`, **immediately after
  `record_call`** and before the glossary and proposal writes. A page with no
  call (the all-empty page, MT-011 AC-7) emits none; a refused page
  (`BudgetRefused`) emits none; an unpriceable model (`UnknownModel` from
  `price`) emits none, because `record_call` never ran. In the stream it lands
  after `PageStarted(k)` and before `StageFinished(k, "translate")`.
- **The numbers are the ledger's, read after the write** - not the call's own
  cost and not arithmetic on the pre-call figures. `spent` is
  `chapter_total(ctx.project)` (so it includes earlier runs of the chapter);
  `projection` is `budget_for(ctx.project).project(chapter_call_costs(ctx.project),
  pages_remaining(ctx) - 1)` - the pages *after* this one, so on the last page
  `remaining_chapter` is `$0` and the readout's projected total equals `spent`.
- **`emit` is required, with no default** - MT-044 C-1's reasoning for `run_id`:
  a default no-op would let a stage built or tested without one stay silent,
  and the readout would read `$—` through a whole paid run with every test
  green.
- **The panel** passes the event's own `ceiling` (not the panel's constructor
  ceiling) to the readout. `CostReadout`'s states, copy and announcement are
  MT-018's and unchanged.
- **`domain/events.py` stays data** (its docstring's PO-4): no method,
  validation or default on `CallPriced`. It imports `Usd` and `Projection` from
  `domain`; `coverage-core`'s 100% bar applies.

### Export shape the tests already pin (fact, not suggestion)

- `mangatl.domain.events.CallPriced` - `@dataclass(frozen=True)`, fields exactly
  `ordinal: int, spent: Usd, ceiling: Usd, projection: Projection`, in that order,
  constructed by keyword; no defaults, no `__post_init__`, no non-dunder
  callables in the class dict. In `RunEvent` (`get_args`) and in `__all__`.
  `RunEvent` is exactly the seven types.
- `mangatl.pipeline.stage.PageContext` - fields exactly
  `["project", "page", "run_id", "emit"]`; `emit` has no default or factory;
  omitting it raises `TypeError` whose message contains `emit` (the dataclass
  default message does). `stage.__all__` unchanged.
- `TranslateStage.run(ctx)` calls `ctx.emit(CallPriced(...))` exactly once per
  call with `result.call is not None`, after `record_call` committed, before
  `_update_glossary` and `write_proposed`. Equality of events is dataclass
  equality, so `projection` must be the full `Projection` that
  `budget_for(project).project(chapter_call_costs(project), pages_remaining(ctx) - 1)` returns.
- `run_chapter(project, stages, emit, cancelled)` - signature unchanged; the
  `emit` it was given is the one in every `PageContext`.
- `RunProgressPanel.on_event(CallPriced)` -> `cost_readout` shows what
  `set_state(event.spent, event.ceiling, event.projection)` shows.

Not constrained (implementer's choice): docstrings; whether the stage reads
`budget_for` once or twice per page; how the panel's branch is ordered among the
