## Context

Split out of MT-024 by its PO-3 (2026-10-08) so that each story is one
RED→GREEN cycle. `architecture.md` **D13** — decided by the user on 2026-09-13 —
ships the GPL-3.0 detector knowingly, conveying weights and not code, and names
five obligations that "MT-024 owns". They are discharged here, by the story
that depends on MT-024's manifest and frozen tree. The evidence behind each is
`docs/wiki/audits/MT-030-detector-licence.md` and MT-002's `## Decided`.

**Do not collapse these into one "credits" criterion.** O-1 to O-3 are copyleft
obligations; O-4 is attribution; O-5 is this project's own rule. A credits
screen discharges O-4 and none of the others (D13).

(`src/mangatl/about.py`); "no About screen exists yet (MT-020 PO-5)". **PO-1:
no About screen.** The brief's constraint is that the notices **ship with the
installer**, and text files in the frozen tree satisfy it; a screen is a UI
story with a design decision in front of it, and this story stays one cycle.
`ABOUT_TEXT` gains one line that names where the notice files are, so the one
place the app already speaks about licences points at the rest.

**D13's own caveat applies to every sentence here:** this is an engineer's
reading of the licence texts, not legal advice. The notice file says so too.

## Acceptance criteria

bytes, a hash equals a recorded hash, a set equals a set, a string contains a
pinned substring. Nothing here invents a metric. Where a criterion reads the
*built* tree it lives in `tests/frozen` and is judged by the `frozen` gate
(required by this story's frontmatter); where it reads the *repository* it
lives in `tests/core` and is judged by `unit` and `coverage`.

Five keys per entry, all strings, all present (empty when not applicable);
`licence_text` names a file beside the notices. The manifest's `licence` field
stays the one source of the licence *name* — the notice never restates it.

`packaging/build_notices.py`, shaped as `packaging/fetch_models.py` (a script
beside the manifest, imported by tests through
`importlib.util.spec_from_file_location` as `test_fetch_models.py` does;
imports `mangatl.models.manifest` and `mangatl.about` and nothing else from
`mangatl`; `ruff`-clean; mypy does not check `packaging/`):

```python
HERE = Path(__file__).resolve().parent
MANIFEST = HERE / "models.json"
NOTICES = HERE / "notices" / "notices.json"
OUTPUT = HERE / "notices" / "THIRD_PARTY_NOTICES.txt"

@dataclass(frozen=True)
class Notice:
    name: str; upstream: str; corresponding_source: str; training_data: str; licence_text: str

class NoticeDrift(Exception):
    """The manifest and notices.json disagree; the message is the drift lines, one per line."""

def load_notices(path: Path) -> tuple[Notice, ...]           # file order
def drift(manifest_names: Sequence[str], notice_names: Sequence[str]) -> list[str]
    # one line per problem, manifest order then notices order:
    #   "manifest entry {name!r} has no entry in notices.json"
    #   "notices.json entry {name!r} is not in the manifest"
    # [] when the two name sets are equal (duplicates in either are a drift line too:
    #   "notices.json names {name!r} twice")
def render(entries: Sequence[ModelEntry], notices: Sequence[Notice], about_text: str) -> str
    # raises NoticeDrift when drift(...) is non-empty; else block 2's text, LF-terminated
def main(argv: Sequence[str] | None = None) -> int
    # no arguments: writes render(load_manifest(MANIFEST), load_notices(NOTICES), ABOUT_TEXT)
    #   to OUTPUT (utf-8, LF, newline="\n") and returns 0
    # `--check`: returns 0 when OUTPUT's bytes already equal the rendering, else prints
    #   "THIRD_PARTY_NOTICES.txt is stale; run: uv run python packaging/build_notices.py"
    #   to stderr and returns 1
    # NoticeDrift either way: the drift lines to stderr, prefixed "build_notices: ", return 1
```

### Block 2 — the rendered `THIRD_PARTY_NOTICES.txt`

UTF-8, LF, no trailing whitespace on any line, exactly this shape. `{...}`
are the manifest's and notices' fields verbatim; a block omits the
`Corresponding source:` or `Training data:` line when its string is empty.

```
THIRD-PARTY NOTICES for mangatl

This application bundles the model weights and the font listed below. Each is
conveyed under its own licence; the full licence texts named here ship beside

packaging/notices/notices.json by packaging/build_notices.py, and it is an
engineer's reading of the licences, not legal advice (architecture.md D13).

== comic-text-detector (detect) ==
File:                 models/comic-text-detector.onnx
Source:               https://huggingface.co/mayocream/comic-text-detector-onnx at revision a5d67ec772adef819ef5b0e7aa701fcf4c8bf74a
SHA-256:              1a86ace74961413cbd650002e7bb4dcec4980ffa21b2f19b86933372071d718f
Licence:              GPL-3.0 (upstream dmMaze/comic-text-detector; the HF repo's metadata says apache-2.0 - architecture.md D13)
Licence text:         GPL-3.0.txt
Upstream:             https://github.com/dmMaze/comic-text-detector
Corresponding source: {corresponding_source}
Training data:        {training_data}

File:                 models/manga-ocr/encoder_model.onnx
Source:               https://huggingface.co/onnx-community/manga-ocr-base-ONNX at revision f9023406bb2f6b17df67bc4a327c56ecd20611f0

Licence:              Apache-2.0
```

The header `== {name} ({role}) ==`; `Source:` is
`https://huggingface.co/{repo} at revision {revision}`; `File:` is
`models/{path}`; labels are padded to the width of `Corresponding source:`
(22 characters) so the values align. The file ends with ABOUT_TEXT's own
final newline and nothing after it.
