## Context

Brief feature 6 and section 8: "comic body font, centred, sensible line breaks,
sized to the bubble… the baked page should look like a normal English release,
not like a machine's output."

**O5 is resolved**: `docs/wiki/design/typeset-font.md` chooses **Shantell Sans
1.011 under the SIL Open Font License 1.1**, shipping the *static* instances
(Regular, Italic, Bold, Bold Italic) rather than the variable font. That document
is settled and is not to be re-litigated here — but two things in it are
explicitly *not* settled and land on this story:

- **§5 licence obligations are mechanical and must actually be performed**: ship
  `OFL.txt`, credit the font in About, and **do not subset** (Reserved Font
  Name). AC-8 makes the first two checkable; the third is a rule for MT-024.
- **§6 records that glyph coverage is unverified** and converts that into a test
  rather than an assertion. AC-7 is that test. Interrobang is deliberately
  **excluded** from the required codepoints — the convention sets `?!`.

`typeset` is in the 100% `coverage-core` set. This is pure geometry and metrics;
it takes a font file and a polygon and returns positioned glyph runs.

**Which required gate would fail if this story's artifact broke:** `unit` and
`coverage-core`.

## Acceptance criteria

- **AC-1** — Given a bubble polygon and a string, when it is typeset, then every
  glyph's bounding box lies inside the polygon's inscribed fitting area, at the
  largest size in the allowed range that achieves this.
- **AC-2** — Given a typeset block, when it is positioned, then each line is
  horizontally centred within the fitting area and the block is vertically
  centred within it.
- **AC-3** — Given a string that cannot fit at the minimum size, when it is
  typeset, then it is set at the minimum size, overflow is reported on the
  result, and **nothing is silently truncated**.
- **AC-4** — Given a string, when lines are broken, then breaks occur at
  whitespace and at existing hyphens only — **no automatic hyphenation** — and
  the break chosen minimises the raggedness measure the contract defines.
- **AC-5** — Given `*italic*` and `**bold**` markers in the text, when it is
  typeset, then those runs use the Italic and Bold **font files**, the markers do
  not appear in the output, and an unclosed marker is rendered literally.
- **AC-6** — Given the same string, polygon and font, when typeset twice, then
  the output is byte-identical — no randomness, no dependence on system font
  configuration.
- **AC-7** — Given the shipped font files, when they are inspected, then every
  codepoint in `REQUIRED_CODEPOINTS` is present in the cmap of **all four**
  faces, and the four faces have **distinct `OS/2` style bits** — Bold is bold
  *in the file*, not synthesised.
- **AC-8** — Given the built application tree, when it is inspected, then
  `OFL.txt` is present beside the font files and the About text names the family,
  the designers and the licence.

```
src/mangatl/typeset/measure.py

src/mangatl/typeset/fit.py
    MIN_SIZE_PX: float
    MAX_SIZE_PX: float
    SIZE_STEP_PX: float
    LINE_HEIGHT_RATIO: float
    FIT_INSET_RATIO: float
    def fitting_area(polygon) -> Polygon
    def break_lines(runs, width_px, face, size_px) -> list[Line]
    def typeset(text: str, polygon, faces) -> TypesetBlock   # includes .overflowed

src/mangatl/typeset/markup.py
    def parse_emphasis(text: str) -> list[Run]   # (text, italic, bold)
```

**Semantics behind each number — one sentence each:**

- **`FIT_INSET_RATIO`** shrinks the polygon before fitting so text does not
  crowd the bubble outline. Scanlation convention leaves visible breathing room;
  GREEN measures the value against the fixture bubbles and records it.
- **`LINE_HEIGHT_RATIO`** is line advance as a multiple of font size. Comic
  lettering is set tighter than body text; record the measured value and the two
  failure directions (lines touching versus a block that will not fit).
- **The raggedness measure** (AC-4) is the sum of squared slack on each line
  except the last — the standard Knuth-style objective, minimised over
  break positions. State it in the contract so RED does not invent a different
  one; "sensible line breaks" is not a specification and this sentence is.
- **No automatic hyphenation** (AC-4). English comic lettering does not hyphenate
  inside bubbles; a hyphenated word in a bubble reads as a typesetting error.
- **Sizing searches from `MAX_SIZE_PX` downward in `SIZE_STEP_PX` steps** and
  takes the first size that fits, which makes AC-1's "largest size that fits"
  exact rather than approximate, and makes AC-6's determinism free.
- **Emphasis uses real face files** (AC-5), never a synthetic oblique or a
  stroke-widened fake. That is the requirement that eliminated the runner-up font
  (`typeset-font.md` §4), so faking it here would discard the reason the font was
  chosen.

**Oracle partition:**

| AC | Kind | Instruction to RED |
|---|---|---|
| AC-1..AC-3, AC-6 | **Mechanical** | Geometry against constructed polygons. Assert containment exactly; assert AC-3's overflow flag *and* that the full string survives. |
| AC-4 | **Mechanical**, given the objective above | The objective is specified. Enumerate cases where greedy and optimal breaking differ, and assert the optimal one — otherwise the criterion passes against a greedy implementation. |
| AC-5 | **Mechanical** | Which face file each run resolves to. Assert on the file, not on a "looks bold" property. |
| AC-7, AC-8 | **Mechanical** | `fontTools` reads the cmap and the `OS/2` table. This is the check that replaces the designer's stated low confidence in coverage. |

Nothing here is oracle-free. "Looks like a real release" is S4, is subjective by
the brief's own statement, and is not a criterion in this story.

## Design notes

`docs/wiki/design/typeset-font.md` in full; §7 carries the lettering rules that
come with the font, and §6 carries the coverage check AC-7 implements. The
designer's confidence statement is worth repeating because it shapes this story:
**licence confidence high** (OFL 1.1 declared by the upstream repository, not by
an aggregator); **coverage confidence low, and deliberately not asserted** —
hence AC-7.

Also flagged by the designer and **not in scope here**: a piracy-aggregator
claim that "CC Wild Words Roman is OFL" is almost certainly false and is
recorded in `typeset-font.md` §4 as a warning so nobody re-finds it and acts on
it. Do not vendor any font this story does not name.

## Deferred verifications

- *Falsifiable condition 1:* with the emphasis runs mapped to the **Regular**
  face for all styles, AC-5 **must** fail. The rendered output would still look
  broadly plausible, which is why this needs a file-level assertion.
- *Falsifiable condition 2:* with `break_lines` replaced by a **greedy**
  first-fit breaker, AC-4 **must** fail on at least one fixture string. If it
  does not, the fixtures do not distinguish greedy from optimal and the
  criterion is weaker than it reads.
- *Falsifiable condition 3:* with `FIT_INSET_RATIO` set to `0.0` — a wrong value
  — AC-1 **must** fail on a bubble whose outline is thick.
- **Owner: GATES.** Three mutations via `bash scripts/mutate.sh`.

## Model guidance

- **RED and GREEN models:** to be recorded at dispatch, by name. Defaults are
  `claude-opus-5` (Claude Opus 5).
- **Oracle partition: entirely mechanical**, which is unusual for a story that
  sounds aesthetic and is the point of writing the objective function into the
  contract. Say so in the dispatch prompt: the font, the break objective, the
  no-hyphenation rule and the emphasis mechanism are all **settled**; RED pins
  them and invents nothing.
- **Success condition, falsifiable:** RED includes at least one string where
  greedy and optimal breaking differ and asserts the optimal result, and AC-5 is
  asserted against the resolved font file path. A suite that would pass against
  a greedy breaker has failed RED.
- **Verdict:** *to be recorded.*

## Out of scope

Per-bubble control over font, size, placement or breaks — brief §5 non-goals.
The **app-wide** lettering-font override is now in scope for the product (the
user decided so on 2026-09-12) but belongs to **MT-027**, not here: this story
establishes the shipped default, its validation and the typesetting itself, and
MT-027 makes that validation reusable against a font the project did not ship.
Also out: sound effects, vertical English, rendering to the page (MT-021), and
subsetting the font — forbidden by the Reserved Font Name clause.
