## Context

Brief success criterion **S2**: "every text-bearing bubble on the page is found,
and no Japanese pixels survive inside a cleaned region. Measured separately from
S1 — a perfect translation in a missed bubble is still a failure, and a leftover
glyph is visible at a glance."

Two measurements, deliberately in one story because they share a ground truth
and because reporting one without the other reproduces the blindness the S1
metrics have — S1b, the headline, cannot see a spurious detection at all, and
**this story is where spurious detections are a reported failure** (AC-3).
`docs/wiki/stack.md` §5/O2 says so explicitly and points here:

- **Recall** — fraction of ground-truth text regions matched by a detection.
- **Residual ink** — whether Japanese pixels survive inside a cleaned region.

The second is the harder one to measure honestly, and it is where a blind metric
is easy to write: "mean absolute difference from the source is high inside the
region" is satisfied by a cleaner that paints the region bright pink.

**Which required gate would fail if this story's artifact broke:** `unit` and
`coverage-core` — `bench` is in the 100% set.

## Acceptance criteria

- **AC-1** — Given a chapter and its ground truth, when recall is measured, then
  it reports matched, missed and spurious region counts, matching by mask IoU ≥
  0.5, and the per-page breakdown.
- **AC-2** — Given a ground-truth region that no detection matches, when recall
  is measured, then it is counted as **missed** and the page it is on is named.
- **AC-3** — Given a detection matching no ground-truth region, when recall is
  measured, then it is counted as **spurious**. *(A detector that emits a
  thousand boxes must not score 100% recall unremarked.)*
- **AC-4** — Given a cleaned page and its source, when residual ink is measured,
  then it reports, per region, the fraction of pixels that remain "ink-like" —
  dark, high-local-contrast — inside the cleaned mask.
- **AC-5** — *(negative control: the metric sees surviving glyphs)* Given a page
  where cleaning was **skipped entirely**, when residual ink is measured, then
  the score exceeds `RESIDUAL_INK_MAX` by a wide margin. Record the two numbers.
- **AC-6** — *(negative control: the metric is about ink, not about difference)*
  Given a page where each region was **filled with a flat mid-grey**, when
  residual ink is measured, then it scores **below** the threshold — the metric
  must not reward "different from the source", only "no ink left".
  *(The complementary check — that a flat fill is nonetheless a bad clean — is
  MT-019 AC-7's tone-variance criterion, deliberately in the other story.)*
- **AC-7** — Given a chapter marked as used during development, when the
  measurement runs in benchmark mode, then it refuses, as MT-022 AC-8 does.
- **AC-8** — Given both measurements, when the report is produced, then S2 is
  reported as a **pair** — recall and residual ink — and passing one while
  failing the other is reported as a failure, not as a partial pass.

### Block 2 — `src/mangatl/bench/residual.py`

```python
__all__ = ["INK_CONTRAST_MIN", "INK_LUMA_MAX", "RESIDUAL_INK_MAX", "CONTRAST_RADIUS",
           "RegionResidual", "ResidualReport", "ink_fraction", "local_contrast", "page_luma",
           "measure_residual"]

INK_LUMA_MAX: int = 160        # a pixel darker than this MAY be ink
INK_CONTRAST_MIN: int = 64     # ... and is ink only if its 5x5 local contrast is at least this
CONTRAST_RADIUS: int = 2       # the neighbourhood is (2r+1) x (2r+1) = 5 x 5, edge-padded
RESIDUAL_INK_MAX: float = ...  # NOT settled here; GREEN measures it (see below)

def page_luma(image: bytes) -> NDArray[np.uint8]:
    """An encoded page as (height, width) luma, Pillow's convert("L") (ITU-R 601-2)."""

def local_contrast(
    luma: NDArray[np.uint8], *, within: NDArray[np.bool_] | None = None
) -> NDArray[np.uint8]:
    """Per pixel: max minus min of luma over the (2r+1)^2 window centred on it,
    np.pad(mode="edge") at the borders, so the output has the input's shape.
    With `within` (same shape; amendment A-1): the max and min are taken only
    over window pixels where `within` is True, and every pixel where `within`
    is False is 0."""

def ink_fraction(cleaned: NDArray[np.uint8], mask: NDArray[np.bool_]) -> float:
    """Fraction of `mask`'s pixels that are ink-like in `cleaned` (a luma array of
    the same shape): luma < INK_LUMA_MAX AND
    local_contrast(cleaned, within=mask) >= INK_CONTRAST_MIN.
    0.0 for an empty mask. ValueError on a shape mismatch."""

@dataclass(frozen=True)
class RegionResidual:
    page_ordinal: int
    truth_index: int
    fraction: float

@dataclass(frozen=True)
class ResidualReport:
    regions: tuple[RegionResidual, ...]   # one per MATCHED truth region, page order then index order
    worst: float                          # max fraction; 0.0 when regions == ()
    uncleaned_pages: tuple[int, ...]      # ordinals whose project has no cleaned image (measured on the source scan)

def measure_residual(project: Project, truth: GroundTruth) -> ResidualReport: ...
```

*RED amendment A-1 (2026-10-08) — the contrast window is restricted to the
measured mask.* **Why:** as first pinned (window over the whole page), AC-6 cannot
pass on any honest fixture. A region filled flat with luma 128 sits next to paper
(255) outside its polygon, so every pixel within `CONTRAST_RADIUS` of the polygon's
edge sees contrast 127 ≥ 64 and luma 128 < 160 — ink. On RED's fixture (40 × 40 px
regions) that 2 px band is 1600 − 36² = **304 px = 0.19 per region**, against a
skipped-cleaning value of **0.2056**: no `RESIDUAL_INK_MAX` can be both ≤ 0.0206
(AC-5's tenfold) and > 0.19 (AC-6). Measured with a throwaway reference outside
`src/`, both variants, same fixture (handoff has the numbers). The fill's own
edge against the paper outside it is not ink left *inside* the region, which is
what AC-4 measures; restricting the window to the mask makes the flat fill score
**0.0** while surviving glyphs keep their contrast against the white *inside* the
region (skipped still 0.2056). The same defect pointed the other way is a correct
white clean whose bubble outline lies just outside the truth polygon — counted as
residual ink under the unrestricted window, not under the restricted one.
`local_contrast(luma)` with no `within` is unchanged and still pinned on its own
(flat → 0, 5 × 5, edge padding). Constants unchanged: `INK_LUMA_MAX = 160`,
`INK_CONTRAST_MIN = 64`, fill luma 128 still inside the luma band, and the test
file asserts that invariant (`test_the_flat_fill_sits_inside_the_luma_band…`).
An implementation that drops the restriction fails AC-6 (scored 0.19) and the two
`within` unit tests — listed in the handoff's mutation table.

Semantics — and the trap this story exists to avoid:

- **"Ink-like" is a two-condition test, not a brightness test**: luma below
  `INK_LUMA_MAX` **and** local contrast at or above `INK_CONTRAST_MIN`.
  Brightness alone counts dense screentone and dark artwork as surviving
  Japanese, which makes the metric fire on correctly cleaned pages and get
  quietly relaxed until it fires on nothing.
- **Local contrast (max − min over 5×5) is what distinguishes a glyph from a
  dark region.** A glyph is a high-frequency structure; a shaded area is not —
  the one-point-versus-two-point distinction `story-authoring` records for the
  variance-versus-gradient case. It is why AC-6 exists: a flat mid-grey fill is
  dark-ish and has zero local contrast, so an ink metric scores it 0 while a
  difference metric scores it high.
- **`INK_LUMA_MAX = 160` is deliberately generous, and AC-6's fill is luma
  128, deliberately inside it.** If the flat fill were darker than paper but
  lighter than `INK_LUMA_MAX`, a luma-only metric would already score it 0 and
  AC-6 would not distinguish the two conditions — deferred verification 1 would
  not fail. The fill must pass the luma test so that the contrast test is the one
  AC-6 exercises. RED may move either constant with a reason, but must keep the
  fill inside the luma band and say so.
- **What the metric counts, honestly stated:** a thick stroke's interior has
  zero local contrast, so the metric counts the *edge band* of glyphs, not their
  area. The fraction's absolute value therefore depends on stroke width, which
  is why `RESIDUAL_INK_MAX` is measured rather than reasoned, and why the
  controls are stated as ratios to it.
- **Which pixels are "inside a cleaned region" (PO-1 in `## Notes`):** the
  **truth polygon of each matched truth region**, rasterised with
  `polygon_mask(region.polygon, page.width, page.height)` — not the detector's
  mask. A mask that is too tight leaves glyph pixels outside itself and inside
  the human-marked region; measuring inside the detector's own mask is blind to
  exactly that defect. Missed truth regions are recall's failure and are not
  measured here (they would fail S2 twice for one cause); spurious proposals have
  no truth polygon and are not measured.
- **The image measured** is `project.read_cleaned(ordinal)`; when it is `None`
  the page was never cleaned and the **source scan** (`chapter.source_dir /
  page.filename`) is measured instead, with the ordinal listed in
  `uncleaned_pages` (PO-2). That is AC-5's control taking the real route.
- Refuses first, exactly as block 1.
- **`RESIDUAL_INK_MAX` is set by GREEN** from three measurements on RED's
  fixtures, all recorded in the GREEN handoff: the skipped-cleaning control
  (AC-5), the flat-fill control (AC-6) and the white-fill clean run; set with
  stated headroom — at most a tenth of the skipped value, above the clean runs.
  RED writes the AC-5 assertion as `skipped >= 10 * RESIDUAL_INK_MAX` and AC-6 as
  `flat < RESIDUAL_INK_MAX`, imports the constant, and records in the handoff the
  fixture values it measured against a throwaway implementation so GREEN can
  confirm them.

### Block 3 — `src/mangatl/bench/s2.py`

```python
__all__ = ["S2Report", "main", "measure_s2"]

@dataclass(frozen=True)
class S2Report:
    recall: RecallReport
    residual: ResidualReport
    recall_ok: bool      # recall.missed == () and recall.spurious == 0
    residual_ok: bool    # every residual fraction <= RESIDUAL_INK_MAX (vacuously True with none)
    passed: bool         # recall_ok and residual_ok — never a partial pass (AC-8)

def measure_s2(project: Project, truth: GroundTruth) -> S2Report: ...
def main(argv: Sequence[str] | None = None) -> int: ...
```

- `measure_s2` calls `measure_recall` then `measure_residual`; it refuses as
  they do (the development-use refusal happens before anything is measured).
- `main` mirrors `acceptance.main` line for line in shape (PO-5 there):
  `python -m mangatl.bench.s2 FOLDER [--truth PATH]`, exit `0` measured, `2`
  cannot measure with the message on stderr prefixed `python -m mangatl.bench.s2:`;
  validator warnings print first. The rendered report carries, one per line:
  `recall` with matched / ground truth; `missed` listing `page N region I`
  entries (or `none`); `spurious` count; `residual ink` with the worst fraction
  against `RESIDUAL_INK_MAX` and the per-region lines beneath; and last a line
  beginning `S2 PASS` or `S2 FAIL` naming which of recall / residual failed.
  RED pins the exact substrings.

*RED amendment A-2 (2026-10-08) — the names `s2` reads.* `s2.py` imports
`measure_recall` (from `mangatl.bench.recall`) and `measure_residual` and
`RESIDUAL_INK_MAX` (from `mangatl.bench.residual`) **by name into its module
namespace**, and `measure_s2` calls `measure_recall` / `measure_residual` through
those module globals at call time. **Why:** the AC-8 verdict test monkeypatches
`s2.measure_recall` / `s2.measure_residual` to hand `measure_s2` constructed
reports, so the conjunction rule (and the `<=` at exactly `RESIDUAL_INK_MAX`) is
pinned independently of either measurement. A module-qualified call
(`recall.measure_recall(...)`) would bypass the patch and fail that test.

*RED amendment A-3 (2026-10-08) — the rendered report, exactly.* After the
validator warnings, one line each, in this order; tests compare each **stripped**
line with `re.fullmatch`, and `\s+` stands for any run of spaces (alignment is
GREEN's choice; at least one space is required):

```text
recall\s+{recall:.1%}\s+matched {matched} / ground truth {ground_truth}
missed\s+none                         | missed\s+page 0 region 2, page 1 region 0
spurious\s+{spurious}
residual ink\s+worst {worst:.4f} / max {RESIDUAL_INK_MAX:.4f}
page {o} region {i}\s+{fraction:.4f}  (one per RegionResidual, report order; may be indented)
uncleaned\s+page 0, page 1 (measured on the source scan)   (ONLY when uncleaned_pages != ())
S2 PASS | S2 FAIL: recall | S2 FAIL: residual ink | S2 FAIL: recall, residual ink
```

Missed entries are joined by `", "`; uncleaned pages likewise. The last line is
exactly one of the four strings. Nothing else is printed to stdout on success.
A failing S2 is a measurement: `main` still returns `0`. **Why:** the contract
asked RED to pin exact substrings; the `uncleaned` line is added because a
benchmark run on a chapter whose clean stage never ran must say so where the user
reads the number (PO-2), not only in the dataclass.

### Discoveries GREEN must know

- **A-1 is load-bearing.** Implement `local_contrast(..., within=mask)` as "window
  ∩ mask"; a sentinel trick works (`-1` for the max, `256` for the min, in an
  `int16` copy, then `np.pad(mode="edge")`, then a 5 × 5 max/min, then zero
  outside the mask). Edge padding never changes a window's max/min (the
  replicated pixel is already in the window), so padding `within` with `edge`
  too is consistent.
- **`IOU_MATCH_THRESHOLD` must be imported by `recall.py` and must not be a
  `0.5` literal there.** The matcher already applies it, so the import is
  otherwise unused and ruff will report `F401`. A mention in a docstring does
  not count as a use. Two forms satisfy both ruff and the test (which checks only
  the `ImportFrom` names): the explicit re-export spelling
  `from mangatl.bench.matching import IOU_MATCH_THRESHOLD as IOU_MATCH_THRESHOLD`,
  or a `# noqa: F401` with a one-line reason. A genuine use is better still, for
  example naming the threshold in a rendered or error string. Pick one and say why.
- `write_regions` deletes the page's cleaned image (MT-065 C-3), so the fixture
  writes cleaned images after regions; `measure_residual` must not assume a
  cleaned image survives a re-detection.
- The seeded truth is all `source: "seed"`, so `validate` warns; `main` prints
  warnings first, and the tests expect them verbatim (stripped) before the report.

### Decisions the contract left open

- **`F401`: the explicit re-export form**, `from mangatl.bench.matching import
  IOU_MATCH_THRESHOLD as IOU_MATCH_THRESHOLD` (on its own line; `match_regions`
  on a second import line). Why, as the module docstring says: the threshold is
  part of what the report's numbers mean, so offering `recall.IOU_MATCH_THRESHOLD`
  is honest; ruff and mypy (strict, no implicit re-export) both read `X as X` as
  deliberate; a `# noqa: F401` would also silence a genuinely dead import on that
  line later. A "genuine use" in a string was not available - every rendered
  line is pinned by `re.fullmatch` (A-3), and `RecallReport`'s fields are pinned.
- **`measure_residual` reuses `measure_recall`** for the pairing (the handoff
  left this open): matched truth indices on a page are those not in that page's
  `PageRecall.missed`. One matching rule, one refusal path - the dev-use and
  validator refusals of `measure_residual` *are* `measure_recall`'s, raised before
  any `read_regions`/`read_cleaned`. Cost: `measure_s2` matches twice (once per
  measurement); the fixture suites are 12 s, unchanged from RED's estimate.
- **A page with no matched truth region is not read at all**, so it is never
  listed in `uncleaned_pages`. The rendered line says "(measured on the source
  scan)", which would be false for a page where nothing was measured. No test
  pins this either way (the nothing-detected tests check `regions`/`worst`/the
  verdict only, and the CLI tests format from `measure_s2`'s own report); the
  branch is reached by `{}`-detection tests, so coverage stays 100 %.
- **`local_contrast` has one path**: `within=None` becomes an all-True mask, then
  the sentinel method (`-1` for max, `256` for min, `int16`, `np.pad(mode="edge")`,
  `numpy.lib.stride_tricks.sliding_window_view` 5x5 max/min, zero outside the
  mask). No branch on `within` beyond that one expression.
- **`residual_ok`** is `all(fraction <= RESIDUAL_INK_MAX ...)` over the regions,
  not `worst <= MAX`, so it never trusts a constructed report's `worst` field;
  equivalent for any report `measure_residual` builds.
