## Context

Brief success criterion **S2**: "every text-bearing bubble on the page is found,
and no Japanese pixels survive inside a cleaned region. Measured separately from
S1 — a perfect translation in a missed bubble is still a failure, and a leftover
glyph is visible at a glance."

Two measurements, deliberately in one story because they share a ground truth
and because reporting one without the other reproduces the blindness the S1
metrics have — S1b, the headline, cannot see a spurious detection at all, and
**this story is where spurious detections are a reported failure** (AC-3).
`docs/wiki/stack.md` §5/O2 says so explicitly and points here:

- **Recall** — fraction of ground-truth text regions matched by a detection.
- **Residual ink** — whether Japanese pixels survive inside a cleaned region.

The second is the harder one to measure honestly, and it is where a blind metric
is easy to write: "mean absolute difference from the source is high inside the
region" is satisfied by a cleaner that paints the region bright pink.

**Which required gate would fail if this story's artifact broke:** `unit` and
`coverage-core` — `bench` is in the 100% set.

## Acceptance criteria

- **AC-1** — Given a chapter and its ground truth, when recall is measured, then
  it reports matched, missed and spurious region counts, matching by mask IoU ≥
  0.5, and the per-page breakdown.
- **AC-2** — Given a ground-truth region that no detection matches, when recall
  is measured, then it is counted as **missed** and the page it is on is named.
- **AC-3** — Given a detection matching no ground-truth region, when recall is
  measured, then it is counted as **spurious**. *(A detector that emits a
  thousand boxes must not score 100% recall unremarked.)*
- **AC-4** — Given a cleaned page and its source, when residual ink is measured,
  then it reports, per region, the fraction of pixels that remain "ink-like" —
  dark, high-local-contrast — inside the cleaned mask.
- **AC-5** — *(negative control: the metric sees surviving glyphs)* Given a page
  where cleaning was **skipped entirely**, when residual ink is measured, then
  the score exceeds `RESIDUAL_INK_MAX` by a wide margin. Record the two numbers.
- **AC-6** — *(negative control: the metric is about ink, not about difference)*
  Given a page where each region was **filled with a flat mid-grey**, when
  residual ink is measured, then it scores **below** the threshold — the metric
  must not reward "different from the source", only "no ink left".
  *(The complementary check — that a flat fill is nonetheless a bad clean — is
  MT-019 AC-7's tone-variance criterion, deliberately in the other story.)*
- **AC-7** — Given a chapter marked as used during development, when the
  measurement runs in benchmark mode, then it refuses, as MT-022 AC-8 does.
- **AC-8** — Given both measurements, when the report is produced, then S2 is
  reported as a **pair** — recall and residual ink — and passing one while
  failing the other is reported as a failure, not as a partial pass.

### Block 2 — `src/mangatl/bench/residual.py`

```python
__all__ = ["INK_CONTRAST_MIN", "INK_LUMA_MAX", "RESIDUAL_INK_MAX", "CONTRAST_RADIUS",
           "RegionResidual", "ResidualReport", "ink_fraction", "local_contrast", "page_luma",
           "measure_residual"]

INK_LUMA_MAX: int = 160        # a pixel darker than this MAY be ink
INK_CONTRAST_MIN: int = 64     # ... and is ink only if its 5x5 local contrast is at least this
CONTRAST_RADIUS: int = 2       # the neighbourhood is (2r+1) x (2r+1) = 5 x 5, edge-padded
RESIDUAL_INK_MAX: float = ...  # NOT settled here; GREEN measures it (see below)

def page_luma(image: bytes) -> NDArray[np.uint8]:
    """An encoded page as (height, width) luma, Pillow's convert("L") (ITU-R 601-2)."""

def local_contrast(luma: NDArray[np.uint8]) -> NDArray[np.uint8]:
    """Per pixel: max minus min of luma over the (2r+1)^2 window centred on it,
    np.pad(mode="edge") at the borders, so the output has the input's shape."""

def ink_fraction(cleaned: NDArray[np.uint8], mask: NDArray[np.bool_]) -> float:
    """Fraction of `mask`'s pixels that are ink-like in `cleaned` (a luma array of
    the same shape): luma < INK_LUMA_MAX AND local_contrast >= INK_CONTRAST_MIN.
    0.0 for an empty mask. ValueError on a shape mismatch."""

@dataclass(frozen=True)
class RegionResidual:
    page_ordinal: int
    truth_index: int
    fraction: float

@dataclass(frozen=True)
class ResidualReport:
    regions: tuple[RegionResidual, ...]   # one per MATCHED truth region, page order then index order
    worst: float                          # max fraction; 0.0 when regions == ()
    uncleaned_pages: tuple[int, ...]      # ordinals whose project has no cleaned image (measured on the source scan)

def measure_residual(project: Project, truth: GroundTruth) -> ResidualReport: ...
```

Semantics — and the trap this story exists to avoid:

- **"Ink-like" is a two-condition test, not a brightness test**: luma below
  `INK_LUMA_MAX` **and** local contrast at or above `INK_CONTRAST_MIN`.
  Brightness alone counts dense screentone and dark artwork as surviving
  Japanese, which makes the metric fire on correctly cleaned pages and get
  quietly relaxed until it fires on nothing.
- **Local contrast (max − min over 5×5) is what distinguishes a glyph from a
  dark region.** A glyph is a high-frequency structure; a shaded area is not —
  the one-point-versus-two-point distinction `story-authoring` records for the
  variance-versus-gradient case. It is why AC-6 exists: a flat mid-grey fill is
  dark-ish and has zero local contrast, so an ink metric scores it 0 while a
  difference metric scores it high.
- **`INK_LUMA_MAX = 160` is deliberately generous, and AC-6's fill is luma
  128, deliberately inside it.** If the flat fill were darker than paper but
  lighter than `INK_LUMA_MAX`, a luma-only metric would already score it 0 and
  AC-6 would not distinguish the two conditions — deferred verification 1 would
  not fail. The fill must pass the luma test so that the contrast test is the one
  AC-6 exercises. RED may move either constant with a reason, but must keep the
  fill inside the luma band and say so.
- **What the metric counts, honestly stated:** a thick stroke's interior has
  zero local contrast, so the metric counts the *edge band* of glyphs, not their
  area. The fraction's absolute value therefore depends on stroke width, which
  is why `RESIDUAL_INK_MAX` is measured rather than reasoned, and why the
  controls are stated as ratios to it.
- **Which pixels are "inside a cleaned region" (PO-1 in `## Notes`):** the
  **truth polygon of each matched truth region**, rasterised with
  `polygon_mask(region.polygon, page.width, page.height)` — not the detector's
  mask. A mask that is too tight leaves glyph pixels outside itself and inside
  the human-marked region; measuring inside the detector's own mask is blind to
  exactly that defect. Missed truth regions are recall's failure and are not
  measured here (they would fail S2 twice for one cause); spurious proposals have
  no truth polygon and are not measured.
- **The image measured** is `project.read_cleaned(ordinal)`; when it is `None`
  the page was never cleaned and the **source scan** (`chapter.source_dir /
  page.filename`) is measured instead, with the ordinal listed in
  `uncleaned_pages` (PO-2). That is AC-5's control taking the real route.
- Refuses first, exactly as block 1.
- **`RESIDUAL_INK_MAX` is set by GREEN** from three measurements on RED's
  fixtures, all recorded in the GREEN handoff: the skipped-cleaning control
  (AC-5), the flat-fill control (AC-6) and the white-fill clean run; set with
  stated headroom — at most a tenth of the skipped value, above the clean runs.
  RED writes the AC-5 assertion as `skipped >= 10 * RESIDUAL_INK_MAX` and AC-6 as
  `flat < RESIDUAL_INK_MAX`, imports the constant, and records in the handoff the
  fixture values it measured against a throwaway implementation so GREEN can
  confirm them.

### Block 3 — `src/mangatl/bench/s2.py`

  they do (the development-use refusal happens before anything is measured).
- `main` mirrors `acceptance.main` line for line in shape (PO-5 there):

## Deferred verifications

  from `ink_fraction` in `src/mangatl/bench/residual.py` — ink = `luma <
  INK_LUMA_MAX` alone — AC-6 **must** fail: the flat luma-128 fill is inside the
  luma band and would score ≈ 1.0. AC-5 still passes, which is the point: AC-5
  alone cannot tell this metric from the right one.
- *Falsifiable condition 2 (difference-from-paper, the "defect put back"):*
  with the two-point `local_contrast` term replaced by the one-point
  **difference from paper white** (`255 - luma >= INK_CONTRAST_MIN`) — the
  plausible wrong quantity, "changed from blank" rather than "structured like a
  glyph" — AC-6 **must** fail and AC-5 must still pass. This is the single most

### PO decisions at PLANNED → RED (2026-10-08, lead-po on Claude Fable 5.1)

entry needed. The acceptance criteria are unchanged from the cut.

- **PO-1 — residual ink is measured inside the truth polygon of each matched
  truth region, not inside the detector's mask.** AC-4 says "inside the cleaned
  mask"; the cleaner's actual mask is `clean/mask.py`'s dilation of the
  detector's, which `bench` may not import (layers contract) and which is not
  stored. More to the point, a too-tight mask leaves glyph pixels outside itself
  and inside the human-marked region, and a metric reading the detector's own
  mask cannot see that — the one defect a cleaning metric most needs to see.
  Missed regions are not measured (recall already fails them; measuring them
  again fails S2 twice for one cause), spurious ones have no truth polygon.
- **PO-2 — a page with no stored cleaned image is measured on its source
  scan**, and listed in `uncleaned_pages`, rather than refused. "Cleaning was
  skipped" is a real pipeline state (and AC-5's control); refusing it would make
  the control unreachable through `measure_residual` and would hide a chapter
  that was benchmarked before its clean stage ran.
- **PO-3 — S2's verdict is the conjunction of three named conditions:** no
  missed region, **no spurious proposal**, and every measured residual fraction
  ≤ `RESIDUAL_INK_MAX`. AC-3 and `stack.md` §5/O2 make spurious detections "a
  first-class reported failure under S2", so they fail the verdict rather than
  merely appearing in it; a phantom bubble gets inpainted, which damages art
  visibly. `recall_ok` folds the first two; `residual_ok` is the third; `passed`
  is the pair's conjunction and is never partial (AC-8). **The user may
  overrule the spurious half before GREEN** — if spurious should be reported but

- **PO-4 — `RESIDUAL_INK_MAX` is set by GREEN from measurement**, not by this
