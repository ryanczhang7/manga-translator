## Context

EPIC-09 PO-6: the consistency pass is text-only and returns **only the lines
it would change**, each with a reason, never the full text. This story is
the request and its parse - the `translate` half, testable with a fake
client. Applying corrections to the store is MT-115.

Why corrections-only is a hard constraint and not a preference: the epic's
cost case (EPIC-09 `## Why now`) puts a full-rewrite pass at ~$5.50 for 200
pages against ~$3.60 with corrections only; the pass would cost more than the
batch saved. The schema enforces it: every item is a changed line, and a
response item whose `corrected_en` equals the line's current English is a
**defect of the pass**, counted and dropped by the parse, never applied.

**Chunking.** A volume's text (Japanese + English + glossary) for 200 pages
is ~200 x (500 + 700) tokens plus the glossary, around 250k - over the 200k
tier (MT-101 D-?). The pass is chunked at page boundaries so each request's
estimated input stays under `CONSISTENCY_MAX_INPUT_TOKENS`; each chunk is one
request and one ledger row. A chunk is a contiguous run of pages, so a
correction's cross-page evidence is as local as the chunk.

Required gates: `unit`, `coverage`.

## Acceptance criteria

- **AC-1** - `consistency_text(pages, glossary_block)` renders the glossary
  block first, then every page under `Page {n}:` with each line as
  `[{reading_index}] {ja}` / `    {en}`, skipping lines with no English, in
  page then reading order; byte-identical on identical input.
- **AC-2** - `CORRECTIONS_SCHEMA` requires a `corrections` array whose items
  require exactly `page` (integer), `reading_index` (integer), `corrected_en`
  (string), `reason` (string) with no additional properties at either level;
  no property of the schema can carry a full page.
- **AC-3** - `parse_corrections(text, current)` where `current` maps
  `(page, reading_index)` to the current English returns `ProposedCorrection`s
  for the items whose `corrected_en` differs from `current`, in response
  order; items equal to `current` are dropped and counted in the result's
  `unchanged_returned`; an item whose `(page, reading_index)` is not in
  `current` raises `UnknownLine` naming both numbers.
- **AC-4** - `chunk_pages(pages, max_tokens)` returns contiguous, ordered,
  non-overlapping chunks covering every page exactly once, each with
  `estimate_tokens(consistency_text(chunk, glossary)) <= max_tokens`; a
  single page over the limit raises `PageTooLarge` naming it; for a fixture
  of 200 pages x 20 lines it returns more than one chunk.
- **AC-5** - Given a fake client, `run_consistency(client, chunk_text)`
  sends one `generate_content` with `contents == [chunk_text]` (no image),
  `system_instruction == CONSISTENCY_PROMPT`, the JSON mime type,
  `CORRECTIONS_SCHEMA`, `ThinkingLevel.MEDIUM`, `max_output_tokens ==
  CONSISTENCY_MAX_OUTPUT_TOKENS`, and returns a `ConsistencyResult` with the
  raw text, usage (thinking added to output) and `CallInfo`.

## Contract

**Writes:** `src/mangatl/translate/consistency.py`, `src/mangatl/translate/gemini.py`, `src/mangatl/domain/correction.py`, `tests/core/test_consistency_pass.py`, `tests/core/test_gemini_consistency.py`

```python
# domain/correction.py (MT-103's module)
@dataclass(frozen=True)
class ProposedCorrection:
    page_ordinal: int        # 0-based; the prompt shows 1-based `Page {n}` and the parse converts
    reading_index: int
    corrected_en: str
    reason: str
@dataclass(frozen=True)
class ParsedCorrections:
    corrections: tuple[ProposedCorrection, ...]
    unchanged_returned: int
@dataclass(frozen=True)
class ConsistencyResult:
    text: str
    usage: TokenUsage
    call: CallInfo

# translate/consistency.py - SDK-free
CONSISTENCY_PROMPT: str                         # "return only lines you would change; never restate a line you keep"
CORRECTIONS_SCHEMA: dict[str, Any]
CONSISTENCY_MAX_INPUT_TOKENS: int = 180_000     # MT-101 D-? may move it
CONSISTENCY_MAX_OUTPUT_TOKENS: int = 8_192
@dataclass(frozen=True)
class PageLines:
    ordinal: int
    lines: tuple[tuple[int, str, str | None], ...]   # (reading_index, ja, en or None)
class UnknownLine(Exception): ...
class PageTooLarge(Exception): ...
def consistency_text(pages: Sequence[PageLines], glossary_block: str) -> str
def chunk_pages(pages: Sequence[PageLines], glossary_block: str, max_tokens: int = CONSISTENCY_MAX_INPUT_TOKENS) -> list[tuple[PageLines, ...]]
def parse_corrections(text: str, current: Mapping[tuple[int, int], str]) -> ParsedCorrections

# translate/gemini.py
def run_consistency(client: Client, chunk_text: str) -> ConsistencyResult
```

Oracle partition: all **mechanical**. No new dependency.
