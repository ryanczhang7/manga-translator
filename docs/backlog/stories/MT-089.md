## Context

Filed 2026-10-17 at MT-075's PLANNED → RED (its PO-1): EPIC-07's done-when
says **`bench`** — one command — "can be pointed at a benchmark chapter plus
its ground truth and prints S1b, S1a, recall, spurious, S2 and S5". After
MT-075 all six numbers exist, across three commands: `python -m
mangatl.bench.acceptance` (MT-022), `python -m mangatl.bench.s2` (MT-023) and
`python -m mangatl.bench.cost` (MT-075). MT-075's stub deferred the combined
command to "MT-024's console-script decision", and MT-024 closed without one.

This story is the glue and nothing else: `python -m mangatl.bench FOLDER
[--truth PATH]` runs the three measurements in order against one opened
project and one loaded document, prints their lines in one report, and exits
as they do (`0` measured, `2` cannot measure — and S1/S2's development-use
refusal refuses the whole report, S5 included).

**Pinned at PLANNED → RED on 2026-10-22.** The three existing `main`s are
the model: each opens the project with `open_project(project_dir_for(folder))`,
defaults `--truth` to `truth_path_for(folder)`, refuses with one stderr line
`<prog>: <message>` and exit `2`, prints `validate(truth, project.chapter).warnings`
then its `_render(report)` lines, and exits `0` whatever the verdict (an
`S2 FAIL` is a measurement, not a failure to measure).

## Acceptance criteria

- **AC-1** — Given a chapter folder with a project, a valid ground truth and
  a ledger, when `python -m mangatl.bench FOLDER` (or `main([FOLDER])`) runs,
  then it exits `0` and stdout is **exactly**, in order: the document's
  validation warnings once, then `acceptance.render(measure(project,
  truth))`, then `s2.render(measure_s2(project, truth))`, then
  `cost.render(measure_cost(project))` — the same lines each command prints
  on its own, computed by the tests from the three public functions on the
  same project and document. With `--truth PATH` the document at `PATH` is
  used instead of `<folder>.truth.json`.
- **AC-2** — Given a document flagged `development_use`, when it runs, then
  stdout is empty, stderr is exactly one line beginning
  `python -m mangatl.bench: `, and it exits `2` — S5 is not printed for a
  chapter the harness refuses. The same holds for a missing folder, a folder
  with no project, a missing document and an invalid document (one line, the
  same message the acceptance command gives, exit `2`, nothing on stdout).
- **AC-3** — Given `src/mangatl/bench/__main__.py`'s source, when it is
  parsed, then it imports `measure` from `mangatl.bench.acceptance`,
  `measure_s2` from `mangatl.bench.s2` and `measure_cost` from
  `mangatl.bench.cost`, calls each **exactly once**, imports `render` from
  each of the three, and defines no function whose name starts with
  `measure` or `render`: the measurements are called, not re-implemented.
- **AC-4** — `pyproject.toml`'s `[project.scripts]` declares
  `mangatl-bench = "mangatl.bench.__main__:main"` (PO-1), and
  `runpy.run_module("mangatl.bench", run_name="__main__")` raises
  `SystemExit` with the status `main` returns (the `python -m` entry).

**Block 1 — `render` goes public** in the three modules: `_render` is renamed
`render` in `acceptance.py` (`list[str]`), `s2.py` (`list[str]`) and `cost.py`
(`tuple[str, str]`), added to each `__all__`, called by each module's own

**Block 2 — the combined command** (`src/mangatl/bench/__main__.py`, new):

```python
_PROG = "python -m mangatl.bench"
_OK = 0
_CANNOT_MEASURE = 2

def main(argv: Sequence[str] | None = None) -> int
```

The argument parser is the acceptance command's (`folder: Path`, `--truth:
Path | None`, `prog=_PROG`). The checks run **in the acceptance command's
order**: folder not a directory → `no such folder: {folder}`; `open_project`
raising `FileNotFoundError` or `SchemaTooNew` → `str(error)`; document not a
file → `no ground-truth document at {path}`; `load_ground_truth` or any
measurement raising `InvalidGroundTruth` or
`BenchmarkChapterUsedInDevelopment` → `str(error)`. Every refusal is
`print(f"{_PROG}: {message}", file=sys.stderr)` and `return _CANNOT_MEASURE`,
with **nothing printed to stdout before it**: the project is opened once (one
`with project:`), the document loaded once, and all three measurements —
`measure(project, truth)`, `measure_s2(project, truth)`, `measure_cost(project)`,
in that order — complete before the first `print`. Then
`validate(truth, project.chapter).warnings` once, then the three `render`s in
that order, one `print` per line, `return _OK`. `if __name__ == "__main__":
raise SystemExit(main())` ends the file, as the three modules end theirs. No
other logic: no arithmetic on any report, no re-rendering.

**Block 3 — the console script** (`pyproject.toml`, `[project.scripts]`, beside
`mangatl-run`): `mangatl-bench = "mangatl.bench.__main__:main"`, with a comment
in the style of the `mangatl-run` one saying it is a development convenience
and that tests call `main([...])` in process. `uv.lock` does not change for a
scripts entry; if it does, GREEN reports it rather than committing a lock
churn.

**Block 4 — docs.** `docs/wiki/benchmark-ground-truth.md` gains a
"Measuring" section (this commit, PO-2).

**Block 5 — tests** (`tests/core/test_bench_main.py`, new; `coverage-core`
requires **100 %** of `bench/**`, so every branch of `__main__.py` is
exercised, including the `python -m` guard via `runpy` as
`tests/core/test_bench_cost.py:530` does it). Fixtures follow
`tests/core/test_bench_acceptance.py`'s `folder` / `chapter` / `truth`
(baseline project, seeded and loaded truth) and record **at least one priced
call** in the ledger (`record_call`, as `test_bench_cost.py`'s `_record`
does) so S5 prints a real total, plus one chapter with no priced calls (the
`$—` lines). AC-1's expected stdout is **computed** in the test from the three
public functions and the three `render`s on the same project and document,
never typed in. AC-2's five refusals reuse the acceptance tests' `_no_folder`
… `_development_document` arrangements (copy them; do not import private
helpers across test modules). AC-3 by `ast` over the file's source. AC-4 by
`tomllib` over `pyproject.toml` and by `runpy`.

**Oracle partition for RED.** *Settled* (read out): the three modules' line
