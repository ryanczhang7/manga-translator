## Context

Filed by the EPIC-02 mutation audit, `docs/wiki/audits/EPIC-02-2026-11-25.md`
(`## Decided` 6, `## Evidence` E-6). This story adds tests only. The production
code is correct today, but the entry-point test that claims to pin it cannot
tell whether it is.

**What is settled.** This comes from the audit's `## Decided` and is not to be
reopened:
- `mangatl-run`'s resume is correct today. `tests/core/test_pipeline.py` pins
  the runner's skip logic.
- `test_a_second_invocation_skips_the_pages_the_first_one_finished`
  (`tests/core/test_cli.py:505`) is theatre for the property its name claims.
  It asserts one progress line per filename and an exact output folder. A page
  that is re-processed produces both of those too.
- The fix is a test that observes the skip *through `main`*. No production
  file changes.

**What is evidence, to verify rather than trust.** The audit found that the
mutant below survives `test_cli.py`. Re-run it at this story's base before
relying on that:

    bash scripts/mutate.sh src/mangatl/pipeline/runner.py 's/^    if stages and all(stage.is_done(ctx) for stage in stages):$/    if False:/; s/^        if stage.is_done(ctx):$/        if False:/' -- uv run pytest -q -p no:cacheprovider tests/core/test_cli.py

At `a2b2003` the audit ran the same mutation by line number (lines 269 and 278)
and got `78 passed`. The expression above anchors on the line text instead, so
it does not depend on line numbers.

**Why it matters more than one test.** EPIC-02 makes runs resumable to save
money: "a crash on page 18 must not re-buy pages 1-17". Suppose a later change
to `cli.py`'s reopen path reset page statuses, or rebuilt the project from the
chapter it has just read. Every page would rerun and be paid for again, and
every CLI test would still pass.

**Required gate that would fail if this broke:** `unit`. `coverage-core` would
fail too, because it runs `tests/core`.

## Acceptance criteria

- **AC-1** - Given a chapter that one `mangatl-run` invocation has finished,
  when `main` is invoked a second time on the same folder, then no stage that
  the composition root built runs for any page during the second invocation.
  This test **fails** under the runner mutant quoted in `## Context`.
- **AC-2** - Given the same second invocation, when its progress output is
  read, then every page's line says the page was skipped, not started. A user
  who re-runs a finished chapter is told that nothing was redone. This test
  **fails** under the same mutant.

## Contract

- Tests only, and GREEN is a no-op. Every test passes on arrival. Each is
  earned by the mutation in `## Deferred verifications`, not by having been

  records `ran: list[int]` (`tests/core/test_cli.py:100-118`). AC-1 can clear

  afterwards.

  shape, and anchor the match to the per-page line. Do not use a floating
  substring that a `PageStarted` line could also contain.

  existing test must not lose an assertion.
