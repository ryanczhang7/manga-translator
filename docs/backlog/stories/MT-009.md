## Context

Brief feature 2's second half. `architecture.md` D10 records the scope decision
and what lost: v1 orders by geometry and does **not** segment panels, accepting
that some unusual layouts will be ordered wrongly, because the LLM sees the page
image and can attribute speakers from the art, and the human sees the order on
the review screen.

Reading order matters more than it looks. It is the sequence the translator
receives, so it decides pronoun and speaker attribution; it is the order lines
appear in the review column, so it decides whether the human can read down the
list at all; and it is stable identity for a region across a resume.

**Which required gate would fail if this story's artifact broke:** `unit` and
`coverage-core`. Pure function on geometry, 100% coverage bar.

## Acceptance criteria

- **AC-1** — Given regions in a single horizontal band, when ordered, then they
  come out right to left.
- **AC-2** — Given regions in two clearly separated horizontal bands, when
  ordered, then every region in the upper band precedes every region in the
  lower band, regardless of horizontal position.
- **AC-3** — Given two regions whose vertical extents overlap by more than
  `BAND_OVERLAP_FRACTION`, when ordered, then they are treated as the same band
  and ordered right to left relative to each other.
- **AC-4** — Given two regions whose vertical extents overlap by less than
  `BAND_OVERLAP_FRACTION`, when ordered, then the higher one precedes the lower
  one even if it is further left.
- **AC-5** — Given any set of regions, when ordered, then the result is a
  permutation of the input, every `reading_index` is assigned once, contiguous
  from 0, and running the function twice on the same input gives the same
  result.
- **AC-6** — Given the annotated fixture pages, when ordered, then the produced
  order matches the hand-annotated ground-truth order on at least the pages
  annotated as "conventional layout", exactly.
  *Control:* a left-to-right ordering must score **0 exact-match pages** on the
  same fixture set — if it does not, the fixtures do not discriminate and the
  criterion is measuring nothing.
- **AC-7** — Given a single region, or zero regions, when ordered, then the
  result is that region alone, or an empty list, with no error.

## Contract

```
src/mangatl/domain/reading_order.py
    BAND_OVERLAP_FRACTION: float      # settled in GREEN from fixture measurement
    def order_regions(regions: Sequence[RawRegion]) -> list[int]
        # returns input indices in reading order
    def assign_reading_indices(regions: Sequence[RawRegion]) -> list[OrderedRegion]
```

**Semantics behind each number and each direction — read this before writing a
comparator:**

- **Right to left means descending in x.** Japanese reads right to left, so the
  region whose polygon has the **greatest** x-centre comes **first**. Getting
  this backwards produces a chapter that reads perfectly and is entirely wrong,
  which no type checker will notice.
- **Top to bottom means ascending in y**, with y increasing downward as image
  coordinates conventionally do. The top-left of the page is `(0, 0)`.
- **`BAND_OVERLAP_FRACTION`** is the fraction of the *shorter* region's vertical
  extent that must overlap the other's for the two to count as the same band.
  Using the shorter one is deliberate: a tall region beside a short one should
  band with it when the short one sits inside its span, and a fraction of the
  taller extent would refuse that.
- **Banding is transitive within a sweep, not pairwise.** Three regions where
  A bands with B and B bands with C but A does not band with C belong in one
  band. Implementing the pairwise version produces an order that depends on
  input sequence, which AC-5's determinism clause catches.
- **Ties break on x first, then on the region's index in the input**, so the
  order is total. A non-total comparator is the same latent bug as MT-004's.

**Oracle partition:**

| AC | Kind | Instruction to RED |
|---|---|---|
| AC-1..AC-5, AC-7 | **Mechanical** | Synthetic rectangles you place by hand. Enumerate the boundary at exactly `BAND_OVERLAP_FRACTION`, one pixel either side. AC-5 is a `hypothesis` property (permutation, contiguity, determinism). |
| AC-6 | **Oracle-free** | Real pages, hand-annotated. Invent the scoring (exact sequence match per page is the obvious one) and the control in the criterion is mandatory. |

**Narrowing a `hypothesis` generator is allowed only against a design clause**
(`rules.md`). "Polygons have at least three points and lie within the page" is a
legitimate narrowing tied to MT-007's AC-4. "The test was failing on degenerate
zero-area rectangles" is not — a zero-area region is a real MT-007 output if
`MIN_REGION_AREA_PX` is ever wrong, and the ordering must not crash on it.

## Deferred verifications

- *Falsifiable condition 1:* with the x comparison **reversed** (left to right),
  AC-1 and AC-6 **must** fail.
- *Falsifiable condition 2:* with `BAND_OVERLAP_FRACTION` set to `0.0` (every
  region bands with every other), AC-2 and AC-4 **must** fail.
- *Falsifiable condition 3:* with the transitive banding replaced by pairwise
  banding, AC-5's determinism property **must** fail on some input. If it does
  not, the property is not exploring enough and RED's generator needs widening,
  not the assertion loosening.
- **Owner: GATES.** Three mutations via `bash scripts/mutate.sh`.

## Model guidance

- **RED and GREEN models:** to be recorded at dispatch, by name. Defaults are
  `claude-opus-5` (Claude Opus 5).
- **Oracle partition mixed**; put the table in the dispatch prompt verbatim.
  Note specifically that the *directions* (descending x, ascending y) are
  settled here and are to be read out, not derived — a RED phase that "decides"
  reading direction has re-litigated a fact about Japanese.
- **Success condition, falsifiable:** the AC-5 property fails against a pairwise
  banding implementation (condition 3 above) rather than passing vacuously, and
  AC-6's control separates right-to-left from left-to-right at 0 pages versus
  all of them. A generator narrowed during RED without a named design clause is
  a failure regardless of the rest.
- **Verdict:** *to be recorded.*
