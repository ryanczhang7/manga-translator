## Context

Filed 2026-10-08 at MT-022's PLANNED → RED (its PO-6): EPIC-07's done-when
says `bench` prints **S1b, S1a, recall, spurious, S2 and S5**, and the epic's
four stories deliver S1 (MT-022), S2 (MT-023), the ground truth (MT-029) and
the installer (MT-024) — nothing delivers **S5**, the brief's cost criterion.
The number already exists: every priced API call is in the project's ledger
(MT-012's `store/ledger.py`, MT-044's `Usd` arithmetic; MT-018's readout shows
the running total), so this story is a read-out, not a measurement, and it
stays small.

**What S5 is.** The brief, section 7, verbatim: *"S5 — Cost: a benchmark
chapter run costs under $2, as reported by the app and confirmed against the
provider's billing at least once."* The denominator is **per chapter**; the
bar is $2. This story prints the chapter figure the bar attaches to, and a
per-page figure beside it as a diagnostic (a chapter twice as long costs
twice as much, and the per-page figure is what makes two chapters
comparable). It does not judge the bar (Out of scope), and "confirmed against
the provider's billing" is the user's act, once, by hand — no story automates
it.

**Where the number comes from, and from nowhere else.** `store.ledger`
(MT-012) is append-only by schema trigger and sums integer micro-dollars in
SQL, so a total read from it is exact and cannot have been quietly edited.
`chapter_total` is deliberately unqualified by run (its AC-6): a resumed
chapter is two `run` rows and one spend. This story reads the ledger through
that module's public functions and computes nothing of its own but one
division.

**`$—`, never `$0.00`.** The app's readout (MT-018 AC-5, AC-9) shows `$—` when
no call was priced, keyed on *a call existing* and not on the total being
non-zero — `$0.00` would be a claim that the run was free, and a chapter whose
calls were never priced (a provider with no rate row; a run that never reached
translation) is not free, it is unmeasured. `bench` may not import `ui`
(`pyproject.toml`, "Nothing imports ui"), so the glyph is spelled here and the
rule is restated here, by reference to MT-018.

## Acceptance criteria

Fixture throughout: a chapter project of **two** pages built the way
`tests/core/test_ledger.py` builds one (`create_project` over tiny PNGs; a
`run` row inserted with raw SQL, as that file's `_open_run` does, because
`bench` sits beside `pipeline` and may not import it), with calls recorded by
`store.ledger.record_call` from `domain.rates.price` — never by writing
`llm_call` rows directly, so what the test sums is what the product writes.

- **AC-1 — the chapter's total is the ledger's, exactly, across every run.**
  Given a two-page chapter with priced calls recorded against **two** `run`
  rows — at least three calls, on both pages, whose exact decimal sum is not
  representable as a double (reuse `test_ledger.py`'s device: a sum such as
  $0.27928) — when `measure_cost(project)` runs, then `report.total` **equals**
  the fold of every recorded `CostRecord.cost` with `Usd.__add__` (a `Usd`
  equality, `Decimal` underneath, **no tolerance**), equals
  `ledger.chapter_total(project)`, `report.calls` is the number of calls
  recorded, and `report.pages` is `len(project.pages())`. Both runs count:
  dropping either run's calls from the fold makes the equality fail.
- **AC-2 — nothing priced is `$—`, never `$0.00`.** Given the same chapter
  with **no** ledger rows, when it runs, then `report.total is None`,
  `report.per_page is None`, `report.calls == 0`, `report.pages == 2`; and
  `main([folder])` exits `0` printing both lines with the figure `$—`
  (`"$\N{EM DASH}"`) and the string `$0.00` nowhere in its stdout.
- **AC-3 — *(negative control)* one entry doubled raises S5 by exactly that
  entry.** Given AC-1's chapter, when one of its calls is recorded a **second
  time** (the same `CostRecord`, against the same run and page — the ledger is
  append-only, so "doubled" is "recorded twice", exactly as a retried page
  bills twice), then the new `report.total` equals the old `report.total +
  that call's cost` (exact `Usd` equality), `report.calls` rises by one, and
  `report.per_page` equals the per-page rule (Contract block 1) applied to the
  new total — the doubled entry is *not* reflected in `pages`.
- **AC-4 — the per-page figure is the total over the chapter's page count,
  rounded once to a micro-dollar, half up.** Given a total of **279,280**
  micro-dollars over a chapter of **three** pages (so the quotient,
  93,093.333…, is not a whole micro-dollar), then `report.per_page ==
  Usd.from_micro(93093)`; and given a total of **1** micro-dollar over **two**
  pages, `report.per_page == Usd.from_micro(1)` (half rounds **up**, as
  `Usd.micro()` rounds — `ROUND_HALF_EVEN` would give 0). The divisor is the
  chapter's page count, **not** the number of pages that carry a call: given
  AC-1's chapter with every call on page 0 and page 1 untouched, `per_page` is
  still `total / 2`.
- **AC-5 — the command prints two lines and exits as its siblings do.** Given
  AC-1's chapter on disk, when `main([str(folder)])` runs, then it returns `0`
  and prints exactly the two lines of Contract block 2, matched with
  `re.fullmatch` against the pinned patterns with the fixture's own figures
  substituted (`str(Usd)`, four decimals). Given a folder that does not exist,
  or a folder with no `.mtproj` beside it, it returns `2` and prints one line
  to **stderr** beginning `python -m mangatl.bench.cost:`, and nothing to
  stdout — the shape of `bench.acceptance.main` (MT-022 PO-5).
- **AC-6 — the module reads the ledger through `store.ledger` and nothing
  else computes a cost.** A source check over `src/mangatl/bench/cost.py`
  (read as text, as `test_bench_recall.py` pins the threshold import): it
  imports `chapter_call_costs` from `mangatl.store.ledger`; it does not import
  `mangatl.ui`, `mangatl.pipeline` or `mangatl.domain.rates`; and no name from
  it contains `price` or `rate`. The `lint` gate's layers contract enforces
  the first two imports mechanically; the check is here because `rates` is
  *below* `bench` and the contract would allow it, and a bench that re-priced
  a call would be a second answer to one question.

Every criterion is **mechanical** — the oracle is the ledger's own sum, the
`Usd` arithmetic that already exists, or a pinned string. There is no
oracle-free criterion here and no threshold to invent; AC-3 is the one
negative control and it is a control on the *sum being a sum*. Which is why
`## Deferred verifications` has one entry.

**Block 1 — the module and the measurement.**

```python
# src/mangatl/bench/cost.py
from __future__ import annotations
from collections.abc import Sequence
from dataclasses import dataclass
from decimal import ROUND_HALF_UP, Decimal
from functools import reduce
from operator import add

from mangatl.domain.money import Usd
from mangatl.store.ledger import chapter_call_costs          # the ONE read
from mangatl.store.project import Project, SchemaTooNew, open_project, project_dir_for

__all__ = ["DASH", "CostReport", "main", "measure_cost"]

#: What the figure reads when no call was priced. MT-018 AC-5's glyph, spelled
#: here because `bench` may not import `mangatl.ui`.
DASH: str = "$\N{EM DASH}"

@dataclass(frozen=True)
class CostReport:
    total: Usd | None      # exact fold of every ledger row; None when calls == 0
    calls: int             # ledger rows, every run of the chapter
    pages: int             # len(project.pages()) - the chapter, not the pages with calls
    per_page: Usd | None   # total / pages, quantised ONCE to a micro-dollar, ROUND_HALF_UP; None when total is None

def measure_cost(project: Project) -> CostReport: ...
```

The read API, by signature, from `src/mangatl/store/ledger.py` (MT-012):

```python
def chapter_call_costs(project: Project) -> tuple[Usd, ...]   # every priced call, oldest first; () when none
def chapter_total(project: Project) -> Usd                    # SUM over every run; Usd zero when none - NOT None
```

`measure_cost` calls `chapter_call_costs` once: `calls = len(costs)`,
`total = reduce(add, costs)` when `costs` is non-empty, else `None`
(`sum()` does not work on `Usd` — `money.py`'s own note). It does **not**
call `chapter_total`, so AC-1's equality with `chapter_total` is a check that
two routes through the ledger agree, not a tautology; tests may call
`chapter_total` freely. `pages = len(project.pages())`, which is at least 1
for any project `create_project` will make (`intake` refuses an empty folder).

**The per-page rule**, exactly:
`Usd((total.amount / pages).quantize(Decimal("0.000001"), rounding=ROUND_HALF_UP))`.
Division of an exact `Decimal` by an `int`, quantised once to the ledger's own
unit, half up — the same rounding `Usd.micro()` uses, for the same reason
(`money.py`). `Usd` is not extended for this; the one division lives here.

**Block 2 — the command and its output.**

```
python -m mangatl.bench.cost FOLDER
```

`main(argv: Sequence[str] | None = None) -> int`, shaped as
`bench.acceptance.main` (MT-022 PO-5): `argparse` with `prog =
"python -m mangatl.bench.cost"`, one positional `folder`; returns `0` when
measured, `2` when it cannot measure — `folder` not a directory, or
`open_project(project_dir_for(folder))` raising `FileNotFoundError` or
`SchemaTooNew` — printing `python -m mangatl.bench.cost: <message>` to stderr
and nothing to stdout. The project is opened under `with project:`.

Stdout, exactly two lines, in this order, fields separated by **two or more
spaces** (tests match `\s+`), figures by `str(Usd)` (four decimals) or `DASH`:

```
S5 chapter cost  $0.2793  20 priced calls
per page         $0.1396  2 pages
```

and with nothing priced:

```
S5 chapter cost  $—  no priced calls
per page         $—  2 pages
```

Pinned patterns (RED substitutes the fixture's figures):

```
r"S5 chapter cost\s+\$\d+\.\d{4}\s+\d+ priced calls"      # \$— and "no priced calls" when None
r"per page\s+\$\d+\.\d{4}\s+\d+ pages"                     # \$— when None; the page count always
```

The word "calls" is plural even for one call; nothing pluralises. No bar, no
PASS/FAIL, no projection: S5's judgement is the user's against the brief, and
the bar is printed nowhere (Out of scope).

**Block 3 — what the module must not do.** Not import `mangatl.ui` or
`mangatl.pipeline` (the layers contract; the `lint` gate) and not import
`mangatl.domain.rates` (AC-6; the contract would allow it). Not read
`budget_ceiling`, not project, not judge. Not take a `--truth` option: see
PO-2.
